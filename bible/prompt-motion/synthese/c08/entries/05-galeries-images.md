## Montrer beaucoup d'images : rafale, éventail, pile et mur qui défile (photo burst, card fan, stacked prints, scrolling image wall, carousel)

Une série d'images devient une série d'objets : cartes en rafale, éventail de tirages, collage qui se disperse, mur incliné qui dérive. La quantité devient une preuve sans liste à lire. Le dosage est étroit. Une carte toutes les 7 à 8 im à 30 fps se lit ; un mur à 3,6 % du cadre par seconde pendant 5,5 s endort. Vue dans 24 vidéos, dont 18 notées 4 ou 5.

**Règles de construction**

1. Cadence : une image par croche (andginja, 0,25 s) ou toutes les 24 im à 60 fps (ajith-io, 0,4 s), si chacune doit se reconnaître. Plus vite, il faut une ancre fixe : monogramme de 45 % H sur des photos changées toutes les 5 im (jacksonfall), légende persistante (ajith-io).
2. Chaque carte entre en 5 im à 30 fps, ease-out fort, et part 2 à 3 im avant l'attaque pour se poser dessus (andginja). L'éventail s'ouvre en 24 im, angles de ±5 à 25° (lester-tyy, francoxavier33, jesscaroline7), avec ombre et léger recul.
3. Le mur défile à vitesse linéaire, 7 à 10 % du cadre par seconde (reyzostyle, samuel-yostt, viktoroddy), incliné d'environ 15° et coupé par les bords. Il tient une mesure ou moins (1,3 à 2,2 s). À 3,6 % par seconde pendant 5,5 s (ai-baymax), l'attention tombe.
4. Rangées en sens alternés, masques en fondu aux bords, et vignettes crédibles dans la charte (titres condensés et pastilles « 17× » chez reyzostyle). Des aperçus hors charte pendant 4,4 s (ddryo-loos) ou quatre styles d'illustration (itisrazak) cassent le film.
5. Le contenu de la galerie argumente. Pile d'affiches qui change avec la requête (lester-tyy), puce liée au mot dit (rammanq), vrais clips qui jouent dans un mur incurvé à ±20° (twoclipping). Une galerie de remplissage reste du papier peint.
6. Calage, d'après les seules vidéos animées sur la musique. Coupe ou départ 2 à 3 im avant l'attaque, pose sur le temps (andginja, ajith-io, reyzostyle). Un carrousel de 27 im doit avoir son pic de vitesse sur le temps (jesscaroline7 : le 1er oui, le 2e hors grille).

Pour la mise en perspective du mur, voir chapitre 5, « Les cartes en perspective ». Pour les rangées fixes, voir chapitre 2, « Grilles, bento et rangées de cartes ». Pour la mosaïque des plans passés avant le logo, voir chapitre 10, « Le récapitulatif en rafale ». Pour les rangées de texte, voir chapitre 3, « Le texte en motif ».

**Verdict** : à reprendre. C'est la preuve par l'abondance, à condition de rester court et lisible. Le mur trop lent est le cousin du mur de mots flous que tu rejettes.

**Quand l'utiliser** : en promo SaaS pour montrer un catalogue, des réalisations ou du contenu généré. En showreel, pour l'accroche (collage dispersé, mur en 2 s). Fonction : preuve ou accroche, choisie au découpage, construite plan par plan sur la grille. À éviter quand une seule image doit être lue en détail : une carte unique en carrousel fait mieux.

**HyperFrames (GSAP)**

```js
// Rafale de 3 cartes sur les croches, puis mur incliné en rangées alternées, puis éventail
const FPS = 60, F = n => n / FPS;
const BEAT = 60 / 120;                          // 120 BPM : croche = 0,25 s = 15 im
const at = b => b * BEAT;
const cards = gsap.utils.toArray(".card");      // 3 cartes verticales, 23 % L, pleine hauteur
tl.set(cards, { xPercent: 130, autoAlpha: 1 }, 0);
cards.forEach((c, i) => {
  const hit = at(4) + i * BEAT / 2;             // une carte par croche
  tl.to(c, { xPercent: 0, duration: F(10), ease: "power4.out" }, hit - F(5)); // part 5 im avant
});
// Mur : 3 rangées 2 fois plus larges que le cadre, sens alternés, 7,5 % L par seconde
const WALL = at(8), HOLD = at(4);               // une mesure de 4 temps = 2 s
const DX = 0.075 * 1920 * HOLD;                 // 288 px parcourus pendant la mesure
tl.set("#wall", { rotation: -15, autoAlpha: 1 }, WALL)
  .to("#wall", { scale: 1.08, duration: HOLD, ease: "none" }, WALL); // zoom lent de 8 %
gsap.utils.toArray(".row").forEach((row, i) => {
  const dir = i % 2 ? 1 : -1;                   // rangée du milieu vers la droite
  tl.fromTo(row, { x: -dir * DX / 2 }, { x: dir * DX / 2, duration: HOLD,
      ease: "none", immediateRender: false }, WALL);
});
// Éventail : 6 tirages cachés derrière l'affiche s'ouvrent en 24 im, ±10 à 25°
const FAN = at(12);
const ANG = [-25, -18, -10, 10, 18, 25], X = [-330, -250, -170, 170, 250, 330];
tl.set("#info", { autoAlpha: 0, y: 24 }, 0)
  .set(".print", { autoAlpha: 1 }, FAN)
  .to(".print", { rotation: i => ANG[i], x: i => X[i], z: -60, duration: F(24), ease: "power3.out" }, FAN)
  .to("#poster", { y: -162, duration: F(24), ease: "power3.out" }, FAN) // 15 % de 1080
  .to("#info", { autoAlpha: 1, y: 0, duration: F(12), ease: "power2.out" }, FAN + F(10));
```

**After Effects**

- Rafale : trois calques photo dans des Shape Layers (calques de forme) arrondis. Position X de hors cadre à la place finale en 10 im à 60 fps ; dans le Speed Graph (éditeur de graphe de vitesse), influence entrante 90 % (≈ power4.out).
- Placer la 1re image clé 5 im avant le marqueur du temps. Décaler chaque carte de 15 im, une croche à 120 BPM (Alt + Pg suiv. : une image).
- Mur : chaque rangée dans un Layer › Pre-compose (Calque › Précomposer), Position X en 2 images clés linéaires sur une mesure. Toutes les rangées parentées à un Layer › New › Null Object (Calque › Nouveau › Objet nul) tourné de −15°, Scale (Échelle) 100 → 108 %.
- Bords du mur : Mask (masque) rectangulaire sur la précomposition finale, Mask Feather (Contour progressif du masque) de 150 px pour le fondu aux bords.
- Éventail : Anchor Point (Point d'ancrage) des tirages en bas au centre, Rotation 0 → ±10 à 25° en 24 im, Easy Ease (Lissage de vitesse, F9) puis influence entrante 80 %. Effect › Perspective › Drop Shadow (Ombre portée) sur chaque tirage.
