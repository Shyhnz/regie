## L'illustration qui explique : construite au fil de la voix, objet qui joue la métaphore (narration-synced illustration build, living diagram, animated metaphor object)

Une illustration se complète élément par élément quand la voix les nomme, flèche et légende manuscrite comprises ; ou un objet dessiné joue l'idée en une action lisible. L'œil reçoit chaque élément au moment où il est nommé, sans mur d'image à déchiffrer : 5 ajouts en 4 s dans la meilleure occurrence. Vue dans 13 vidéos, dont 9 notées 4 ou 5.

**Règles de construction**

1. Un élément paraît 0,1 à 0,3 s avant le mot qui le nomme (chapitre 9, « Le calage sur la voix off ») ; 1 ou 2 ajouts par phrase.
2. Ordre de construction d'un élément : trait, aplat, flèche, puis légende manuscrite ; chaque élément se dessine en ≈ 8 à 20 im (différence d'image, probable). Le guide propose un atout toutes les 1,5 s, trait fin puis texte (guide Otom, p. 9) : c'est l'écart mesuré ici (1 à 1,6 s).
3. Entre deux ajouts, l'image vit par zones (gouttes, bulles, faisceau). Modèle : [DistilBook motion explainer](https://prompt-motion.com/sudo-kiran-b055de), animé sur la musique à 120 BPM : rien de figé en 4,4 s, gestes sur les temps et demi-temps. Contre-exemple : ajith-io, 65 % de la durée figée.
4. Une métaphore tient en une action de 2 à 4 s, répétée pour être comprise. Ici 5 copies à 0,48 s d'écart ; ailleurs un bloc de 5,0 s rejoué 3 fois ([Negroni recipe animation](https://prompt-motion.com/ror-fly-9950f1)). Pour un plan « problème », le guide fait se vider puis se briser un objet en 3 s (guide Otom, p. 10).
5. Geste d'objet : posé en 4 im, tenu 0,3 s, bascule de 110° en 10 à 15 im (ease-in-out). Les deux cocktails n'ont ni anticipation ni dépassement : ajoute-les (entrée « Le poids du personnage »).
6. Un mobile d'ambiance (avion, oiseau) traverse en linéaire à 12-25 % L/s et doit rejoindre ce qu'il illustre. Une image qui illustre un mot peut se révéler par taches de bruit à liseré clair. Mesure : 43 im, ≈ 40 % à mi-course, courbe accélérée ([Tented image gen product video](https://prompt-motion.com/justincooperman-e7bbc4)).

**Verdict** : à reprendre. C'est la version illustrée du calage sur la voix : chaque élément arrive sur son mot, rien n'est à déchiffrer. Pour la métaphore, garde une seule action, répétée, en 2 à 4 s.

**Quand l'utiliser** : explainer de données ou de process, tutoriel, promo SaaS qui doit faire comprendre un concept. Fonction : poser le problème (objet métaphore), montrer un mécanisme, prouver. Se prépare au script (un élément par nom prononcé), puis à la construction du plan. À éviter en typo cinétique 1600 : à un événement par 0,5 s, une illustration détaillée n'a pas le temps d'être lue. Et jamais de flèche qui n'explique rien.

**HyperFrames (GSAP)**

```js
// Illustration construite au fil de la voix, puis objet qui joue la métaphore (60 fps)
const FPS = 60, F = n => n / FPS;
const LEAD = 0.2;                      // l'élément part 0,1 à 0,3 s avant son mot
const CUES = [                         // début du mot (s), d'après les horodatages du TTS
  { t: 11.0, el: "#sun" }, { t: 11.5, el: "#air" }, { t: 13.0, el: "#sugar" }, { t: 13.5, el: "#feeds" },
];
// l'image finie passe en fantôme à 15 %
tl.to("#ghost", { opacity: 0.15, duration: F(18), ease: "power2.inOut" }, 10.4);
CUES.forEach(({ t, el }) => {
  const t0 = t - LEAD;                 // traits : <path pathLength="1" stroke-dasharray="1">
  tl.fromTo(`${el} .stroke`, { strokeDashoffset: 1 }, { strokeDashoffset: 0, duration: F(16),
      ease: "power2.inOut", stagger: F(2), immediateRender: false }, t0)
    .fromTo(`${el} .fill`, { opacity: 0 }, { opacity: 1, duration: F(10), ease: "power1.out",
      immediateRender: false }, t0 + F(8))
    // flèche tracée, puis légende manuscrite écrite 1 lettre par image
    .fromTo(`${el} .arrow`, { strokeDashoffset: 1 }, { strokeDashoffset: 0, duration: F(10),
      ease: "power3.out", immediateRender: false }, t0 + F(10))
    .fromTo(`${el} .label .ch`, { opacity: 0 }, { opacity: 1, duration: F(1), stagger: F(1),
      immediateRender: false }, t0 + F(16));
});
// métaphore : l'original descend dans la photocopieuse (0,48 s) sous la ligne de scan
const M = 37.0;
tl.to("#original", { y: 90, duration: 0.48, ease: "power2.inOut" }, M)
  .fromTo("#scan", { x: 0 }, { x: 260, duration: 0.48, ease: "none", immediateRender: false }, M);
// 5 copies identiques (même tache), une toutes les 0,48 s : glisse de 5 % L, éventail ±3°
[-3, 2, -1, 3, -2].forEach((rot, i) => {
  tl.fromTo(`#copy${i}`, { x: 0, autoAlpha: 0 }, { x: 96 + i * 19, autoAlpha: 1, rotation: rot,
    duration: 0.1, ease: "power2.out", immediateRender: false }, M + 1.08 + i * 0.48);
});
```

**After Effects**

- File › Import › File (Fichier › Importer › Fichier), Import As: Composition - Retain Layer Sizes (Composition - Conserver la taille des calques) : un calque par élément. Une copie complète à 15 % d'Opacity (Opacité) sert de fantôme.
- In Point (point d'entrée) de chaque élément 12 im avant le marqueur de son mot. Traits : Layer › Create › Create Shapes from Vector Layer (Calque › Créer › Créer des formes à partir d'un calque vectoriel), puis Add › Trim Paths (Ajouter › Réduire les tracés), End 0 → 100 % en 16 im, Easy Ease (Lissage de vitesse, F9).
- Légende manuscrite : Animate › Opacity (Animer › Opacité) à 0 %, Range Selector (Sélecteur de plage) Start 0 → 100 % à 1 lettre par image. Boucles vivantes : expression `loopOut("cycle")` sur les gouttes et les bulles.
- Photocopieuse : une copie = Position +96 px et Opacity 0 → 100 % en 0,1 s, Rotation ±3° ; 5 calques décalés de 12 im par Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques). Bouteille : Rotation 0 → 110° en 10-15 im, F9.
- Révélation par taches : Effect › Transition › Gradient Wipe (Balayage dégradé) avec un calque Fractal Noise (Bruit fractal) comme dégradé, Transition Completion (Fin de transition) 0 → 100 % en 43 im, clé d'arrivée en ease-in.
