## La vraie matière : captures, vidéos et photos réelles détourées (real footage and screenshots, cutout compositing, background replacement)

Des images réelles servent de matière première : vraies pages de l'appli, vidéo de démo, partie du jeu, archive, personne filmée. On les détoure, on les étalonne selon le monde, on les assombrit en fond, on les incruste dans un objet. Une seule vraie capture déclinée fait preuve et continuité mieux qu'une illustration : chez gautam-mer1, une vidéo de 10 s joue quatre rôles. Vue dans 11 vidéos, dont 8 notées 4 ou 5.

**Règles de construction**

1. Une source, plusieurs rôles : la même vidéo dans l'écran, en plein cadre, dans la timeline et dans les cartes (gautam-mer1). Les mêmes photos passent du post au calendrier (miskinho). Le spectateur suit un contenu, pas des écrans.
2. En fond sous la typo : voile sombre d'environ 40 à 45 % et vignette radiale (deifosv 45 %, imthatcarlos 40 %). Vérifier les collisions avec l'interface du fond : chez deifosv, un titre se pose sur le tableau de score.
3. Détourer, puis étalonner selon le monde : le sujet adopte la matière du décor (sab8a). Le guide le dit aussi : « Une photo détourée sur fond transparent (PNG) donne un rendu nettement plus professionnel » (guide Otom, p. 9).
4. L'ajout graphique suit le réel à l'image près : carte qui naît sur la paume en 2 im, joues kawaii suivies sur le visage (sab8a). Un suivi en retard d'1 im dédouble l'image (twoclipping-221cab).
5. La matière garde la qualité du film : un clip généré à ≈ 12 im/s dans un film à 60 saccade (jesscaroline7). Un raster agrandi adoucit le texte (1stnoel). Les photos réalistes (broderie, sceau de cire chez jacksonfall) supposent des assets fournis.
6. La vraie matière doit vivre : 35 s de téléphone figé (1stnoel) ou 2,4 s gelées (deifosv) sont des temps morts. Calage, d'après les vidéos animées sur la musique : scènes de 2 ou 4 temps, contenu sur le kick à 0 à +2 im (deifosv). Chez lexnlin, coupes 1,8 im avant l'attaque, plans de 6 à 12 im.

Le guide prévient aussi que des images de mauvaise qualité donnent un résultat de mauvaise qualité (guide Otom, p. 4). Pour l'écran dans un appareil, voir chapitre 7, « La maquette d'appareil et l'interface reconstruite ». Pour la vidéo dans la lettre, voir chapitre 3, « La lettre comme image ».

**Verdict** : à reprendre. Pour une promo SaaS, c'est la preuve la plus forte : tes vraies captures NuOps, déclinées et assombries en fond, plutôt qu'une interface inventée.

**Quand l'utiliser** : en promo SaaS ou lancement, pour la preuve et la démonstration. En showreel éditorial avec des archives, en face caméra avec détourage. On réunit la matière au brief (captures, vidéo, logo, photos détourées), on fixe le voile et l'étalonnage au système de design. À éviter quand les sources sont floues, saccadées ou hors charte : mieux vaut une interface reconstruite.

**HyperFrames (GSAP)**

```js
// Vraie capture en fond assombri, une par stat sur 4 temps, coupe 3 im avant le kick
const FPS = 30, F = n => n / FPS;
const BEAT = 60 / 120;                          // 120 BPM : 1 temps = 15 im
const at = b => b * BEAT;
const LEAD = F(3);                              // coupe 3 im avant le kick (mesuré)
// CSS : .shot { background: url(capture.webp) center / cover }  ← vraie capture à 2× sa taille
//       .veil { background: radial-gradient(transparent 40%, rgba(0,0,0,.6)), rgba(0,0,0,.45) }
const shots = gsap.utils.toArray(".shot");      // une capture réelle par statistique
tl.set(shots, { autoAlpha: 0 }, 0);
shots.forEach((s, i) => {
  const kick = at(4 + 4 * i);                   // une stat = 4 temps (2 s)
  tl.set(s, { autoAlpha: 1 }, kick - LEAD)      // coupe sèche sur la nouvelle capture
    .set(shots.filter((_, j) => j !== i), { autoAlpha: 0 }, kick - LEAD)
    // la capture vit : poussée lente de 3 % sur sa scène, jamais figée
    .fromTo(s, { scale: 1 }, { scale: 1.03, duration: at(4), ease: "none",
        immediateRender: false }, kick - LEAD)
    // le chiffre arrive sur le kick : pop de 2 im
    .fromTo(s.querySelector(".stat"), { scale: 1.3, autoAlpha: 0 },
        { scale: 1, autoAlpha: 1, duration: F(2), ease: "power2.out", immediateRender: false }, kick);
});
// Objet posé sur un geste réel : la carte naît au-dessus de la paume en 2 im
const PALM = 9.92;                              // seconde où la main s'ouvre (f238 à 24 im/s)
tl.set("#idea-card", { autoAlpha: 0.4, scale: 0.6, rotation: -3 }, PALM)
  .to("#idea-card", { autoAlpha: 1, scale: 1, duration: 2 / 24, ease: "power2.out" }, PALM);
```

**After Effects**

- Fond assombri : capture réelle en plein cadre, puis Layer › New › Solid (Calque › Nouveau › Solide) noir à 45 % d'Opacity (Opacité). Ajouter un Mask (masque) elliptique inversé, Mask Feather (Contour progressif du masque) 400 px, pour la vignette.
- Coupe sur la grille : poser un marqueur par kick, couper chaque capture 3 im avant avec Edit › Split Layer (Édition › Fractionner le calque). Scale (Échelle) 100 → 103 % en linéaire sur la scène pour qu'elle vive.
- Détourage d'une personne filmée : outil Roto Brush (Pinceau Roto, Alt + W), propagé sur le plan, puis outil Refine Edge (Améliorer le contour). Contour sticker de 1 % : Layer › Layer Styles › Stroke (Calque › Styles de calque › Contour).
- Étalonnage par monde, sur la personne. Sépia : Effect › Color Correction › Tint (Correction colorimétrique › Teinte) et Effect › Noise & Grain › Add Grain (Bruit et grain › Ajout de grain). 8-bit : Effect › Stylize › Mosaic (Esthétique › Mosaïque).
- Objet incrusté ou carte sur la paume : Window › Tracker (Fenêtre › Suivi), Track Motion (Suivi de mouvement) sur la paume, Apply vers un Null Object (Objet nul), puis parenter la carte au nul. Vérifier image par image : 1 im de retard dédouble.
