## Étape 2 · Le message et le script : une idée, un budget de mots, une accroche

Cette étape tire du brief une phrase à retenir, un dispositif qui porte le film et un script écran par écran, avec le texte exact et son temps de lecture. On la fait avant la musique : le nombre d'écrans décide du nombre de mesures. Les films à fil rouge ou à concept unique ont environ 4,10 de moyenne (environ 40 vidéos, 7 notées 5) ; les catalogues à gabarit répété, 3,81 (environ 47 vidéos, 3 notées 5). On livre le script, dans un budget de mots fixé.

**Ce que font les meilleures vidéos**

- Une idée ordonne les plans. Avec le même prompt, [3D motion design showreel](https://prompt-motion.com/sahildesigner23-ee3155) (5/5) choisit un fil, le point, et un concept, le film qui se fabrique puis se rembobine. [Motion design showreel](https://prompt-motion.com/safarkhanshuvo-ffd52d) (4) aligne 8 univers en 1,875 s.
- Une consigne de direction crée la progression. « Meticulously art-directed rather than like a random collection of effects » change une liste de 12 techniques en suite point → ligne → plan → volume ([Motion techniques showreel](https://prompt-motion.com/lukasersil-0ed38e), 5/5). [Full Stop figure sequence](https://prompt-motion.com/hbcoop-de365c) (5/5) relie 9 savoir-faire par un seul objet.
- Une formule devient plan et chute. « Hello Opus 5.5 » devient « HI. I'M OPUS 5.5 » en ouverture et en boucle ([Kinetic type showreel](https://prompt-motion.com/zheke-38deff), 5/5).
- L'accroche est dans la première image : « hook in the first second » donne une image 0 déjà en mouvement (« click. ») dans [Supademo launch video](https://prompt-motion.com/jhylee95-e1152f).

**Ce qui manque aux moins bonnes**

- Une liste de fonctions fait un diaporama. [Animated business explainer](https://prompt-motion.com/alex-prompter-1ea044) (2/5) : 5 scènes de 4,6 à 7,8 s, immobile 83 % du temps. [Tally product demo](https://prompt-motion.com/visheshbaghell-3aba37) : 81 s pour tout montrer, 64 % d'images quasi fixes.
- L'ouverture traîne dans environ 50 vidéos : 1,8 s statiques ([Motion designer showreel](https://prompt-motion.com/zaqailo-212ad3)), 6 s sans accroche ([GravityDEX anime hype edit](https://prompt-motion.com/micheleharmonic-77628e)).
- Le texte passe trop vite, même dans 6 des 17 notées 5 : mots à 0,125 s ([Claude motion design showreel](https://prompt-motion.com/sudo-kiran-49176d)), rafales de 3 à 5 im ([Engraving-style Claude ad](https://prompt-motion.com/lexnlin-038035)).
- Pas de message propre : le même [Claude motion design showreel](https://prompt-motion.com/sudo-kiran-49176d) reste un « catalogue de tropes », sans « idée ni message propre ».

**Décisions** (valeur par défaut)

- La phrase à retenir, 15 mots au plus, que vérifiera le test des 3 secondes.
- Le dispositif : un objet, une forme ou une couleur qui traverse tous les plans ; par défaut, un objet du produit (voir *Le fil rouge : un objet, un exemple ou un plan continu traverse le film* et *Le dispositif unique : une métaphore ou un concept décliné dans chaque scène* au chapitre 10).
- L'arc : accroche (problème senti avant 1 s) → bascule → 1 ou 2 preuves → promesse → signature (voir *L'arc de pitch : problème → solution → preuves → appel*, *L'accroche de la première seconde* et *La chute : constat puis retournement* au chapitre 10).
- Le texte exact de chaque écran, son nombre de caractères et son temps de lecture minimal.
- Ce qu'on coupe : tout ce qui demande une explication. Une idée par écran.

**Livrable** : le script écran par écran, et le total de mots.

```text
SCRIPT · <produit> · à retenir : « … » (≤ 15 mots) · dispositif : <objet>
n° | texte exact                    | car. | mode   | lecture min. | fonction
1  | Leads en sommeil.              | 17   | phrase | 1,5 s        | accroche
2  | Relance. Réponse. Rendez-vous. | 30   | mots   | 3 × 0,2 s    | bascule
…
Total : <n> mots (budget : 15 à 25 pour 30 s)
```

**Règles**

1. Budget de mots : 15 à 25 pour un lancement de 30 s (35 au plus), 15 pour une vidéo produit (skill cinetic). Au plus 7 mots par écran en 16:9, 5 à 6 en 9:16 (motion-premiers-principes), 5 par ligne, 2 lignes par plan.
2. Temps de lecture, deux cas. Phrase à lire : 0,4 s + caractères / 15, plancher 1,0 s, +20 % en 9:16, compté après la fin de l'entrée. Mot à mot sur le temps : environ 0,2 s par mot, un par temps ; si la liste reste affichée, elle tient ensuite son temps de phrase (voir *Le calage mot à mot : un mot par temps, mot à mot sur la voix* au chapitre 3).
3. Jamais de gel pendant la tenue : poussée de 2 % ou pulsation sur le temps (voir *Le maintien : temps de lecture ou temps mort* au chapitre 9).
4. Accroche lisible avant 1 s, dans le problème : ni « Introducing », ni question rhétorique, ni logo (cinetic).
5. Trois tests (cinetic). Suppression : sans les plans de démo, la valeur se lit encore. Spécificité : un concurrent ne pourrait pas le dire. Mot de la fonction : un inconnu, sans le son, emploierait le mot du brief.

**La méthode Otom, corrigée**

On reprend l'étape 1 (guide Otom, p. 5) : le message tient en une phrase de mouvement (« un chiffre apparaît et grandit »). On reprend le test des 3 secondes (p. 6) : vu une fois, sans le son, le spectateur redit le message. On garde la consigne du prompt maître (p. 7) : « Ces textes sont définitifs : ne les reformule pas et n'ajoute aucun contenu fictif. » La Bible corrige deux règles anti-« template » (p. 6) : un texte reste « assez longtemps pour être lu », pas « immobile » ; plusieurs accents sont permis si chacun a un rôle. Surtout, pas de tenue forfaitaire de 1,5 s (p. 7) : la Bible a raison, le temps se calcule par mot.

**Erreur fréquente** : dérouler les fonctions au même gabarit, un écran chacune. Le film devient un diaporama : 3,81 de moyenne contre 4,10 avec un fil.

**Dans HyperFrames**

- Le script vit dans un seul fichier de données, lu par la composition ; aucun texte écrit en dur dans le HTML (skill cinetic).
- Avant de construire, passer la liste `début|fin|texte` dans `temps-lecture.py` (skill motion-premiers-principes) ; chaque « TROP COURT » se corrige dans le script.

```js
// Script écran par écran : seule source du texte affiché, contrôlé avant construction
const BEAT = 60 / 128, at = b => b * BEAT;          // 128 BPM : 1 temps = 0,469 s
const SCRIPT = [
  { n: 1, texte: "Leads en sommeil.", debut: at(0), fin: at(4), mode: "phrase" },
  { n: 2, texte: "Relance. Réponse. Rendez-vous.", debut: at(4), fin: at(8), mode: "mots" },
];
const mots = t => t.trim().split(/\s+/).length;
const lecture = l => l.mode === "mots"
  ? 0.2 * mots(l.texte)                               // mot à mot sur le temps
  : Math.max(1.0, 0.4 + l.texte.length / 15);         // phrase à lire
for (const l of SCRIPT) {
  const tenue = l.fin - l.debut - 0.3;                // moins l'entrée de 0,3 s
  if (tenue < lecture(l)) console.warn(`Écran ${l.n} trop court : ${tenue.toFixed(2)} s`);
  if (mots(l.texte) > 7) console.warn(`Écran ${l.n} : plus de 7 mots`);
  const el = document.querySelector(`#ecran-${l.n}`);
  el.textContent = l.texte;                           // le texte vient du script
  tl.set(el, { autoAlpha: 1, yPercent: 100 }, l.debut)
    .to(el, { yPercent: 0, duration: 0.3, ease: "power3.out" }, l.debut)
    .set(el, { autoAlpha: 0 }, l.fin);
}
```

**Dans After Effects**

- Un calque texte par écran, nommé « 01 accroche », « 02 bascule »…
- Pour une seule source : File › Import › File (Fichier › Importer › Fichier) d'un `script.json`, puis une expression sur Source Text (Texte source) : `footage("script.json").sourceData[0].texte`.
- Sur chaque calque, Layer › Markers › Add Marker (Calque › Marqueurs › Ajouter un marqueur) : sa Duration (durée) vaut le temps de lecture minimal, posée à la fin de l'entrée.
- Après validation, verrouiller les calques texte (Lock, cadenas) : le script ne bouge plus.
