## Les stores et les bandes en escalier (venetian blinds, staggered stripe wipe, stair-step wipe)

Plusieurs bandes couvrent ou traversent l'écran, décalées de 1 à 3 im entre elles, en alternance ou en escalier. Le décalage donne un rythme lisible, et la couleur des bandes annonce le plan B ou rappelle la marque. Dans la meilleure occurrence, le volet couvre le cadre en 14 im, soit un demi-temps à 128 BPM. Vue dans 43 vidéos, dont 41 notées 4 ou 5.

**Règles de construction**

1. 5 à 8 bandes de 8 à 20 % du cadre : 1/8 H (lukasersil), 8 % (tequilafunks), 1/6 L (andginja), 20 % (jayscambler, shinskinakamoto). Les bords d'attaque portent un flou de mouvement (lukasersil, tequilafunks, 3xtihor).
2. Décalage de 1 à 2 im entre bandes à 60 fps, 1 im à 30 fps (lukasersil, jasonzhou, shinskinakamoto, 3xtihor, tequilafunks).
3. Couvrir le cadre en 0,2 à 0,37 s (12 à 22 im à 60 fps), avec une courbe en S. Trois études 60 fps mesurent power1.inOut, power2.inOut et sine.inOut. En 2 à 3 im, le volet se lit comme un scintillement (himanshutwtxs, chatgptastra, à ralentir).
4. La couverture complète tombe sur le temps ou le demi-temps, et la révélation part de là. Départ sur le temps 7 (tequilafunks), stores ouverts sur le temps (vanshwtfff), sortie sur le 1er temps de la mesure (3xtihor). L'aplat plein tient 3 à 11 im (bizibeast, 3xtihor).
5. Les bandes prennent la couleur du plan B (crazyalphaaa, eyishazyer : la dernière bande a la couleur du fond suivant) ou de la marque (jayscambler, gonzalomacagno, arjunsh1607). Des couleurs sans lien avec le sujet font papier peint (adamdesgns, à adapter).
6. Un composant, pas un tic : le même volet pour chaque changement de chapitre (3 fois en 30 s chez bizibeast) installe un système. Toutes les 2 s, à l'identique (5 fois chez aistocksavvy), il s'use.

Le guide Otom propose un « volet rapide de 250 ms » comme transition franche (guide Otom, p. 10). C'est la durée mesurée ici : 14 im, soit 0,23 s, chez lukasersil et manuelogomigo.

**Verdict** : à reprendre. Ce sont tes stores vénitiens. La meilleure version naît d'un objet du plan A (barres du graphique chez vanshwtfff, texte caviardé chez ddryo-loos) et prend les couleurs du plan B.

**Quand l'utiliser** : en promo SaaS pour passer d'une fonction à l'autre, en showreel éditorial suisse ou Bauhaus, et en typo cinétique pour basculer de fond entre deux phrases. Elle sert la transition de chapitre et le récapitulatif de palette avant le logo (itsuki-dev). On choisit ses couleurs et son sens au système de design, comme un composant réutilisable ; on la place aux enchaînements. À éviter entre deux plans d'une même scène (l'objet relais fait mieux), ou plus d'une fois toutes les deux mesures.

**HyperFrames (GSAP)**

```js
// Stores : 6 bandes alternées gauche / droite, plein cadre sur le temps 8, puis révélation
const FPS = 60;
const BEAT = 60 / 128;                         // 128 BPM : 1 temps = 28,125 im
const at = b => b * BEAT;
const F = n => n / FPS;                        // images → secondes
const N = 6;
const COLORS = ["#2B3AF4", "#F5CF24", "#EB2A2A"];   // palette du plan B
const bars = gsap.utils.toArray(".bar");       // 6 divs pleine largeur, top = i × 100/N %,
                                               // height = 100/N % + 2 px (pas de fil entre bandes)
const FULL = at(8);                            // cadre couvert sur le temps 8
const IN = F(12), STAG = F(1);                 // 12 im par bande, 1 im d'écart (étude 60 fps)
const T0 = FULL - IN - STAG * (N - 1);         // départ calculé pour finir sur le temps

tl.set(bars, { xPercent: i => (i % 2 ? 101 : -101), backgroundColor: i => COLORS[i % 3], autoAlpha: 1 }, 0)
  // entrée : chaque bande glisse depuis son bord, en S
  .to(bars, { xPercent: 0, duration: IN, ease: "power1.inOut", stagger: STAG }, T0)
  // la coupe A → B a lieu sous l'aplat
  .set("#scene-a", { autoAlpha: 0 }, FULL)
  .set("#scene-b", { autoAlpha: 1 }, FULL)
  // tenue de 3 im, puis sortie dans le même sens : le bord arrière découvre B
  .to(bars, { xPercent: i => (i % 2 ? -101 : 101), duration: IN, ease: "power2.inOut", stagger: STAG }, FULL + F(3))
  .set(bars, { autoAlpha: 0 }, FULL + F(3) + IN + STAG * (N - 1));

// Variante escalier : toutes les bandes à xPercent -101 au départ,
// stagger: { each: STAG, from: "start" } pour que la bande du haut mène.
```

**After Effects**

- Six Shape Layers (calques de forme) Rectangle de 1920 × 180 px (1/6 de 1080), aux couleurs du plan B. Position X : hors cadre à gauche pour les bandes impaires, à droite pour les paires, puis centre en 12 im.
- Easy Ease (Lissage de vitesse, F9), puis influence 40 % en entrée et en sortie dans le Speed Graph (éditeur de graphe de vitesse) (≈ power1.inOut). Activer le Motion Blur (flou de mouvement).
- Décaler chaque bande d'1 im : Alt + Pg suiv. sur chaque calque, ou Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques), chevauchement = durée − 1 im.
- Caler la dernière bande pleine sur le marqueur du temps ; couper A et B sur cette image : Edit › Split Layer (Édition › Fractionner le calque). Tenir 3 im, puis animer la sortie de la même façon.
- L'effet Effect › Transition › Venetian Blinds (Stores vénitiens) fait des lamelles égales sans décalage ni couleur : à réserver à la variante lamelles.
