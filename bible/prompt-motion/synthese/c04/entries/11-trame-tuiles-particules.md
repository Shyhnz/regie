## La décomposition en trame, tuiles et particules (dither fade, halftone wipe, tile flood, particle dissolve)

L'image se défait en petites unités (points de trame, pixels, tuiles, particules) qui s'éteignent, se retournent ou se dispersent, puis se recomposent en plan B. Le passage est fait de la matière même de la vidéo : la liseuse e-ink se rafraîchit, la grille de points devient le fond, le nuage de particules devient le logo. Le front dure en général 12 à 20 im à 60 fps (0,2 à 0,33 s). Vue dans 33 vidéos, dont 32 notées 4 ou 5.

**Règles de construction**

1. La matière du passage existe déjà dans le plan : liseuse e-ink ([Product intro synced to music](https://prompt-motion.com/bogdandragomir-35e024)), grille de points, damier ou tuiles du système graphique. Sans grille ni pixel à l'écran, l'effet sent le logiciel.
2. Durée du front : 12 à 20 im à 60 fps. Mesures : 12 im ([Anime maid dance showreel](https://prompt-motion.com/topi-003-b0e12c)), 13, 17, 19, puis 20 im ([Kinetic type showreel](https://prompt-motion.com/itsuki-dev-10942d)). Un aplat qui sature peut tenir en 2 im s'il tombe sur un temps fort.
3. Un seul front lisible : d'un coin vers l'opposé, d'un bord, ou d'un point motivé vers les bords. Le décalage suit la distance (≈ 1 im par anneau). Les unités grossissent de minuscules à pleines sur une bande de 5 à 15 % du trajet.
4. Unités de 2,5 à 6 % de la largeur. Des tirets d'1 % de la largeur, pâles, ne se lisent plus ([Alan agent platform promo](https://prompt-motion.com/prasad-pilla-2c0cba)). Des tuiles inégales qui glissent sans direction brouillent la lecture ([Photo retouch app promo](https://prompt-motion.com/oliahmed205-3e31c4)).
5. Départ sur un temps, cadre couvert au demi-temps ou au temps suivant, à ±1 im. Pour une reformation, la forme doit être lisible ≈ 10 im après le temps. Les particules gardent d'abord la silhouette d'origine.
6. Une forme par passage. [Motion design principles reel](https://prompt-motion.com/tolgayhickiran-e90799) répète 4 fois le même volet en blocs ; change la direction ou l'unité à chaque fois.

**Verdict** : à reprendre, quand le système graphique a déjà une trame, une grille ou des pixels. C'est la version « machine » de ta feuille qui devient logo (particules → cadenas). L'iris de grain qui sort de l'écran du produit prolonge ta révélation circulaire.

**Quand l'utiliser** : en promo SaaS à l'esthétique e-ink, pixel ou données, et en showreel éditorial suisse à grille. En typo cinétique 1600, pour changer de chapitre. Fonction : transition entre chapitres, signature (particules qui forment le logo), ouverture et fermeture en boucle (trame Bayer). La trame se décide au système de design, puis se pose à l'étape des enchaînements. À éviter sur un style photo, 3D réaliste ou personnages sans grille, et plus d'une fois par vidéo sous la même forme.

**HyperFrames (GSAP)**

```js
// Volet en demi-teinte : 32 × 18 carrés qui naissent du coin haut gauche (aucun plugin)
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 120;                      // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT;
const COLS = 32, ROWS = 18;                 // carrés de ≈ 2,8 % de la largeur
const box = document.querySelector("#tiles");   // calque plein cadre au-dessus des plans,
for (let i = 0; i < COLS * ROWS; i++) {         // display: grid, 32 colonnes, joints de 2 px
  box.appendChild(Object.assign(document.createElement("i"), { className: "tile" }));
}
const T0 = at(24);                          // 1er temps de la mesure 7
const wave = { grid: [ROWS, COLS], from: 0, amount: f(13) };  // décalage selon la distance au coin
tl.set(".tile", { scale: 0 }, 0)
  .set("#sceneB", { autoAlpha: 0 }, 0);
// 1. Le front part 2 im avant le temps : chaque carré grossit en 4 im, la vague dure 13 im
tl.to(".tile", { scale: 1, duration: f(4), ease: "power2.out", stagger: wave }, T0 - f(2));
// 2. Cadre couvert au demi-temps : on échange les plans sous la trame
tl.set("#sceneA", { autoAlpha: 0 }, T0 + at(0.5))
  .set("#sceneB", { autoAlpha: 1 }, T0 + at(0.5));
// 3. La trame se retire dans le même sens, B est plein 1 im avant le temps suivant
tl.to(".tile", { scale: 0, duration: f(4), ease: "power2.in",
  stagger: { ...wave, amount: f(9) } }, T0 + at(0.5) + f(1));
```

**After Effects**

- Grille : Shape Layer (calque de forme) Rectangle de 2,8 % de la largeur, puis Add › Repeater (Ajouter › Répéteur) deux fois (32 copies en X, 18 en Y). Pour une trame tirée du plan lui-même : Effect › Simulation › CC Ball Action (Effet › Simulation › CC Ball Action).
- Front en demi-teinte : Effect › Transition › Gradient Wipe (Effet › Transition › Balayage en dégradé) sur le plan A. Le Gradient Layer (Calque de dégradé) est une Pre-comp (précomposition) d'un dégradé linéaire en diagonale. Ajouter l'effet Noise (Bruit), ≈ 40 %, pour le bord granuleux e-ink.
- Transition Completion (Achèvement de la transition) de 0 à 100 % en 17 im à 60 i/s, 2 im avant le temps jusqu'au demi-temps. Keyframes en Linear (images clés linéaires) pour une vitesse constante ; influence d'arrivée à 60 % dans le Speed Graph (éditeur de graphe de vitesse) pour le volet e-ink.
- Particules qui forment un logo : faire éclater le logo avec Effect › Simulation › CC Pixel Polly, Pre-compose (précomposer), puis Layer › Time › Time-Reverse Layer (Calque › Temps › Inverser le temps du calque). Les éclats se rangent en logo en 10 à 12 im.
- Une seule vague par passage ; pour la suivante, changer le coin de départ ou la forme des unités.
