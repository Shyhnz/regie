## Le chapitrage : un chapitre par mesure (chaptering, one bar per chapter, numbered sections, step tabs)

Le film est découpé en chapitres égaux, une idée chacun, signalés par un numéro ou un onglet (« 01 / 08 », HUD, onglets d'étapes). Chez les meilleurs, chaque coupe tombe sur le premier temps d'une mesure : 2 s à 120 BPM, 1,875 s à 128 BPM. La durée fixe rend la structure lisible et cale le montage sur la musique. Vue dans 81 vidéos, dont 64 notées 4 ou 5.

**Découpage type**

Nombre de mesures = durée × BPM ÷ 240. Pour 15 s à 128 BPM, 8 mesures de 1,875 s : ouverture, 5 chapitres, rafale ou récap, signature (fionntobin, ghinaiya-nirmal, shneural). À 120 BPM, 7,5 mesures : 6 chapitres de 2 s, récap de 1,5 s, logo de 1,5 s (sudo-kiran-49176d). À 96 BPM, 6 mesures de 2,5 s (bogdandragomir, étude 60 fps).

**Règles de construction**

1. Choisir un tempo qui donne des mesures entières : 15 s = 32 temps à 128 BPM (fionntobin, stephanlivera), 30 temps à 120 BPM. Un chapitre = 4 temps ; 5 temps pour un chapitre phare (crazyalphaaa).
2. Couper sur l'image calculée du 1er temps, jamais sur une grille arrondie. À 128 BPM et 60 fps, le temps vaut 28,125 im : alterner 28 et 29 im (stephanlivera, étude 60 fps). Coupes mesurées à 0 à +1 im (fionntobin, stephanlivera, bogdandragomir).
3. La transition chevauche la frontière. La sortie démarre 4 im (sudo-kiran-49176d) à 15 im (tequilafunks, 30 fps) avant la coupe ; le plein cadre frappe le temps.
4. L'étiquette est un repère, pas un message : mono capitales de 1,2 à 1,7 % H dans un coin (charlesmendez, sahildesigner23, 1stnoel). Elle change à l'image de la coupe, et disparaît sur la signature (jasonzhou1993).
5. Une idée par chapitre, et une montée : les derniers plans raccourcissent (tequilafunks ; teslachartz, 6 plans de 15 im ; adamdesgns). Sans montée, c'est un catalogue : 6 sections de 5,6 à 6,4 s au même traitement (ai-baymax-0ef9dd), 9 chapitres de 1,5 s sans progression (motiondsgnr).
6. Chaque chapitre naît d'un objet du précédent : le post devient 6 déclinaisons, puis un calendrier (miskinho, 1 mesure à 125 BPM chacun). Sinon la numérotation n'est qu'un sommaire décoratif.

**Verdict** : à reprendre. C'est la grille la plus sûre pour un film de 15 s calé sur la musique. Un chapitre par mesure, un geste par temps : c'est le rythme 1600. En promo, remplace les noms de disciplines par les étapes d'usage ou les onglets réels du produit.

**Quand l'utiliser** : showreel éditorial, typo cinétique 1600, promo SaaS en visite du produit, explainer à étapes. C'est l'ossature du film entier, de l'ouverture à la signature. On la choisit au découpage en plans, juste après la grille musicale, en comptant les mesures disponibles. À éviter au-delà de 30 s sans montée (ezshine-c90d73, ai-baymax-0ef9dd), ou si le message tient en une idée : préférer un dispositif unique.

**HyperFrames (GSAP)**

```js
// Un chapitre par mesure : coupe sur l'image calculée du 1er temps, HUD qui suit
const FPS = 60;
const BPM = 128;
const BEAT = 60 / BPM;                         // 0,46875 s = 28,125 im
const at = b => b * BEAT;
const F = n => n / FPS;
const snap = t => Math.round(t * FPS) / FPS;   // 28 ou 29 im : la grille ne dérive pas
const chapters = gsap.utils.toArray(".chapter");  // 8 scènes plein cadre empilées
const labels = gsap.utils.toArray(".hud-label");  // un span par chapitre : « 01 / 08 · GRID »…
const last = chapters.length - 1;              // le dernier = la signature, sans HUD

tl.set([...chapters, ...labels], { autoAlpha: 0 }, 0);
chapters.forEach((ch, i) => {
  const cut = snap(at(4 * i));                 // 1er temps de la mesure i + 1
  const out = snap(at(4 * (i + 1)));
  tl.set(ch, { autoAlpha: 1 }, cut);
  if (i > 0) tl.set(labels[i - 1], { autoAlpha: 0 }, cut);
  if (i === last) return;
  tl.set(labels[i], { autoAlpha: 1 }, cut);
  // Sortie à cheval sur la frontière : la forme de sortie (couleur du chapitre suivant)
  // part 14 im avant et couvre le cadre pile sur le temps
  const exit = ch.querySelector(".exit");
  tl.set(exit, { scale: 0 }, 0)
    .to(exit, { scale: 1, duration: F(14), ease: "power3.in" }, out - F(14))
    .set(ch, { autoAlpha: 0 }, out);
});
```

**After Effects**

- Poser un marqueur sur chaque 1er temps : Layer › Markers › Add Marker (Calque › Marqueurs › Ajouter un marqueur), ou la touche * du pavé numérique. À 128 BPM et 60 i/s, une mesure = 112,5 im : alterner 112 et 113 im.
- Monter chaque chapitre dans sa précomposition : Layer › Pre-compose (Calque › Précomposer), longue d'une mesure. Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques) les aligne. Cocher Overlap (Chevauchement) à 14 im.
- HUD : un seul calque de texte mono capitales à 1,5 % H, dans un coin. Sa propriété Source Text (Texte source) reçoit une image clé par chapitre, sur chaque marqueur ; ces clés sont toujours maintenues.
- Sortie : une Ellipse de la couleur du chapitre suivant, Scale (Échelle) de 0 à plein cadre en 14 im, finie sur le marqueur. Dans le Speed Graph (éditeur de graphe de vitesse), influence sortante 75 % sur la 1re clé, clé d'arrivée sans lissage (≈ power3.in).
- Masquer le calque HUD sur la dernière mesure (signature) : Opacity (Opacité) à 0 % sur le dernier marqueur.
