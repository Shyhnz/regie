## La signature finale : logo, slogan, appel, sans temps mort (end card, logo lockup, tagline + URL + CTA, outro)

Le dernier plan assemble la marque en cascade sur les temps : icône, mot-symbole démasqué, slogan, URL ou commande, parfois un bouton cliqué. Il dure environ une mesure et sort par un fondu au noir ou des volets, calés sur la fin du son. Dans les vidéos notées 5/5, l'image vraiment figée dure 0,1 à 1,2 s, et un élément reste souvent vivant. Vue dans 110 vidéos, dont 86 notées 4 ou 5.

**Mesures (60 fps)**

- Durée du plan final : environ une mesure. 1,85 s (fionntobin), 1,8 s (manuelogomigo), 2,2 s (tequilafunks), 2,6 s (steventey).
- Image vraiment figée en fin de film : 6 im (web3wesley), 20 im (manuelogomigo), 25 im (grace-sunnyy, après 95 im de halo qui pulse). Puis 30 im (tequilafunks), 46-47 im (steventey, fionntobin), 71 im (lexnlin).
- Cascade : un élément par temps ou demi-temps. Steventey : iris 5 im, marque réduite en expo.out 34 im, puis le logotype. Ensuite un mot du slogan toutes les 6 im, et les boutons en 12 im.
- Sortie calée sur le son : fondu au noir 12 im power1.inOut, noir sur les 2 dernières images (sudo-kiran-49176d). Ou volets haut et bas en 9 im qui accélèrent, son de −18 à −97 dB (crazyalphaaa).

**Règles de construction**

1. Un élément par temps, quatre étages au plus : marque, mot-symbole, slogan, URL ou bouton. Le mot-symbole se démasque depuis l'icône (lexnlin, manuelogomigo, wozu-co, ratheejaisal).
2. Gel final de 0,1 à 1,2 s. Pour tenir plus, un micro-mouvement : logo en égaliseur toutes les 2 à 4 im (shinskinakamoto), halo qui pulse (grace-sunnyy). Ou un curseur qui clignote (hbcoop), un reflet sur le bouton (agonaliu).
3. La fin répond au début : le point d'ouverture revient (web3wesley, zaqailo), le slogan reprend l'accroche (utopyaszx, thismacapital), le sommaire revient complété.
4. Lisible sur un téléphone : nom à 13 % H ou plus (astrodevil 13 %, stephanlivera 16 %). Les mentions mono à 1 à 1,5 % H ne sont qu'un décor. Un nom à 3 % H, tenu 2,5 s, est un cliché (ultimaxbt).
5. Un appel concret, propre au produit : URL, commande d'installation (misbahsy, « $ pip install litellm »), « AVAILABLE FOR WORK » pour un reel. Garder le système de la vidéo : un outro aux autres police et fond casse l'univers (kloss-xyz, kantamk).

Le guide Otom demande un écran final d'au moins 2,5 s (guide Otom, p. 14). Nos mesures disent l'inverse : 2,5 s figées sont un temps mort (ultimaxbt, sudo-kiran-b055de). La Bible retient ses mesures. Du guide, on garde le bouton « qui pulse une seule fois » (guide Otom, p. 10) : c'est un micro-mouvement.

**Verdict** : à reprendre, avec une tenue courte et vivante. C'est la fin « sans temps mort » du style 1600 : le dernier accent (le point) revient une seule fois, sans se répéter partout.

**Quand l'utiliser** : toute vidéo en lecture unique. Promo SaaS : logo, URL, bouton. Showreel : nom et disponibilité. Typo cinétique : le point final. On fixe ses éléments au système de design (lockup, couleurs) et sa durée au découpage : une mesure, calée sur la fin de la musique. À éviter dans une boucle de fil d'actualité, où la dernière image doit rejoindre la première.

**HyperFrames (GSAP)**

```js
// Signature en une mesure à 120 BPM : point qui tombe sur le temps, rôle, pied de page tapé,
// tenue vivante, fondu au noir (mesures de tequilafunks ramenées à 60 fps)
const FPS = 60;
const BEAT = 60 / 120;                       // 1 temps = 30 im ; film de 15 s = 30 temps
const at = b => b * BEAT;
const F = n => n / FPS;
const H = 1080;
const S = at(26);                            // contact du point = temps 26 (13,0 s)
tl.set(["#dot", "#role", "#status", "#black"], { autoAlpha: 0 }, 0)
  .set("#role", { y: 0.04 * H }, 0)
  .set("#footer", { clipPath: "inset(0 100% 0 0)" }, 0)
  .set("#dot", { autoAlpha: 1, y: -0.38 * H }, S - F(12))
  .to("#dot", { y: 0, duration: F(12), ease: "sine.inOut" }, S - F(12))
  .set("#dot", { scaleX: 1.47, scaleY: 0.68 }, S)          // écrasé 2,15:1 sur 1 image
  .set("#dot", { scaleX: 1, scaleY: 1 }, S + F(2));
[[28, 0.146], [16, 0.029], [8, 0.006]].reduce((t, [d, h]) => {   // rebonds, hauteur × 0,2
  tl.to("#dot", { y: -h * H, duration: F(d / 2), ease: "sine.out" }, t)
    .to("#dot", { y: 0, duration: F(d / 2), ease: "power1.in" }, t + F(d / 2));
  return t + F(d);
}, S);
tl.to("#role", { autoAlpha: 1, y: 0, duration: F(12), ease: "power3.out" }, S)
  .to("#footer", { clipPath: "inset(0 0% 0 0)", duration: F(34), ease: "steps(34)" }, S + F(16))
  .to("#status", { autoAlpha: 1, duration: F(8), ease: "power1.out" }, S + F(20));
for (let k = 0; k < 2; k++) tl.set("#caret", { autoAlpha: k % 2 ? 1 : 0 }, at(28 + k)); // 1 temps sur 2
tl.to("#black", { autoAlpha: 1, duration: F(12), ease: "power1.inOut" }, at(30) - F(14));
```

**After Effects**

- Point : un calque de forme Ellipse. Position en Y : chute de 12 im jusqu'au marqueur du temps 26. Puis rebonds de 28, 16 et 8 im, hauts de 14,6, 2,9 et 0,6 % H. Speed Graph (éditeur de graphe de vitesse) : influence 70 % au sommet de chaque rebond.
- Écrasement : Scale (Échelle) 147 / 68 % pendant 2 images au contact. Clés en Toggle Hold Keyframe (Image clé maintenue), puis retour à 100 %.
- Lockup : l'icône glisse de −31 % L en 14 im (Easy Ease (Lissage de vitesse), F9). Le mot-symbole se révèle par un Mask Path (Tracé du masque) gauche → droite en 17 im, 7 im avant la fin du glissé.
- Pied de page tapé : panneau Effects & Presets (Effets et paramètres prédéfinis) › Animation Presets › Text › Animate In › Typewriter (Machine à écrire). Régler 1 caractère par image. Curseur : expression d'Opacity (Opacité) `Math.floor(time / 0.5) % 2 ? 100 : 0` (1 temps sur 2).
- Sortie : un Solid (Solide) noir, Opacity de 0 à 100 % en 12 im, fini 2 im avant la fin. La musique s'éteint en même temps.
