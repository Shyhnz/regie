## Le récapitulatif en rafale avant la signature (recap montage, accelerating rewind, recap grid)

Juste avant le logo, tous les chapitres repassent en accéléré. C'est un mot par croche ou double-croche dans le style de son chapitre, un rembobinage qui accélère, ou une mosaïque de vignettes vivantes. Il résume le film en 1,4 à 2,5 s et crée un pic d'énergie juste avant la fin, au lieu d'un creux. Les trois vidéos notées 5 de la famille le placent entre 10 et 13,5 s d'un film de 15 s, juste avant le logo. Vue dans 15 vidéos, dont 12 notées 4 ou 5.

**Règles de construction**

1. Une mesure, pas plus : 90 im à 60 fps ([Claude motion design showreel](https://prompt-motion.com/sudo-kiran-49176d)), 60 im à 30 fps ([Claude motion design reel](https://prompt-motion.com/tequilafunks-97f6c9)), 99 im de rembobinage. Elle finit 1,5 à 3 s avant la fin du film : le logo prend le reste.
2. Un plan par subdivision : 7,5 im (double-croche à 120 BPM, 60 fps) est le plus court mesuré pour un mot lisible. Ce mot doit déjà avoir été vu : le récap rappelle, il n'apprend rien.
3. Chaque plan garde la direction artistique de son chapitre (fond, couleur, typo). Fonds alternés sur 4 couleurs dans [Claude motion design reel](https://prompt-motion.com/tequilafunks-97f6c9) : l'œil reconnaît le chapitre avant de lire le mot.
4. Accélérer jusqu'au nom : divisions 2, 2, 1, 1, ½ × 4 temps, ou rembobinage power1.inOut. La dernière coupe débouche sur un flash ou un iris pile sur le temps. Flash : pic sur le temps, retombée power4.out en 26 im.
5. Coupe : 1 image de fondu sur les croches, coupe sèche sur les doubles-croches intermédiaires ; chaque plan garde un micro-geste (réduction de 8 %, séparation RGB qui se résorbe en 3 im).
6. Une grille reste vivante : chaque vignette rejoue sa scène, assombrie de 40 à 50 % si une phrase se pose dessus. Une grille posée puis figée 4,3 s ([Steam new releases news recap](https://prompt-motion.com/gigabit-million-16b3a0)) redevient une diapositive.

Le guide Otom (p. 13, fiche 10) range 4 indicateurs dans une grille 2 × 2 en 4 s, puis le logo. C'est la version lente : nos vidéos notées 5 font le même résumé en 1,5 à 2 s, sans arrêt.

**Verdict** : à reprendre. C'est la version musicale du récap, et la grammaire 1600 pure : un mot par subdivision, aucun temps mort avant le logo. Le rembobinage est la variante la plus élégante quand le film a une interface ou une timeline visible.

**Quand l'utiliser** : en showreel, en typo cinétique 1600 et en promo SaaS qui présente au moins 4 fonctions ; fonction de sortie, juste avant la signature. On le prévoit au découpage (la mesure qui précède le logo lui est réservée), puis on le règle aux enchaînements, avec le flash ou l'iris vers le logo. À éviter sous 4 chapitres ou sous 10 s : il n'y a rien à rappeler. En explainer à voix off, préférer les perles sur le fil, une par temps.

**HyperFrames (GSAP)**

```js
// Récap en doubles-croches : 12 plans de 7,5 im, flash sur le temps, puis le nom (120 BPM, 60 i/s)
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 120;                       // 1 temps = 30 im
const at = b => b * BEAT;
const T = at(24);                            // 1er temps de la mesure 7
const S = at(0.25);                          // double-croche = 7,5 im
const shots = gsap.utils.toArray("#recap .shot");   // un mot par chapitre, dans sa DA
const end = T + shots.length * S;            // 12 plans : temps 27
tl.set(shots, { autoAlpha: 0 }, 0)
  .set("#flash", { autoAlpha: 0 }, 0)
  .set("#logo .char", { autoAlpha: 0, scale: 1.9 }, 0);
shots.forEach((el, i) => {
  const t0 = T + i * S;
  if (i > 0 && i % 2 === 0) {                // sur la croche : 1 image de fondu
    tl.to(el, { autoAlpha: 1, duration: f(1), ease: "none" }, t0 - f(1));
  } else {                                   // double-croche intermédiaire : coupe sèche
    tl.set(el, { autoAlpha: 1 }, t0);
  }
  tl.fromTo(el, { scale: 1.08 }, { scale: 1, duration: S, ease: "power2.out", immediateRender: false }, t0)
    .set(el, { autoAlpha: 0 }, t0 + S);      // le plan suivant est au-dessus
});
// Flash sur le temps, retombée power4.out en 26 im
tl.set("#flash", { autoAlpha: 1 }, end)
  .to("#flash", { autoAlpha: 0, duration: f(26), ease: "power4.out" }, end + f(1));
// Le nom : lettres de ×1,9 à ×1 en 12 im, 2,4 im d'écart, éclaircies en 4 im
tl.to("#logo .char", { scale: 1, duration: f(12), ease: "power2.out", stagger: f(2.4) }, end + f(4))
  .to("#logo .char", { autoAlpha: 1, duration: f(4), ease: "none", stagger: f(2.4) }, end + f(4));
```

**After Effects**

- Chaque mot dans la DA de son chapitre : Layer › Pre-compose (Calque › Précomposer), un précomp par chapitre. Couper chaque calque à 8 puis 7 im en alternance (7,5 im en moyenne à 60 i/s).
- Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques), sans chevauchement. Sur les calques pairs, Opacity (Opacité) de 0 à 100 % en 1 im au début.
- Micro-geste : Scale (Échelle) de 108 à 100 % sur la durée du plan, Speed Graph (éditeur de graphe de vitesse) avec une influence d'arrivée de 80 %.
- Flash : Layer › New › Solid (Calque › Nouveau › Solide) blanc, Opacity 100 → 0 % en 26 im, influence d'arrivée 90 %. Le nom : animateur de texte Scale 190 % avec Range Selector (Sélecteur de plage) basé sur les caractères, 12 im.
- Variante rembobinage : précomposer tout le film, puis Layer › Time › Enable Time Remapping (Calque › Temps › Activer le remappage temporel). Aller de la fin à 0 s en 99 im, influence de 60 % aux deux images clés, puis figer 12 im sur la 1re image.
