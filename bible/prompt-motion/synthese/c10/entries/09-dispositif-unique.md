## Le dispositif unique : une métaphore ou un concept décliné dans chaque scène (extended metaphor, governing concept, self-demonstrating content)

Une seule idée gouverne tout le film et chaque scène la décline. Ce peut être une métaphore filée (le CV comme jeu vidéo), un objet-horloge (le soleil comme compte à rebours) ou un contenu qui se démontre lui-même (« IN. » bouge en ease-in). Le concept rend le film mémorable et donne une règle pour inventer chaque plan. C'est la famille la mieux notée du chapitre : 5 des 31 vidéos ont 5/5. Vue dans 31 vidéos, dont 29 notées 4 ou 5.

**Règles de construction**

1. Une règle énonçable en une phrase, qui fabrique chaque plan : « chaque compétence est un niveau », « chaque mot subit ce qu'il nomme ». On la choisit avant le découpage, pas pendant.
2. Le concept se montre, il ne se dit pas. Des légendes de règle à 1,5-2 % H tenues moins de 2 s sont illisibles ([Blue editorial motion showreel](https://prompt-motion.com/fionntobin-97b7af)). Un titre qui annonce sa propre technique est un cliché ([DeFi Saver stop-motion explainer](https://prompt-motion.com/nikolajankovic-ce4ff4)).
3. Un sujet par chapitre, un chapitre par mesure : 112,5 im à 128 BPM ([Swiss-style motion showreel](https://prompt-motion.com/levabashidze-2d713a)), 2 temps par verbe à 120 BPM ([Supademo launch video](https://prompt-motion.com/jhylee95-e1152f)), 30 im par principe ([Motion designer showreel](https://prompt-motion.com/hanifproduktif-54bdee)).
4. La démonstration doit être exacte : les six courbes du tableau de [Easing and morphing showreel](https://prompt-motion.com/roundtablespace-d3a1be) collent aux eases GSAP par défaut à 0,3-1,5 % près. Un mot « EASE IN » qui bouge en linéaire détruit le concept.
5. L'objet-concept ouvre et ferme le film. L'astérisque d'ouverture revient en logo ; la balle revient en point final, avec la même chute power1.in de 13 im ; le compte à rebours atteint zéro au dernier plan.
6. Varier la technique, jamais le concept : 6 traitements du même 100, une figure différente par phrase ([Oscilloscope-style studio motion graphic](https://prompt-motion.com/rneayan-ea6129)).

Le guide Otom (p. 10) confie le problème d'une pub de 15 s à « un objet métaphore qui se brise » pendant 3 s. Le sablier d'Alan fait mieux : le même objet porte le problème, puis la solution.

**Verdict** : à reprendre. C'est le choix qui distingue un film d'une suite de jolis plans. Pour une promo SaaS, la meilleure forme est celle de Supademo : chaque verbe du produit exécute sa propre fonction, sans plan explicatif.

**Quand l'utiliser** : pour un showreel (la leçon de motion), une promo SaaS (le verbe produit qui se démontre, la métaphore du problème), un explainer ou un film à personnages (métaphore filée). On le décide à l'étape message et script, et on le confirme à la direction artistique : il fixe ensuite le contenu de chaque plan au découpage. À éviter quand la métaphore demande une phrase pour être comprise. En promo, remplacer le contenu « motion design » autoréférent par le message produit.

**HyperFrames (GSAP)**

```js
// 1. Le mot fait ce qu'il dit : chaque mot suit la courbe qu'il nomme (128 BPM, 60 i/s)
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128;                       // 1 temps = 28,125 im ; croche = 14 im
const at = b => b * BEAT;
const T = at(24);                            // 1er temps de la mesure 7
const words = [                              // [sélecteur, x départ, x arrivée, courbe, durée en im]
  ["#w-in",     -900, 0,   "power2.in",     6],    // IN. accélère et s'arrête net
  ["#w-out",    1700, 0,   "expo.out",      13],   // OUT. arrive d'un coup et freine
  ["#w-never",  1100, 0,   "back.out(1.7)", 11],   // NEVER dépasse puis revient
  ["#w-linear", -210, 210, "none",          28],   // LINEAR. 0,78 % L par image, constant
];
tl.set(words.map(w => w[0]), { autoAlpha: 0 }, 0);
words.forEach(([sel, x0, x1, ease, n], i) => {
  const t0 = T + i * at(0.5);                // une coupe par croche
  tl.set(sel, { autoAlpha: 1, x: x0 }, t0)
    .to(sel, { x: x1, duration: f(n), ease }, t0);
  if (i < words.length - 1) tl.set(sel, { autoAlpha: 0 }, t0 + at(0.5));
});
// 2. Objet-horloge : compte à rebours 00:SS:FF piloté par la timeline (aucune horloge système)
const END = at(56);                          // instant où l'objet-concept s'éteint
const clock = { t: 0 };
const pad = v => String(v).padStart(2, "0");
tl.to(clock, { t: END, duration: END, ease: "none", onUpdate: () => {
  const r = Math.max(0, END - clock.t), s = Math.floor(r), fr = Math.floor((r - s) * 30);
  document.querySelector("#clock").textContent = `LAST LIGHT IN 00:${pad(s)}:${pad(fr)}`;
} }, 0);
```

**After Effects**

- Un chapitre par mesure : Layer › Markers › Add Marker (Calque › Repères › Ajouter un repère) tous les 112,5 im à 128 BPM, puis un précomp par chapitre avec Layer › Pre-compose (Calque › Précomposer).
- IN. : Position x en 2 images clés à 6 im d'écart ; dans le Speed Graph (éditeur de graphe de vitesse), influence de départ 75 %, arrivée 0 % : le mot accélère et s'arrête net. OUT. : l'inverse sur 13 im, départ 0 %, arrivée 90 %.
- NEVER : une image clé intermédiaire à 110 % du trajet vers la 7e image, retour à 100 % à la 11e. LINEAR. : Animation › Keyframe Interpolation (Animation › Interpolation des images clés) › Linear (Linéaire), 420 px en 28 im.
- Compte à rebours : calque de texte, expression sur Source Text (Texte source) : `r = Math.max(0, 27.73 - time); s = Math.floor(r); f = Math.floor((r - s) * 30); "00:" + ("0" + s).slice(-2) + ":" + ("0" + f).slice(-2)`.
- L'objet qui ouvre le film referme le film : Edit › Duplicate (Édition › Dupliquer) du calque d'ouverture, placé sur la dernière mesure avec la même courbe.
