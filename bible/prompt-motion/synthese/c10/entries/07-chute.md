## La chute : constat puis retournement (punchline, setup-twist, rule of three, label flip)

Une mise en place est retournée par un dernier mot court, plus gros ou plus petit, tenu juste le temps d'être lu. La mise en place peut être deux éléments rayés, une échelle vertigineuse, un flot verbeux ou une étiquette. Le contraste entre la mise en place et la réponse fait retenir le message : sans mise en place, la phrase-choc n'est qu'un slogan de plus. Dans la vidéo notée 5, la réponse « JUST CODE. » est figée 24 im (0,4 s à 60 fps), pas plus. Vue dans 22 vidéos, dont 16 notées 4 ou 5.

**Règles de construction**

1. Mise en place en deux éléments, ou un flot, puis une réponse de 1 à 3 mots. Le guide Otom (p. 13) fixe 12 mots maximum pour toute la phrase : au-delà, « le rythme s'effondre ».
2. Marquer la chute par une rupture franche. Soit l'échelle, d'au moins ×5 : « ONE BOOK. » à 4 % H après des capitales géantes, l'aparté à 3 % H sous « 3. » à 22 % H. Soit le fond : crème, bleu, puis noir pour la réponse ([Kinetic type showreel](https://prompt-motion.com/zheke-38deff)).
3. Rythme de la règle de trois à 128 BPM : un élément tous les 1,5 temps (42 im à 60 fps), rature sur le demi-temps. La réponse tombe sur le temps, le point final au demi-temps suivant.
4. Tenir la chute 20 à 24 im si la signature suit, 1,2 à 1,4 s si c'est la dernière image. Un carton seul tient une mesure : entrée 0,5 s, tenue 1,0 s, sortie 0,45 s ([Animated short about a bug](https://prompt-motion.com/kamstudiolabs-c9bb28)). À éviter : 2,6 s figées sans sortie ([Negroni recipe animation](https://prompt-motion.com/ror-fly-9950f1)).
5. Une couleur d'accent réservée à la chute (point orange, boîte rose, titre orange) et absente de la mise en place.
6. Caler la réponse sur un temps : posée 5 im après le temps ([sweetRegret app update reel](https://prompt-motion.com/thilina-a-891c09)), la légende-gag perd son effet.

Le guide Otom (p. 13) décrit la même mécanique : « des fenêtres » barré par un trait qui se dessine, puis « au chaud » dans la couleur d'accent. Il prévoit des pauses de 1,5 et 2 s. Nos mesures donnent 22 à 24 im : garde les pauses longues seulement si la chute est tout le film.

**Verdict** : à reprendre. C'est la forme la plus nette pour dire « nous, pas eux » sans phrase explicative. La rature orange ou le point final qui se pose donnent un geste signature, à condition de ne l'utiliser qu'une fois par film.

**Quand l'utiliser** : en typo cinétique 1600 et en promo SaaS, comme chute avant la signature ou comme accroche (le flot verbeux puis « yes. » ouvre un film). On l'écrit à l'étape message et script (mise en place, réponse, 12 mots maximum), puis on lui réserve une mesure au découpage. Une par film dans un reel de 15 s ; une par chapitre seulement dans un explainer long, où le spectateur apprend à l'attendre. À éviter sans mise en place : la réponse seule devient un slogan.

**HyperFrames (GSAP)**

```js
// Règle de trois : deux mots rayés, puis la réponse et son point final (128 BPM, 60 i/s)
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128;                       // 1 temps = 28,125 im
const at = b => b * BEAT;
const T = at(24);                            // drop : 1er temps de la mesure 7
const step = at(1.5);                        // un élément tous les 1,5 temps
tl.set(["#w2", "#answer"], { autoAlpha: 0 }, 0)
  .set(".strike", { scaleX: 0, transformOrigin: "0% 50%" }, 0)
  .set("#w1", { clipPath: "inset(0% 100% 0% 0%)" }, 0)
  .set("#answer .line", { yPercent: 110 }, 0)   // lignes sous un masque (overflow: hidden)
  .set("#dot", { autoAlpha: 0, y: -300, transformOrigin: "50% 100%" }, 0);
// 1. AFTER EFFECTS s'écrit en 11 im à vitesse constante, rayé au demi-temps en 5 im
tl.to("#w1", { clipPath: "inset(0% 0% 0% 0%)", duration: f(11), ease: "none" }, T)
  .to("#s1", { scaleX: 1, duration: f(5), ease: "power4.out" }, T + at(0.5));
// 2. Coupe sèche 1,5 temps après le drop : KEYFRAMES, même rature au demi-temps
tl.set("#w1", { autoAlpha: 0 }, T + step)
  .set("#w2", { autoAlpha: 1 }, T + step)
  .to("#s2", { scaleX: 1, duration: f(5), ease: "power4.out" }, T + step + at(0.5));
// 3. La réponse sur le temps : 2 lignes masquées, 3 im d'écart
const A = T + 2 * step;
tl.set("#w2", { autoAlpha: 0 }, A)
  .set("#answer", { autoAlpha: 1 }, A)
  .to("#answer .line", { yPercent: 0, duration: f(6), ease: "power2.out", stagger: f(3) }, A);
// 4. Le point tombe en 8 im et s'écrase 1,9:1 sur le demi-temps, puis gel de 24 im
tl.set("#dot", { autoAlpha: 1 }, A + at(0.5) - f(8))
  .to("#dot", { y: 0, duration: f(8), ease: "sine.in" }, A + at(0.5) - f(8))
  .to("#dot", { scaleX: 1.9, scaleY: 0.53, duration: f(1), yoyo: true, repeat: 1 }, A + at(0.5));
// 5. Sortie : le point repart sur le demi-temps suivant vers le plan d'après
tl.to("#dot", { x: -480, y: 180, duration: f(15), ease: "power1.in" }, A + step);
```

**After Effects**

- Composition à 60 i/s. Poser un repère par temps : Layer › Markers › Add Marker (Calque › Repères › Ajouter un repère), un toutes les 28,125 im ; la règle de trois prend 42 im par élément.
- Mot écrit : Effect › Transition › Linear Wipe (Effet › Transition › Balayage linéaire), Transition Completion (Fin de transition) de 100 à 0 % en 11 im, images clés linéaires.
- Rature : calque de forme avec un tracé et un contour orange épais, Add › Trim Paths (Ajouter › Coupe de tracés), End (Fin) de 0 à 100 % en 5 im. Dans le Speed Graph (éditeur de graphe de vitesse), influence d'arrivée à 90 %, départ à 0 %.
- Réponse : animateur de texte Position Y avec Range Selector (Sélecteur de plage) et un rectangle en Track Matte (Cache) Alpha ; 6 im par ligne, 3 im d'écart.
- Point : ellipse qui tombe en 8 im, Speed Graph influence de départ 60 %, arrivée 0 % ; Scale (Échelle) 190 / 53 % sur la seule image d'impact. Aucune image clé ensuite pendant 24 im.
