## L'escalade puis la résolution (escalation arc, build and release, three-act story)

Les scènes suivent un même gabarit, mais chacune est plus grosse, plus complexe ou plus chargée que la précédente. Exemples : point, ligne, plan, volume ; niveaux d'une pile d'appels ; sorts de plus en plus gros. Elles montent jusqu'à un pic, puis reviennent au calme, souvent sur la montée et le drop de la musique. La courbe d'intensité tient l'attention sans texte, même dans un récit muet. Vue dans 19 vidéos, dont 17 notées 4 ou 5.

**Règles de construction**

1. Un gabarit, une variable qui monte : la dimension, le nombre (1 à 12 480 pages), la taille du sort. Si les étapes ne partagent pas de gabarit, ce n'est plus une escalade, c'est une liste.
2. Chaque étape naît de la précédente : le point trace la ligne, les volumes fusionnent en sphère qui fond en fluide. [Full Stop figure sequence](https://prompt-motion.com/hbcoop-de365c) tient 29 s sans une coupe.
3. La durée suit la complexité : 2 s pour les figures simples, 4 à 5 s pour les riches en explainer. En reel musical, des chapitres de 1,1 à 2,2 s coupés sur les temps, ou des plans qui raccourcissent (1,3 puis 0,70 s).
4. Un vide juste avant le pic : 13 im figées puis flash d'une image sur le 1er temps ([Motion techniques showreel](https://prompt-motion.com/lukasersil-0ed38e)), 7 im de noir et de silence avant le drop ([Supademo launch video](https://prompt-motion.com/jhylee95-e1152f)).
5. La résolution revient au départ, plus vite. La remontée va deux fois plus vite que la descente ; le rembobinage passe 8 plans de 7 im ; le globe se replie en point par le geste d'ouverture inversé (56 im, sine.inOut).
6. Proportions mesurées : la montée occupe 48 à 85 % du film, la résolution 15 à 28 %. Exemple : 4,5 s de montée, 2,2 s de condensation, 2,6 s de structure sur 9,3 s ([DistilBook motion explainer](https://prompt-motion.com/sudo-kiran-b055de)).

Le guide Otom (p. 13, fiche 12) donne la version promo de cet arc. 9 cartes flottent en désordre (3 s), se rangent et se cochent une à une (3 s), puis viennent la promesse et le logo (4 s). Son conseil vaut pour toute escalade : « Utilisez les mots exacts de vos clients pour le désordre ».

**Verdict** : à reprendre. C'est l'ossature la plus sûre pour un film sans voix : l'œil suit la courbe d'intensité. Sans pic ni retour au calme, elle redevient une suite de scènes de même poids.

**Quand l'utiliser** : en showreel (dimension croissante), en explainer (pile, complexité), en promo SaaS (chaos puis structure, deux actes autour du drop) et en récit à personnages. On choisit la variable qui monte à l'étape message et script. Le pic se place sur le drop à l'étape musique et grille, et le vide d'avant le pic se règle au découpage. À éviter dans un film de moins de 8 s, qui n'a pas la place de monter puis de redescendre.

**HyperFrames (GSAP)**

```js
// Escalade en 3 étapes, vide puis flash sur le drop, pic, puis retour rapide au point (128 BPM, 60 i/s)
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128;                       // 1 temps = 28,125 im
const at = b => b * BEAT;
const build = gsap.utils.toArray(".stage");  // point, ligne, plan : même gabarit, une dimension de plus
const DROP = at(12);                         // 1er temps de la mesure 4
tl.set([...build, "#peak", "#flash", "#end-dot"], { autoAlpha: 0 }, 0);
build.forEach((el, i) => {
  const t0 = at(4 * i);                      // une étape par mesure
  tl.set(el, { autoAlpha: 1 }, t0)
    .fromTo(el, { scale: 0.6 }, { scale: 1, duration: f(17), ease: "back.out(2.2)", immediateRender: false }, t0)
    .set(el, { autoAlpha: 0 }, i < build.length - 1 ? at(4 * i + 4) : DROP);
});
// Avant le pic : implosion 10 im, 13 im figées, flash d'une seule image sur le drop
const last = build[build.length - 1];
tl.to(last, { scale: 0.1, duration: f(10), ease: "power1.inOut" }, DROP - f(23))
  .set("#flash", { autoAlpha: 1 }, DROP)
  .set("#flash", { autoAlpha: 0 }, DROP + f(1))
  .set("#peak", { autoAlpha: 1 }, DROP + f(1));    // le pic : la dimension nouvelle, 8 temps
// Résolution : l'escalade repasse à l'envers, 7 im par étape, puis le point seul
const R = DROP + at(8);
tl.set("#peak", { autoAlpha: 0 }, R);
[...build].reverse().forEach((el, k) => {
  tl.set(el, { autoAlpha: 1, scale: 1 }, R + k * at(0.25))
    .set(el, { autoAlpha: 0 }, R + (k + 1) * at(0.25));
});
tl.set("#end-dot", { autoAlpha: 1 }, R + build.length * at(0.25));
```

**After Effects**

- Une étape par précomp, même gabarit : Layer › Pre-compose (Calque › Précomposer). Un repère par mesure (112,5 im à 128 BPM, 60 i/s) avec Layer › Markers › Add Marker (Calque › Repères › Ajouter un repère).
- Naissance de chaque étape : Scale (Échelle) 60 → 115 → 100 % aux images 0, 8 et 17, influence de 80 % à l'arrivée dans le Speed Graph (éditeur de graphe de vitesse).
- Avant le drop : Scale 100 → 10 % en 10 im, puis aucune image clé pendant 13 im. Flash : Layer › New › Solid (Calque › Nouveau › Solide) blanc, coupé à 1 image, posé sur le repère du drop.
- Résolution : dupliquer les précomps des étapes, les couper à 7 im, les ranger en ordre inverse, puis Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques).
- Variante plan-séquence : un seul objet qui change de forme, et la fin rejoue l'ouverture à l'envers. Copier les images clés d'ouverture, puis Animation › Keyframe Assistant › Time-Reverse Keyframes (Inverser la temporisation des images clés).
