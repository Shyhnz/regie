## L'accroche de la première seconde (cold open, first-second hook, problem opener)

Le plan 1 de tout film : une image 0 déjà composée et vivante, puis la tension posée avant 1 s. Le spectateur doit sentir le problème avant d'avoir décidé de rester. Le chiffre de Photon journey est complet à 0,7 s. Voir *L'accroche de la première seconde* au chapitre 10 (28 vidéos, dont 19 notées 4 ou 5).

![Les quatre carrés du logo au centre dès l'image 0, leur éclatement, le bureau en désordre qui apparaît, la phrase « It's not a prompting problem. » qui monte, puis « prompting » biffé](ILLUS:C01-accroche)

*[Second brain service promo](https://prompt-motion.com/theviableedge-9065be), 0:00.00 à 0:01.87 : le logo est là dès l'image 0 et ses carrés éclatent à f12. La phrase-problème monte de f35 à f55, puis « prompting » est biffé.*

**Quand l'utiliser** : toujours en plan 1 (accroche), mesure 1 de la timeline type (W : « une image qui gagne l'attention »). En promo SaaS : question au client ou problème chiffré. En typo cinétique 1600 : constat mot par temps, retournement sur le temps fort. À éviter : le pré-titre « Introducing », l'écran noir, une accroche que le film ne paie pas.

**Règles**

1. **Image 0 composée, jamais noire.** Noir initial ≤ 0,2 s, élément fort ≥ 10 % H avant 0,5 s (voir *Le temps mort : quand l'image s'arrête* au chapitre 11). L'accroche lente est un tic de 37 vidéos : noir ou point minuscule. Premier geste avant f12, comme chez Second brain.
2. **Montrer la tension, pas l'annoncer** (W). L'objet du problème est à l'écran dès l'image 0 : l'URL qui s'allonge chez Dub, le bureau en désordre chez Second brain. Une phrase d'ouverture courte (B).
3. **5 à 8 mots en deux temps** : constat puis retournement, un groupe de mots par temps. Mots de 5 à 16 % H ; phrase tenue 1,1 à 1,2 s après son entrée (chapitre 10).
4. **Un seul accent**, sur le mot de la tension. Entrées de 0,2 à 0,5 s en promo rythmée (Bible, médiane 0,30 s) ; aucun dépassement sur le texte (F).
5. **Mesure 1 sans grosse caisse.** Des clics sur les gestes, puis la grosse caisse sur la mesure 2 : chez Keyframe motion design reel, 3 clics seulement, puis grosse caisse et basse à f113 (voir *Le temps fort* au chapitre 9). L'image mène le son de 1 im (F).
6. **Payer la tension** : la réponse arrive plus tard dans le film (révélation, signature). Pour tester deux accroches, ne changer que ce plan (chapitre 10).

**HyperFrames (GSAP)**

```js
// Plan 1 · Accroche (mesure 1, f0-f112) : image 0 composée, tension posée avant 1 s
const FPS = 60, BPM = 128, BEAT = 60 / BPM;
const at = (bar, beat = 0) => ((bar - 1) * 4 + beat) * BEAT;
const F = n => n / FPS;                                        // images → secondes
const T = (bar, beat = 0) => Math.round(at(bar, beat) * FPS) / FPS; // temps arrondi depuis l'image 0
const SHARDS_X = [-420, -160, 180, 440], SHARDS_Y = [-120, 90, -70, 130]; // éclats écrits, pas tirés au hasard

// Image 0 = vignette : l'objet du problème et le 1er groupe sont déjà posés
tl.set(["#problem", "#w1"], { autoAlpha: 1 }, 0)
  .set("#w-tension", { autoAlpha: 0, yPercent: 110 }, 0)       // caché sous sa ligne de masque
  .set("#strike", { scaleX: 0, transformOrigin: "0% 50%" }, 0)
  // Ambiant : poussée de 2 % sur toute la mesure, jamais figé
  .to("#hook", { scale: 1.02, duration: T(2), ease: "sine.inOut" }, 0)
  // Premier geste avant f12 : l'objet du problème éclate en fragments
  .to(".shard", { x: i => SHARDS_X[i], y: i => SHARDS_Y[i],
                  duration: F(33), ease: "power2.out" }, F(12))
  // Temps 1 (f28) : le mot de la tension monte du masque, 12 im, seul mot en accent
  .to("#w-tension", { autoAlpha: 1, yPercent: 0, duration: F(12), ease: "power3.out" }, T(1, 1))
  // Temps 2 (f56) : la tension se resserre, biffure de 12 im
  .to("#strike", { scaleX: 1, duration: F(12), ease: "power1.inOut" }, T(1, 2))
  // Fin de mesure : le texte accélère vers la sortie, l'objet relais grossit
  .to("#hook-text", { yPercent: -60, autoAlpha: 0, duration: F(6), ease: "power2.in" }, T(2) - F(6))
  .to("#relay", { scale: 1.15, duration: F(6), ease: "power2.in" }, T(2) - F(6));

// Repères son, à recopier dans timeline.js (l'image mène de 1 im)
const SFX = [["click", F(1)], ["click", T(1, 1) + F(1)], ["click", T(1, 2) + F(1)], ["kick", T(2)]];
```

**After Effects**

- Composition › Composition Settings (Composition › Paramètres de composition) : 1920 × 1080, 60 fps. Un marqueur de composition par temps (touche * du pavé numérique) : f0, f28, f56, f84, f113.
- Pas de calque vide en tête : à l'image 0, l'objet et le 1er groupe sont visibles. Composition › Save Frame As › File (Composition › Enregistrer l'image sous › Fichier) sur l'image 0 : c'est la vignette, elle doit tenir seule.
- Mot de tension : calque de texte sous un cache, Layer › Track Matte › Alpha Matte (Calque › Cache › Cache alpha). Position Y en 12 im, influence d'entrée 85 % dans le Graph Editor (Éditeur de graphiques).
- Biffure : calque de forme Rectangle, Add › Trim Paths (Ajouter › Réduire les tracés), End de 0 à 100 % en 12 im sur le marqueur f56.
- Poussée ambiante : Scale (Échelle) de 100 à 102 % sur toute la mesure, Easy Ease (Lissage de vitesse, F9).

**Contrôle** : rendre f0, f12, f28, f40, f56, f84, et une bande de 8 images de f106 à f113. Regarder f0 à 360 px de large : on doit comprendre le sujet sans lecture. À f40, la phrase entière se lit et un seul mot porte l'accent. Entre f0 et f12, quelque chose bouge déjà. Sur la bande, le texte accélère jusqu'à la coupe et l'objet relais est le seul survivant.
