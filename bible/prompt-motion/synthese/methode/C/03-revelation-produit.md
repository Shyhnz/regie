## La révélation du produit (product reveal, drop on the reveal, click-to-reveal)

Le plan 3 : le produit naît du point laissé par le problème, puis entre par un vrai geste : un curseur clique son nom sur le drop, l'interface s'ouvre depuis le bouton. Le temps fort en fait l'impact maximal du film. Voir *Le temps fort* au chapitre 9 (79 vidéos, 69 notées 4 ou 5).

![Le point, la pastille « dub.sh/launch » qui naît, le curseur, le fond qui s'embrase au clic, puis le globe et le compteur](ILLUS:C03-revelation-produit)

*[Dub promo video](https://prompt-motion.com/steventey-0d20e4), 0:01.50 à 0:02.67 : le point devient la pastille du produit, le curseur la clique, le fond s'embrase sur le drop, puis globe et compteur prennent le relais.*

**Quand l'utiliser** : plan 3 de la timeline type (W : « le produit entre par une vraie interaction »), juste après le problème montré, sur le premier drop. Promo SaaS, typo cinétique 1600. À éviter sans vrai écran du produit : un écran manquant se demande, il ne s'invente pas (W).

**Règles**

1. **Le produit naît du problème.** Son origine est le point du plan 2 : la solution sort de l'objet du problème, sur le temps fort (chapitre 10, arc de pitch). L'iris part d'un point qui a un sens, ici le bouton cliqué (voir *L'iris né d'un point* au chapitre 4).
2. **Une vraie interaction** (W). Le curseur arrive en courbe et freine ; en ligne droite, ou s'il attend plus d'une demi-seconde, il sonne faux (voir *Le curseur acteur* au chapitre 7). L'attention reste sur le bouton jusqu'à sa réponse, puis le résultat possède l'écran (B).
3. **Le drop sur la révélation.** L'impact tombe sur l'image du temps, 0 à 2 im avant l'attaque audible ; après le drop, le mouvement est multiplié par 1,5 à 4,25 (chapitre 9). Chez Dub, les aigus montent de 4,5 dB sous le curseur, les graves de 19 dB au drop.
4. **Un seul ressort pour ce qui naît** : ζ ≈ 0,5, pic de 12 à 15 % vers 15 im, repos vers 30 im, soit un temps (étude 60 fps de steventey). Taille et position rebondissent ; opacité et couleur jamais (F).
5. **L'iris est un masque** : l'interface bouge déjà dans le disque. Il part sur le temps, donc décélère : 27 à 46 % du cadre dès la 1re ou 2e image, plein en 6 à 14 im (chapitre 4).
6. **Lisible à chaque état.** Nom à 6 % H au moins au clic, puis 3 % H au moins en secondaire (chapitre 12). Le résultat roule en power3.out et se fige sur un temps (voir *Le compteur qui roule* au chapitre 7).

**HyperFrames (GSAP)**

```js
// Plan 3 · Révélation (globale f309-f449) : point → nom → clic sur le drop → iris
const FPS = 60, BPM = 128, BEAT = 60 / BPM;
const at = (bar, beat = 0) => ((bar - 1) * 4 + beat) * BEAT;
const F = n => n / FPS;
const T = (bar, beat = 0) => Math.round(at(bar, beat) * FPS) / FPS;
const IN = T(3, 3), DROP = T(4), OUT = T(5);          // f309, f338, f450
const BTN = { x: 960, y: 540, r: 14 };                // ancre du bouton, lue dans timeline.js
const R = 1.02 * Math.hypot(1920, 1080) / 2;
// Ressort mesuré chez Dub : ζ 0,52, ω 0,26 rad/im ; pic ≈ +15 % vers 15 im, repos ≈ 30 im
const spring = (z = 0.52, w = 0.26, frames = 40) => p => {
  const t = p * frames, wd = w * Math.sqrt(1 - z * z);
  return 1 - Math.exp(-z * w * t) * (Math.cos(wd * t) + (z * w / wd) * Math.sin(wd * t));
};
const res = { v: 0 }, out = document.querySelector("#result");

tl.set(["#pill", "#app"], { autoAlpha: 0 }, 0)
  // 1. Éclair d'une image, puis le nom naît du point en ressort
  .fromTo("#flash", { opacity: 0.31 }, { opacity: 0, duration: F(11), ease: "power1.out", immediateRender: false }, IN + F(1))
  .set("#dot", { autoAlpha: 0 }, IN + F(2))
  .fromTo("#pill", { autoAlpha: 1, scale: 0 }, { scale: 1, duration: F(40), ease: spring(), immediateRender: false }, IN + F(2))
  // 2. Le curseur arrive en courbe (x et y sur deux courbes), posé 1 im avant le clic
  .fromTo("#cursor", { x: 340 }, { x: 0, duration: F(12), ease: "power2.out", immediateRender: false }, DROP - F(13))
  .fromTo("#cursor", { y: 260 }, { y: 0, duration: F(12), ease: "sine.out", immediateRender: false }, DROP - F(13))
  // 3. Le clic sur le drop : appui 1 → 0,92 → 1, l'iris naît du bouton
  .to("#pill", { scale: 0.92, duration: F(1), ease: "none" }, DROP)
  .to("#pill", { scale: 1, duration: F(6), ease: "power2.out" }, DROP + F(1))
  .set("#app", { autoAlpha: 1, clipPath: `circle(${BTN.r}px at ${BTN.x}px ${BTN.y}px)` }, DROP)
  .to("#app", { clipPath: `circle(${R}px at 960px 540px)`, duration: F(10), ease: "expo.out" }, DROP)
  // 4. Le nom passe en secondaire, le résultat roule et se fige sur la mesure 5
  .to("#pill", { y: -380, scale: 0.6, duration: F(18), ease: "power3.out" }, DROP + F(8))
  .to(res, { v: 1284093, duration: OUT - T(4, 1), ease: "power3.out",
             onUpdate: () => (out.textContent = Math.round(res.v).toLocaleString("en-US")) }, T(4, 1));
```

**After Effects**

- Marqueurs de composition sur f309, f338 (drop) et f450 ; l'onde du son (touches LL) montre l'attaque sur f338.
- Pastille : Scale (Échelle) par expression de ressort (étude 60 fps de steventey) : t = time − inPoint ; s = 100 × (1 − exp(−8,1 t) × (cos(13,3 t) + 0,61 sin(13,3 t))).
- Curseur : Position › Separate Dimensions (Séparer les dimensions), influences différentes sur X et Y : la trajectoire courbe. Clic : Scale de 100 à 92 % en 1 im sur f338, retour en 6 im.
- Iris : calque de forme Ellipse sur le bouton, interface précomposée au-dessus en Layer › Track Matte › Alpha Matte (Calque › Cache › Cache alpha). Size (Taille) de 28 à 2 250 px en 10 im, influence d'entrée 90 % sur la dernière clé.
- Résultat : Source Text (Texte source) par expression, cible × (1 − (1 − t)³) (≈ power3.out), figé sur f450.

**Contrôle** : rendre f309, f310, f326, f337, f338, une bande de 8 images de f336 à f343, puis f348, f366 et f450. À f310, l'éclair dure une image. À f326, la pastille est à son pic. À f337, le curseur posé ne cache pas le nom. Sur la bande, le disque couvre 27 % du cadre dès f339, l'interface bouge déjà dedans. À f450, le résultat figé se lit à 360 px de large. Au son décodé, le drop tombe sur f338 ou 1 im après.
