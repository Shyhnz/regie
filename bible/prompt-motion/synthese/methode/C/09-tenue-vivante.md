## La tenue vivante (living hold, reading hold, slow push, beat pulse)

Après l'entrée, le texte doit se lire : c'est la tenue. Elle dure le temps de lecture, pas plus, et elle reste vivante sans que le texte bouge : le bloc pousse de 2 à 3 %, un détail bat le temps. Au-delà d'environ 1 s sans geste, c'est du temps mort : 22 des 81 cas relevés sont jugés clichés (*Le maintien : temps de lecture ou temps mort*, chapitre 9).

**Quand l'utiliser** : fonction « tenue », après chaque entrée qui porte un message : la phrase du problème, l'affirmation clé, le résultat d'une démo, la preuve. Tous les styles. On la chiffre au découpage, on la vérifie au rendu. À éviter : la tenue longue et figée, défaut le plus fréquent des vidéos générées (*Le maintien*).

**Règles**

1. **Compter dès que c'est lisible** (B), jamais depuis le début de l'entrée. Phrase à lire : 0,4 s + caractères / 15, 1 s au moins, +20 % en 9:16 ; mot sur le temps : 0,2 s par mot (*Étape 2 · Le message et le script*, chapitre 12). B le rappelle : 8 im à 30 fps, soit 0,27 s, c'est trop court ; lire à voix haute.
2. **Une durée bornée.** Sans geste, un temps au plus : 0,4 à 0,8 s, 24 à 48 im (*Le maintien*). Au-delà, tenue voulue de 60 à 96 im sur l'affirmation clé, avec poussée de 2 à 3 % (*Étape 5 · Le découpage en plans*, chapitre 12). Si la formule dépasse 96 im, on raccourcit le texte.
3. **Vivante, pas bougeante.** Le bloc entier pousse de 2 à 3 %, linéaire, sur toute la tenue : 1,00 → 1,03 en 3 s (B), 2 % (F). Aucune lettre, aucune place, aucune couleur ne change pendant qu'on lit : « texte qui bouge pendant qu'on le lit » est un interdit de F. 1 % par seconde ne suffit pas (lexnlin-6161a6).
4. **Le héros tient, le décor vit.** Un détail secondaire bat le temps : 2 à 3 % pour un titre tenu, attaque 1 à 2 im, relâche 4 à 15 im, 0 à 2 im avant le coup (*Le décor qui bat la mesure*, chapitre 9). L'ambiant reste sous 5 % de la course du héros, en sinus lent, jamais arrêté (F). Ou un compteur qui roule (steventey).
5. **Sortir en mouvement.** On ne coupe jamais sur une image immobile : le plan sortant accélère (power2.in à power4.in) jusqu'à l'image de coupe (*Le maintien*) ; ici +3,6 % en 8 im (étude 60 fps de grace-sunnyy).
6. **Pas de durée forfaitaire.** La musique pilote la tenue : le carton final tient une mesure au plus et reste animé (*Le maintien*). Le guide Otom demande 1,5 s de texte immobile ; nos mesures en font du temps mort.

**HyperFrames (GSAP)**

```js
// Tenue vivante : « Liens en direct. » lu 1,47 s, poussée 3 %, détail qui bat, sortie accélérée
const FPS = 60, BPM = 128, BEAT = 60 / BPM;
const at = (bar, beat = 0) => ((bar - 1) * 4 + beat) * BEAT;
const fr = n => n / FPS;
const snap = t => Math.round(t * FPS) / FPS;      // chaque temps arrondi seul, depuis l'image 0
const IN = snap(at(4)), CUT = snap(at(5));        // f338 → f450
const READ = IN + fr(12);                         // lisible : la lecture se compte d'ici

tl.set("#line", { autoAlpha: 1, yPercent: 105 }, IN)
  // Entrée : montée par masque, 12 im power3.out
  .to("#line", { yPercent: 0, duration: fr(12), ease: "power3.out" }, IN)
  // Tenue : le bloc entier pousse de 3 %, linéaire ; rien ne bouge à l'intérieur
  .fromTo("#hold", { scale: 1 }, { scale: 1.03, duration: CUT - fr(8) - READ, ease: "none",
          immediateRender: false }, READ)
  // Sortie : encore +3,6 % en power2.in jusqu'à l'image de coupe (1,03 × 1,036)
  .to("#hold", { scale: 1.067, duration: fr(8), ease: "power2.in" }, CUT - fr(8))
  .set("#shot-hold", { autoAlpha: 0 }, CUT);

// Secondaire : le soulignement bat les temps 2, 3, 4 ; +3 %, attaque 2 im, relâche 10 im, 1 im avant
for (let b = 1; b <= 3; b++) {
  const t = snap(at(4, b)) - fr(1);
  tl.to("#underline", { scaleX: 1.03, duration: fr(2), ease: "power2.out" }, t)
    .to("#underline", { scaleX: 1, duration: fr(10), ease: "power2.out" }, t + fr(2));
}

// Ambiant : le fond glisse de 5 px au plus (< 5 % de la course du héros), en sinus, sans arrêt
tl.fromTo("#bg", { y: -2.5 }, { y: 2.5, duration: (CUT - IN) / 2, ease: "sine.inOut",
          yoyo: true, repeat: 1, immediateRender: false }, IN);
```

**After Effects**

- Mesurer la tenue : de la dernière image clé d'entrée à la première de sortie. Au-delà de 28 im (un temps), un geste ; au-delà de 96 im, raccourcir le texte.
- Poussée : sur un Null Object (objet nul) parent du bloc, Scale (Échelle) 100 → 103 % sur la tenue ; clic droit sur les clés › Keyframe Interpolation (Interpolation d'image clé) › Linear (Linéaire). Aucune clé sur les calques de texte eux-mêmes.
- Pulsation du soulignement, sans clés : expression sur Scale (Alt-clic sur le chronomètre), avec 1 im d'avance : `b = 60/128; p = ((time + 1/60) % b)/b; s = 100 + 3*Math.exp(-8*p); [s, 100]`.
- Sortie : Scale 103 → 106,7 % sur les 8 im avant la coupe, vitesse nulle au départ et maximale à l'arrivée (≈ power2.in) dans le Speed Graph (graphe de vitesse). Jamais Layer › Time › Freeze Frame (Calque › Temps › Figer l'image) pour tenir un plan.

**Contrôle** : rendre f0, f12, f27, f28, f58, f104, f111, f112, puis la bande de 8 images f104-f111. On regarde : à f12 la phrase est entière et nette ; de f12 à f104 il y a au moins le temps de lecture (ici 88 im), lu à voix haute ; la boîte de chaque mot ne bouge pas dans le bloc ; l'échelle du bloc monte de 2 à 3 % ; le soulignement culmine 1 im avant chaque temps ; aucune image n'est identique à la précédente (différence d'images non nulle) ; à f111 le bloc accélère encore.
