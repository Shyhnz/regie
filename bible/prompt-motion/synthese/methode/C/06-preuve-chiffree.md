## La preuve chiffrée (proof shot, hero stat count-up, line chart draw-on, before/after bars)

Un écran ou un chiffre démontre l'affirmation (W) : un compteur qui roule, une courbe qui se trace, des barres qui poussent. La preuve devient un événement que l'œil suit jusqu'au bout. Chez steventey, seule vidéo notée 5/5 de *L'arc de pitch* (chapitre 10), les preuves occupent 55 % des 15 s. Seulement de vrais chiffres.

**Quand l'utiliser** : la PREUVE du squelette de W, après la démo (C04, C05) et avant la fin ; en explainer de données ; en typo cinétique 1600 quand la voix cite un chiffre. Un compteur pour une valeur, une courbe pour une évolution, des barres pour comparer (chapitre 7). À éviter sans chiffre réel et sourcé : le plan saute, on n'invente pas.

**Règles**

1. Vrais chiffres seulement (W). Chaque chiffre vient de `BRIEF.md`, avec son fichier source dans `assets/`. Un chiffre manquant arrête le travail : Claude demande (parcours A, phase 1). Données dans un seul fichier, relues : sommes, pluriels, unités. Contre-exemples : « 0M+ », « 1 steps » (voir *Étape 7* au chapitre 12).
2. Un héros (F) : le chiffre, de 10 à 30 % H (voir *Le compteur qui roule* au chapitre 7). Le secondaire suit avec la même courbe, 6 im après : 0 à 6 im pour la Bible, 100 à 200 ms pour F. Un graphique, un message (*Les barres qui poussent et se réordonnent*, chapitre 7).
3. Courbe : power3.out, 2 temps pour une preuve, 2,2 s au plus pour un héros. La moitié de la valeur au premier cinquième. Arrivée 1 à 4 im avant le temps (*Le compteur qui roule*).
4. Largeur fixe : chiffres tabulaires, séparateurs immobiles, virgule décimale et espace insécable en français. Seuls les chiffres qui changent tournent ; ceux de gauche se figent d'abord.
5. Le tracé aboutit sur une étiquette : c'est la chute (voir *La courbe qui se trace* au chapitre 7). Sa taille peut rebondir, son opacité jamais (F).
6. Honnête et lisible : échelle qui part de 0, forme fidèle à la donnée. Libellés ≥ 3 % H. Tenue : 0,4 s + caractères / 15 dès que le texte est lisible (*Le temps mort*, chapitre 11), avec une dérive de 2 % (F).

**HyperFrames (GSAP)**

```js
// Preuve chiffrée : l'affirmation, le chiffre héros, la courbe qui suit, l'étiquette qui conclut
const FPS = 60, BPM = 128, BEAT = 60 / BPM;
const at = (bar, beat = 0) => ((bar - 1) * 4 + beat) * BEAT;
const F = n => n / FPS;
const P0 = at(7), T = b => P0 + b * BEAT;          // le plan commence à la mesure 7
// PROOF vient de data.js, recopié de BRIEF.md avec sa source ; jamais tapé dans le plan
const { value, decimals } = PROOF;
const fmt = new Intl.NumberFormat("fr-FR", { minimumFractionDigits: decimals, maximumFractionDigits: decimals });
const num = document.querySelector("#num"), n = { v: 0 };  // #num : chiffres tabulaires, « 0 » dans le HTML
const draw = () => { num.textContent = fmt.format(n.v); };
const path = document.querySelector("#curve path"), L = path.getTotalLength();
tl.set("#claim", { autoAlpha: 0, y: 24 }, P0)
  .set(path, { strokeDasharray: L, strokeDashoffset: L }, P0)
  .set("#delta", { autoAlpha: 0, scale: 0.6 }, P0)
  // 1. l'affirmation entre sur le temps 0 et reste
  .to("#claim", { autoAlpha: 1, y: 0, duration: F(18), ease: "power3.out" }, T(0))
  // 2. le héros : power3.out sur 2 temps, posé 2 im avant le temps 3
  .to(n, { v: value, duration: T(3) - T(1) - F(2), ease: "power3.out", onUpdate: draw }, T(1))
  // 3. le secondaire : même courbe, 6 im après, posé avec le chiffre
  .to(path, { strokeDashoffset: 0, duration: T(3) - T(1) - F(8), ease: "power3.out" }, T(1) + F(6))
  // 4. la chute sur le temps 3 : la taille rebondit, l'opacité non
  .to("#delta", { autoAlpha: 1, duration: F(4), ease: "none" }, T(3))
  .to("#delta", { scale: 1, duration: F(28), ease: "back.out(1.7)" }, T(3))
  // 5. tenue vivante jusqu'à la fin du plan (temps 8)
  .to("#proof", { scale: 1.02, duration: T(8) - T(4), ease: "none" }, T(4));
```

**After Effects**

- Chiffre : un calque de texte avec Effect › Expression Controls › Slider Control (Effet › Paramètres pour expressions › Paramètre glissière) ; clés 0 → valeur réelle sur 2 temps, influence d'arrivée forte dans le Graph Editor (éditeur de graphique) pour imiter power3.out.
- Source Text (Texte source) : expression `Math.round(effect("Slider Control")("Slider"))` ; police à chiffres tabulaires, texte aligné à gauche pour que la largeur ne bouge pas.
- Courbe : un tracé avec Trim Paths (Réduire les tracés), End 0 → 100 % en 48 im, 6 im après le chiffre, mêmes influences ; un petit cercle parenté à la tête avec Parent & Link (Parent et lien).
- Étiquette : Scale (Échelle) 60 → 100 % avec un léger dépassement, posée sur le Composition Marker (repère de composition) du temps 3 ; Opacity (Opacité) sans dépassement.
