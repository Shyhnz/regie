## La courbe qui se trace (line chart draw-on, leading dot, synced counter, scrubbing tooltip)

Une ligne, souvent doublée d'une aire en dégradé, se dessine de gauche à droite, menée par un point lumineux. Elle raconte une évolution et donne une direction à l'œil. Elle porte quand sa tête aboutit sur le chiffre clé au temps fort, en 0,45 à 1 s dans les promos. Vue dans 35 vidéos, dont 28 notées 4 ou 5.

**Règles de construction**

1. Durée : 27 à 58 im à 60 fps, soit 0,45 à 1 s, 1 à 2 temps à 120 BPM. Ease-out quand la tête vient se poser sur une valeur (steventey 38 im, twoclipping 27 im, utopyaszx 27 im). Ease-in-out quand le pic de vitesse doit tomber sur un temps (daniel-haida 58 im, quickdesignio 50 im).
2. Calage : départ sur le temps (steventey, +0 im), arrivée sur le temps (astrodevil, sommet sur le temps 9 ; quickdesignio), ou pose 3 im avant (twoclipping). Contre-exemple : vitesse constante, départ 5 im et fin 3,5 im avant le temps, jugé mécanique (miskinho).
3. Une seule progression pilote trait, tête, aire et chiffre : ils finissent ensemble (quickdesignio ; ratheejaisal, 86 im ; imthatcarlos). Seul écart mesuré : le compteur part 8 im avant et finit 6 im après le trait, en power3.out (steventey).
4. Habillage : trait de 2 à 6 px, tête en point blanc lumineux ou en anneau creux de 30 px environ (miskinho). L'aire en dégradé se révèle derrière la tête, masque à bord flou (utopyaszx). Grille : trois lignes horizontales très claires au plus, échelle à 0 (guide Otom, p. 9).
5. Le tracé aboutit sur une étiquette : c'est la chute du plan. Exemples : « +28% » 0,1 s après la fin (bizibeast), « ▲ 24% » 20 im après (ratheejaisal), infobulle tenue 10 im sur le pic (sudeepsd), dernier point orange (en-ra).
6. Sans chiffre, une référence donne le sens : bande « jour normal » (marouanegazouzi), lignes de base et de cible (macrohou). Chez kloss-xyz, le halo de la tête passe de l'orange au bleu dans les bandes « AI WINTER ».

Le guide Otom trace sa courbe à vitesse constante en 4 s (guide Otom, p. 9) ; nos mesures donnent 0,45 à 1 s en ease-out. La vitesse constante ne vaut que pour l'explainer à voix (tak3sh8, ≈ 4,3 s).

**Verdict** : à reprendre. C'est le visuel de croissance de la promo SaaS, à condition que la tête aboutisse sur l'étiquette chiffrée au temps fort. Sa tête peut être le point relais de ton match cut (« L'objet relais »).

**Quand l'utiliser** : en promo SaaS / interface, comme preuve après la démo (tableau de bord, croissance, dépassement), et en explainer données (évolution, seuil, deux courbes comparées). On fixe au découpage le temps qui porte l'arrivée. Pour comparer des catégories, préfère « Les barres qui poussent et se réordonnent ». Pour un trait sans donnée, vois « Le tracé qui se dessine : soulignement, connecteur, logo au trait ». Pour l'annotation, « Désigner : balayage, surlignage, annotation ».

**HyperFrames (GSAP)**

```js
// Courbe tracée : trait, point de tête, aire et compteur pilotés par la même horloge
const FPS = 60;
const BEAT = 60 / 120;                                  // 120 BPM (Dub promo video)
const at = b => b * BEAT;
const im = n => n / FPS;
const line = document.querySelector("#line");           // <path> SVG, trait 3 px
const head = document.querySelector("#head");           // <circle> blanc, halo en drop-shadow
const wipe = document.querySelector("#area-clip rect"); // clipPath de l'aire en dégradé
const kpi = document.querySelector("#kpi");
const L = line.getTotalLength(), x0 = line.getBBox().x;
const fmt = new Intl.NumberFormat("fr-FR");             // 1 284 093 (espace insécable)
const s = { p: 0 }, k = { v: 0 };
const drawLine = () => {
  line.style.strokeDashoffset = L * (1 - s.p);
  const pt = line.getPointAtLength(L * s.p);            // la tête reste au bout du trait
  gsap.set(head, { attr: { cx: pt.x, cy: pt.y } });
  gsap.set(wipe, { attr: { width: Math.max(0, pt.x - x0) } });   // l'aire suit la tête
};
const T0 = at(9);                                       // départ du trait sur le temps
tl.set(line, { strokeDasharray: L, strokeDashoffset: L }, 0)
  .set(wipe, { attr: { width: 0 } }, 0)
  .set("#badge", { autoAlpha: 0, scale: 0.6, transformOrigin: "0% 100%" }, 0)
  .set(head, { autoAlpha: 1 }, T0)
  // compteur : part 8 im avant le trait, power3.out en 52 im (finit 6 im après lui)
  .to(k, { v: 1284093, duration: im(52), ease: "power3.out",
           onUpdate: () => { kpi.textContent = fmt.format(Math.round(k.v)); } }, T0 - im(8))
  // trait : power2.out en 38 im, de 16 à 86 % de la largeur
  .to(s, { p: 1, duration: im(38), ease: "power2.out", onUpdate: drawLine }, T0)
  // étiquette au bout de la courbe, pleine 4 im avant le temps 11
  .to("#badge", { autoAlpha: 1, scale: 1, duration: im(12), ease: "back.out(1.7)" }, at(11) - im(16));
```

**After Effects**

- Courbe : la tracer au Pen Tool (outil Plume) sur un calque de forme, Stroke (Contour) 3 px, sans Fill (fond). Add › Trim Paths (Ajouter › Réduire les tracés), End (Fin) 0 → 100 % en 38 im depuis le marqueur du temps.
- Courbe de vitesse : clé d'arrivée en Easy Ease In (lissage de vitesse en entrée, Maj+F9). Dans le Graph Editor (éditeur de graphiques), Speed Graph (graphe de vitesse), influence entrante ≈ 70 % : c'est power2.out.
- Tête : sélectionner le Path (Tracé), Ctrl/Cmd+C, coller sur la Position d'un petit cercle blanc. Les clés itinérantes (roving) suivent le tracé à vitesse constante ; recaler la première et la dernière sur celles de Trim Paths, même influence. Halo : Effect › Stylize › Glow (Effet › Esthétiques › Lueur).
- Aire : dupliquer le calque, fermer le tracé vers l'axe, Gradient Fill (remplissage en dégradé) de la couleur vers 0 % d'opacité. Effect › Transition › Linear Wipe (Balayage linéaire) de gauche à droite, Transition Completion (Fin de transition) 100 → 0 % aux mêmes images, Feather (Contour progressif) 20 px.
- Compteur : sur le Text layer (calque de texte), un Slider Control (Paramètre glissière) de 0 à 100 (le curseur plafonne à 1 000 000). 52 im, Easy Ease In à ≈ 85 %, départ 8 im avant le trait. Source Text (Texte source) : `v = Math.round(effect("Slider Control")("Slider") / 100 * 1284093); v.toString().replace(/\B(?=(\d{3})+(?!\d))/g, " ")`.
