## Le schéma qui se construit et le flux qui circule (node diagram build-on, hub and spoke, travelling packet, timeline)

Un schéma (nœuds reliés, hub en étoile, arbre, frise) se monte élément par élément, puis un paquet lumineux court sur un lien et allume sa cible. Il explique une architecture sans phrase : l'ordre de construction est l'ordre de lecture, le paquet donne le sens. Meilleure occurrence : une étape par demi-temps (7,5 im à 30 fps, 120 BPM). **Règles de construction**

1. Ordre : lien, puis nœud, puis libellé. Lien en ≈ 4 im, contour en ≈ 6 im, libellé en dernier (techyoutbe-945b56). Les éléments de même rang entrent en cascade serrée de 2 à 4 im (charlesmendez-73b6e4, misbahsy-80eaec, prasad-pilla-2c0cba).
2. Une étape par temps ou demi-temps, d'après les vidéos animées sur la musique à 120 BPM : un temps chez bizibeast, un demi-temps chez amol909s-27533e, trois puces sur trois demi-temps chez gabrielbuzziv-4ff0c6. Contre-exemple : prasad-pilla (musique posée), étapes à 33 puis 30 im, et SHIP ne s'allume jamais. Le guide tient 1,2 s par étape (guide Otom, p. 11) : rythme de voix off ; sur musique, la Bible garde un temps.
3. Le paquet qui compte : un seul, 9 à 12 im à 30 fps (0,3 à 0,4 s), en ease-in-out, qui trace le lien derrière lui. Son arrivée déclenche la cible (contour allumé, cercle à 2×, libellé qui passe au noir) sur le temps ou le demi-temps (amol909s, davidmarcus-a28a60). C'est un objet relais : voir « L'objet relais » (chapitre 4).
4. Le flux d'ambiance : points à vitesse constante, en boucle, décalés (≈ 30 im par trajet chez gabrielbuzziv, ≈ 1 % L par image chez mdaman010-e7226a). Il garde vivant un maintien (1,77 s chez sudo-kiran-b055de), sans rien apporter à lire (techyoutbe).
5. Choisir rend le schéma utile : une branche gagne, les autres tombent à ≈ 30 % (macrohou-33959d) ; rouge puis vert pour un incident résolu (misbahsy) ; une couleur par route (amol909s) ou par commande git (yunn260414-60d996).
6. Lisible ou rien : 3 à 8 nœuds. Les libellés à 1 à 1,5 % H sont jugés trop petits (misbahsy, jayscambler-3f8889, ismailfahmi-557268) : vise 2,5 % H au moins. Réseau dense : tout le reste en gris (sayan-shanky-f850d8).

**Verdict** : à reprendre. Le paquet qui allume sa cible dit « cause, puis effet » en 0,3 s. Un lien doit porter un flux ou un choix : une flèche statique entre deux boîtes est du décor, à retirer ou à faire parcourir par un paquet.

**Quand l'utiliser** : promo SaaS (routage, intégrations, pipeline) et explainer données ou process. Fonction : démonstration, ou résumé du produit en une image avant la démo (hqmank-7c61f1). Se décide au découpage (un schéma par plan, 8 nœuds au plus), se règle à la construction du plan. À éviter en typo cinétique 1600 pure. Sur voix off, voir « L'illustration qui explique » (chapitre 8) ; le connecteur seul, « Le tracé qui se dessine » (chapitre 6).

**HyperFrames (GSAP)**

```js
// Un temps par étape, paquet qui trace le lien et allume la cible, flux d'ambiance (MotionPathPlugin)
gsap.registerPlugin(MotionPathPlugin);
const FPS = 60, F = n => n / FPS;
const BEAT = 60 / 120, at = b => b * BEAT;          // 120 BPM
const STEPS = [["#l-0", "#n-comment"], ["#l-1", "#n-bot"]]; // lien puis nœud
tl.set(".node", { autoAlpha: 0, scale: 0.6 }, 0).set(".node .label", { opacity: 0, y: 8 }, 0)
  .set(".link", { strokeDasharray: 1, strokeDashoffset: 1 }, 0)    // <path pathLength="1">
  .set(".dot, #packet", { autoAlpha: 0 }, 0);
STEPS.forEach(([link, node], i) => {
  const t = at(4 + i);                                // une étape par temps
  tl.to(link, { strokeDashoffset: 0, duration: F(8), ease: "power2.out" }, t - F(8))
    .to(node, { autoAlpha: 1, scale: 1, duration: F(12), ease: "back.out(1.7)" }, t)
    .to(`${node} .label`, { opacity: 1, y: 0, duration: F(10), ease: "power3.out" }, t + F(4));
});
// le paquet part du nœud, trace le lien derrière lui (même durée, même courbe)
const land = at(6.5), TRIP = F(18);                  // 9 im à 30 fps ; arrivée sur le demi-temps
tl.set("#packet", { autoAlpha: 1 }, land - TRIP)
  .to("#packet", { motionPath: { path: "#l-2", align: "#l-2", alignOrigin: [0.5, 0.5] },
      duration: TRIP, ease: "power2.inOut" }, land - TRIP)
  .to("#l-2", { strokeDashoffset: 0, duration: TRIP, ease: "power2.inOut" }, land - TRIP)
  .set("#packet", { autoAlpha: 0 }, land).set("#n-guide", { autoAlpha: 1 }, land)
  .to("#n-guide", { scale: 1, duration: F(12), ease: "back.out(1.7)" }, land)
  .to("#n-guide .label", { opacity: 1, y: 0, duration: F(10), ease: "power3.out" }, land + F(4))
  .fromTo("#n-guide .ring", { scale: 1, opacity: 0.8 }, { scale: 2, opacity: 0, duration: F(20),
      ease: "power2.out", immediateRender: false }, land);
// flux d'ambiance : 3 points à vitesse constante, un nombre fini de tours (jamais repeat: -1)
const H0 = at(8), HOLD = at(4), LAP = F(40);
[0, 1, 2].forEach(k => {
  const t = H0 + k * LAP / 3;
  tl.set(`#dot${k}`, { autoAlpha: 1 }, t)
    .to(`#dot${k}`, { motionPath: { path: "#l-1", align: "#l-1", alignOrigin: [0.5, 0.5] },
        duration: LAP, ease: "none", repeat: Math.floor((H0 + HOLD - t) / LAP) - 1 }, t);
});
```

**After Effects**

- Nœuds : un calque de forme par nœud, libellé parenté au nœud. Scale (Échelle) 60 → 100 % en 12 im (60 fps), clé intermédiaire à 106 % pour le dépassement.
- Liens : tracés à l'outil Pen (Plume), puis Add › Trim Paths (Ajouter › Réduire les tracés), End (Fin) 0 → 100 % en 8 im, juste avant le nœud. Décalage des étapes par Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques) : 30 im (un temps à 120 BPM), ou 3 im pour des nœuds de même rang.
- Paquet : cercle + Effect › Stylize › Glow (Esthétique › Lueur). Copier le Path (Tracé) du lien et le coller dans la Position du paquet : les clés suivent la courbe. Dernière clé à 18 im de la première, Easy Ease (Lissage de vitesse, F9) ; mêmes clés sur le Trim Paths End du lien, qui se trace derrière le paquet.
- Arrivée : contour de la cible en Stroke Width (Épaisseur du contour) 0 → 4 px en 6 im, ou Scale 100 → 200 → 100 % (piste de transfert).
- Flux d'ambiance : sur le contour du lien, Dashes (Tirets) avec Offset (Décalage) piloté par l'expression `time * -60` : les tirets coulent à vitesse constante. Pour des points : `loopOut("cycle")` sur la Position, 3 calques décalés.
