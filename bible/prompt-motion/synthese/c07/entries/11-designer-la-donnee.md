## Désigner : balayage, surlignage, annotation (scan line sweep, highlight, leader-line callout, before/after slider)

Un élément dit où regarder : ligne de scan qui trie au passage, rideau avant/après, éléments non retenus qui s'éteignent, annotation qui chiffre un détail. La sélection se voit se faire : chaque carte change d'état à l'image où la ligne la touche. Le geste est court : un temps (30 im à 60 fps, 120 BPM) pour trier tout un mur. Vue dans 34 vidéos, dont 23 notées 4 ou 5.

**Règles de construction**

1. Le balayage cause le changement. Chaque élément change d'état à l'image où la ligne le touche : « how to clean a grinder » bascule à f207, quand le faisceau l'atteint (utopyaszx-1b2f94). 12 cartes et le compteur « ADS GENERATED » avancent ensemble (quickdesignio-dd93d0, 0:02.47).
2. Durée et courbe. Pour traverser le cadre : 20 à 64 im à 60 fps (0,33 à 1,07 s), en power2.inOut (étude theviableedge). Pour lire un document : vitesse constante, 30 à 43 im (sudo-kiran-6609ed, kyonax-on-tech-aabc1d).
3. Sélection : les retenus restent à 100 % (liseré de 2 px, échelle 1,1 ou pastille), les autres tombent à 25 à 50 %, parfois floutés de 4 px. Peu de gagnants : 3 chez twoclipping-6dd14e, un seul jour sur sept chez tankazunori0914-0fc886. C'est « un seul point focal à la fois » (guide Otom, p. 6).
4. Une annotation par figure, sans flèche : une mesure chiffrée et vraie, reliée par un filet fin à 45° (hbcoop-de365c) ou posée sous un anneau (« 212 accounts posting in sync », ismailfahmi-557268). Texte à 2,5 % H au moins ; à 1 % H il est jugé illisible. Filet : « Cadrer le mot clé » (chapitre 2) ; surligneur : « Le trait sur le mot » (chapitre 3).
5. Rideau avant/après : 7 im à 30 fps (l3d1c-0e35a3), 32 im à 60 fps (quickdesignio), 60 im pour une fiche produit entière (ceowinkz-7c776b). Le guide propose 3 s (guide Otom, p. 12) ; nos mesures donnent 0,2 à 1 s, et la Bible retient les mesures.
6. Calage, d'après les vidéos animées sur la musique : balayage d'un temps parti à −1,4 im d'une marque (reyzostyle-b55864) ; « Top post » sur le demi-temps (miskinho-443898) ; 7 légendes à 8 im d'écart, parties sur le temps et la montée (jesscaroline7-1ff7cb). Contre-exemple : elliot-garreffa-f334bc, un saut toutes les 0,75 s (1,4 temps). Sur voix off, voir « Le calage sur la voix off » (chapitre 9).

**Verdict** : à reprendre. Balayage qui trie et rideau avant/après montrent une action invisible (analyse, retouche) en 0,5 s, sans texte. À adapter : le radar à secteur tournant, poncif « tech » (marouanegazouzi-6071d5) ; une ligne droite dit la même chose. Aucune flèche : un filet fin ou un anneau suffit.

**Quand l'utiliser** : promo SaaS et interface, en plan de démonstration (le produit lit, trie, retouche) ou de preuve (le compteur monte avec la ligne). En explainer données ou showreel éditorial : une seule mesure chiffrée par figure. Se décide au découpage, se règle à la construction du plan. À éviter en typo cinétique pure, sur un écran sans rien à trier, et au-delà d'une désignation par plan.

**HyperFrames (GSAP)**

```js
// Ligne de scan qui trie un mur de cartes, compteur couplé, puis rideau avant/après
const FPS = 60, F = n => n / FPS;
const BEAT = 60 / 120, at = b => b * BEAT;        // 120 BPM : 1 temps = 30 im
const W = 1920, X0 = 0.04 * W, X1 = 0.96 * W;     // la ligne va de 4 à 96 % L
const T0 = at(6), D = BEAT, EASE = "power2.inOut"; // un temps ; "none" pour une lecture
const ease = gsap.parseEase(EASE);
const inv = p => { let a = 0, b = 1;              // instant où la ligne atteint la fraction p
  for (let i = 0; i < 24; i++) { const m = (a + b) / 2; if (ease(m) < p) a = m; else b = m; }
  return (a + b) / 2; };
tl.set("#scan", { x: X0, scaleY: 0, autoAlpha: 1 }, T0 - F(6))
  .to("#scan", { scaleY: 1, duration: F(6), ease: "power2.out" }, T0 - F(6))
  .to("#scan", { x: X1, duration: D, ease: EASE }, T0)
  .to("#scan", { autoAlpha: 0, duration: F(6), ease: "power1.in" }, T0 + D);
// chaque carte change à l'image où la ligne passe sur son centre
const hits = gsap.utils.toArray(".card").map(el => {
  const cx = el.offsetLeft + el.offsetWidth / 2;
  return { el, win: el.dataset.win === "1", t: T0 + D * inv((cx - X0) / (X1 - X0)) };
}).sort((a, b) => a.t - b.t);
let n = 0;
hits.forEach(({ el, win, t }) => {
  if (!win) { tl.to(el, { opacity: 0.25, filter: "blur(4px)", duration: F(8), ease: "power2.out" }, t); return; }
  n += 1;
  tl.to(el, { scale: 1.1, outlineColor: "#ffffff", duration: F(10), ease: "back.out(1.7)" }, t)
    .set("#found", { textContent: String(n).padStart(2, "0") }, t);          // compteur 00 → 09
});
// rideau : l'« après » entre par la droite en 32 im
const S = at(10);
tl.set("#after", { clipPath: "inset(0% 0% 0% 100%)" }, 0)
  .set("#handle", { left: "100%" }, 0)
  .to("#after", { clipPath: "inset(0% 0% 0% 0%)", duration: F(32), ease: "power2.inOut" }, S)
  .to("#handle", { left: "0%", duration: F(32), ease: "power2.inOut" }, S)
  .set("#badge", { textContent: "AFTER" }, S + F(16));
```

**After Effects**

- Ligne de scan : Layer › New › Shape Layer (Calque › Nouveau › Calque de forme), rectangle de 3 px sur toute la hauteur, Effect › Stylize › Glow (Effet › Esthétique › Lueur). Position X : 2 images clés sur 30 im (un temps à 120 BPM, 60 fps), Easy Ease (Lissage de vitesse, F9) puis Speed Graph (graphe de vitesse) à ≈ 50 % d'influence ; clés linéaires pour une lecture.
- Tri au passage : sur l'Opacity (Opacité) de chaque carte perdante, l'expression `x = thisComp.layer("Scan").transform.position[0]; linear(x, position[0] - 20, position[0] + 20, 100, 25)`. Idem pour Effect › Blur & Sharpen › Gaussian Blur (Flou et netteté › Flou gaussien), 0 → 4, et la Scale (Échelle) des gagnantes, 100 → 110 %.
- Gagnantes : Layer › Layer Styles › Stroke (Calque › Styles de calque › Contour), 2 px blanc. Compteur : Source Text (Texte source) compte par expression les gagnantes déjà dépassées par la ligne.
- Rideau : calque « Après » au-dessus de « Avant », Effect › Transition › Linear Wipe (Balayage linéaire), Transition Completion (Fin de transition) 100 → 0 % en 32 im, F9 ; régler Wipe Angle (Angle de balayage) pour que l'après entre par la droite. Poignée : Position X liée par expression à Transition Completion.
- Annotation : texte italique à 2,5 % H (27 px en 1080) et filet à 45°, Opacity 0 → 100 % en 10 im, 10 im après l'impact.
