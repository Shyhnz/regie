## La maquette d'appareil et l'interface reconstruite (device mockup, browser frame, tilted UI, rebuilt product UI)

Un téléphone, un navigateur ou une appli reconstruite en calques entre et porte la démo. Le cadre rend l'interface crédible ; reconstruite en HTML, chaque pastille ou ligne s'anime. Seul, l'appareil est banal : il devient fort quand il échange avec le plan, par exemple en aspirant des cartes en 14 im sur le temps. Vue dans 41 vidéos, dont 31 notées 4 ou 5.

**Règles de construction**

1. Taille : téléphone 18 à 25 % L sur 70 à 93 % H, navigateur 50 à 75 % L ; l'autre côté porte le titre. Ce qui se lit fait au moins 2,5 % H (4 % selon le guide Otom, p. 14). À 1-1,5 % H (Taxtello, [Tally product demo](https://prompt-motion.com/visheshbaghell-3aba37)), poussez la caméra sur l'élément (chapitre 5, « La poussée vers le sujet »).
2. Entrée : un seul geste, ease-out sans dépassement, 10 à 16 im ; trajet par image de 12, 9, 7, 5, 4, puis 2 % H ([Parenting app hype video](https://prompt-motion.com/francoxavier33-d2dfd2)). Inclinaison de −10 à −12° ramenée à 0 ou à −4°. Second appareil : un temps entier en power4.out. Angles : chapitre 5, « Les cartes en perspective ».
3. Jamais vide ni figé : la notification arrive 7 im après le départ (kangaroohere). Navigation interne en 6 im ([Sotto reading app explainer](https://prompt-motion.com/1stnoel-c20a89)), défilement de 15 % H en 4 im (slvdev). Le téléphone figé 35 s de Sotto est un temps mort.
4. Calage (vidéos animées sur la musique) : cartes parties sur le temps (Enxovaly), une étape par temps (kangaroohere), interrupteur au demi-temps ([UGC ad generator promo](https://prompt-motion.com/twoclipping-6dd14e)). Contre-exemple : écrans fondus toutes les 1,2 s hors temps ([AI Arena product promo](https://prompt-motion.com/ezshine-c90d73), musique partielle).
5. Reconstruire plutôt que capturer : couleurs exactes, chaque élément animable (Taxtello). Avec des captures, reproduire leur mise en page en HTML (guide Otom, p. 11) ; les captures brutes servent de preuve (chapitre 8, « La vraie matière »).
6. Un échange avec le plan : l'appareil aspire, éjecte (ViralGrow) ou termine un recul (chapitre 5, « Le recul révélateur »). Sinon, c'est « la scène la plus générique » ([Flowdrive motion showreel](https://prompt-motion.com/manuelogomigo-f33ca9)).

**Verdict** : à adapter. Le cadre qui glisse seul est un cliché de promo ; garde l'aspiration, l'éjection ou le recul, qui en font une transition motivée comme tu les aimes, et une UI reconstruite assez grosse pour être lue.

**Quand l'utiliser** : en promo SaaS / interface d'abord, pour la démonstration et la présentation produit. Le style d'appareil (réaliste, dessiné au trait, navigateur) se choisit à la direction artistique ; l'échange avec le plan, aux enchaînements. En typo cinétique 1600, au plus un plan, le temps d'une preuve. À éviter si le texte de l'écran ne peut pas dépasser 2,5 % H ou si rien ne s'y passe.

**HyperFrames (GSAP)**

```js
// Téléphone qui monte en se redressant, aspire les cartes sur le temps, puis une étape par temps
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 120;                       // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT;
const T0 = at(24);                           // 1er temps de la mesure
// Mesurer avant tout set, après document.fonts.ready
const s = document.querySelector("#screen").getBoundingClientRect();
const cards = gsap.utils.toArray(".card"), rs = cards.map(c => c.getBoundingClientRect());
tl.set("#phone", { yPercent: 110, rotation: -10, transformOrigin: "50% 100%" }, 0)
  .set(["#notif", "#inbox", "#article"], { autoAlpha: 0 }, 0)
  .set("#tap", { autoAlpha: 0, scale: 0.3 }, 0);
// 1. Montée en 10 im, ease-out sans dépassement, posée sur le temps
tl.to("#phone", { yPercent: 0, rotation: 0, duration: f(10), ease: "power3.out" }, T0 - f(10));
// 2. Sur le temps : les cartes plongent dans l'écran, 2 im d'écart, 12 im chacune
cards.forEach((c, i) => tl.to(c, {
  x: s.x + s.width / 2 - (rs[i].x + rs[i].width / 2), y: s.y + s.height / 2 - (rs[i].y + rs[i].height / 2),
  scale: 0.2, autoAlpha: 0, duration: f(12), ease: "power2.in" }, T0 + i * f(2)));
// 3. Une étape par temps : notification, boîte remplie, tap, article poussé en 6 im
tl.fromTo("#notif", { autoAlpha: 1, yPercent: -120 }, { yPercent: 0, duration: f(5), ease: "power3.out", immediateRender: false }, T0 + f(14))
  .set("#inbox", { autoAlpha: 1 }, T0 + at(1))
  .fromTo("#tap", { autoAlpha: 0.6, scale: 0.3 }, { autoAlpha: 0, scale: 1.6, duration: f(12), ease: "power2.out", immediateRender: false }, T0 + at(2))
  .fromTo("#article", { autoAlpha: 1, xPercent: 100 }, { xPercent: 0, duration: f(6), ease: "power2.out", immediateRender: false }, T0 + at(3));
// 4. Jamais figé : dérive de 0,4 px par image jusqu'à la coupe
tl.to("#phone", { y: -24, duration: at(2), ease: "none" }, T0 + at(1));
```

**After Effects**

- Appareil : coque en calque de forme Rectangle (Roundness (Arrondi) ≈ 8 % L) ; interface en calques de forme et de texte, Layer › Pre-compose (Calque › Précomposer), découpée par l'écran via Track Matte (Cache par approche) › Alpha Matte (Cache alpha).
- Entrée : point d'ancrage en bas avec le Pan Behind Tool (outil Déplacer l'arrière-plan) ; Position Y depuis le bas et Rotation −10 → 0° en 10 im ; Speed Graph (éditeur de graphe de vitesse), influence d'arrivée 80 %, sans dépassement ; Motion Blur (Flou de mouvement) activé.
- Aspiration : chaque carte vers le centre de l'écran, Scale (Échelle) 100 → 20 % et Opacity (Opacité) → 0 en 12 im, accélération finale (influence de départ 80 %) ; calques décalés de 2 im.
- Étapes : un repère toutes les 30 im (120 BPM, 60 fps) ; écran suivant en Position X de 100 % → 0 en 6 im ; tap : Ellipse, Scale 30 → 160 % et Opacity 60 → 0 en 12 im.
- Navigateur incliné : 3D Layer switch (commutateur Calque 3D), Y Rotation (Rotation Y) −10°, X Rotation (Rotation X) 4°, Layer › New › Camera (Calque › Nouveau › Caméra) ; dérive : expression `wiggle(0.5, 4)` sur Position.
