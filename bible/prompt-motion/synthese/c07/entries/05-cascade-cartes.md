## Les cartes et lignes en cascade (staggered card build, list rows, chips, bento cascade, card deal)

Des cartes, des lignes de tableau, des puces ou des tuiles entrent une à une avec un léger décalage (stagger) jusqu'à reconstituer un panneau, une liste ou une grille. Le décalage impose l'ordre de lecture et donne un rythme qu'on cale sur les croches : 4 im à 60 fps (0,067 s) dans la vidéo notée 5. Elle devient un cliché quand chaque plan entre de la même façon. Vue dans 61 vidéos, dont 46 notées 4 ou 5.

**Règles de construction**

1. Décalage : 3 à 4 im à 60 fps (2 à 3 im à 30 fps) quand le groupe se lit d'un bloc ([What day is it](https://prompt-motion.com/tankazunori0914-0fc886) 3 im, sudo-kiran 4 im, [Supademo launch video](https://prompt-motion.com/jhylee95-e1152f) 2 im). Une croche ou un temps par élément si chaque ligne se lit (AjustaCV 14 im ; [Chain.wtf pitch video](https://prompt-motion.com/spearwtf-3c1fd1) un élément par temps). Le guide Otom conseille 100 à 150 ms (guide Otom, p. 14) : c'est le haut de la fourchette, nos meilleures vont plus vite. Une carte toutes les 1,6 s laisse la 1re seule 3 s ([Animated business explainer](https://prompt-motion.com/alex-prompter-1ea044), noté 2).
2. Une carte : 9 à 15 im. Opacité en 4-5 im, montée de 2 à 10 % H en power2.out, rotation de −5° à 0 en 11 im. Sans dépassement : le rythme vient du décalage, pas du rebond. Pour un vol rapide, flou de mouvement sur 3 à 5 im ([Bento.surf product video](https://prompt-motion.com/bizibeast-10f264)).
3. Calage (vidéos animées sur la musique) : la 1re carte sur le temps (sudo-kiran +1 im, Bento.surf f62), la dernière sur l'accent suivant (Quetzal, clap f376 ; Supademo). Contre-exemples : un pas de 18 im contre un demi-temps de 19,05 im dérive ([Alan agent platform promo](https://prompt-motion.com/prasad-pilla-2c0cba), musique posée) ; des boucles hors grille dans un bento ([DistilBook product explainer](https://prompt-motion.com/sudo-kiran-4f8b59)).
4. La cascade fait avancer une donnée : total qui monte (AjustaCV), « N vagas » à chaque pose, « 12 FILES SELECTED » ([PicTwin AI app ad](https://prompt-motion.com/l3d1c-0e35a3)). Ordre : celui de la lecture ; alterner gauche et droite seulement pour une colonne.
5. Lisibilité : 3 à 7 éléments, texte d'au moins 2,5 % H. À 1-1,5 % H ([Nohandslabs brand promo](https://prompt-motion.com/robvjourney-ce3e1a), [Chunku product promo](https://prompt-motion.com/reyzostyle-b55864)), le panneau n'est qu'une texture. Après la pose, une dérive de ±0,5 % ([Stock analysis app promo](https://prompt-motion.com/aistocksavvy-3fb9f5)) évite l'image figée.

**Verdict** : à reprendre, avec un geste différent par scène (montée, donne, éventail, insertion) : c'est le même accent répété que tu rejettes. La cascade qui compte (ligne + total) est la plus forte.

**Quand l'utiliser** : en promo SaaS / interface pour les fonctions, les prix, un tableau de bord ; en explainer données pour une table qui s'additionne ; en showreel éditorial pour un bento. Fonction : présentation ou preuve. Décalage et courbe se fixent au système de design, le geste à la construction du plan. À éviter au-delà de 8 éléments à lire et pour un message unique. Voir aussi chapitre 2, « Grilles, bento et rangées de cartes », et chapitre 4, « Vider le cadre avant la coupe » pour la sortie.

**HyperFrames (GSAP)**

```js
// Cascade bento (étude 60 fps), puis lignes de tableau sur les croches avec total
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 120;                       // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT;
const T0 = at(20);                           // 1er temps de la mesure
tl.set(".card", { autoAlpha: 0, yPercent: 14, rotation: -5, scale: 0.95 }, 0)
  .set(".row", { autoAlpha: 0, y: -12 }, 0);
// 1. Cinq cartes à 4 im, la 1re 1 im après le temps
tl.to(".card", { autoAlpha: 1, duration: f(5), ease: "power1.out", stagger: f(4) }, T0 + f(1))
  .to(".card", { yPercent: 0, scale: 1, duration: f(14), ease: "power2.out", stagger: f(4) }, T0 + f(1))
  .to(".card", { rotation: 0, duration: f(11), ease: "power1.out", stagger: f(4) }, T0 + f(2));
// 2. Jamais figé : flottement lent après la pose
tl.to(".card", { y: -6, duration: at(2), ease: "sine.inOut", stagger: f(4) }, T0 + f(30));
// 3. Une ligne par croche, 9 im chacune ; le total suit chaque arrivée
const T1 = at(24), total = { v: 0 }, out = document.querySelector("#total");
gsap.utils.toArray(".row").forEach((r, i) => {
  const t = T1 + i * at(0.5);
  tl.to(r, { autoAlpha: 1, y: 0, duration: f(9), ease: "power2.out" }, t)
    .fromTo(total, { v: i * 7.8 }, { v: (i + 1) * 7.8, duration: f(9), ease: "power2.out",
      immediateRender: false,
      onUpdate: () => { out.textContent = "R$ " + total.v.toFixed(2).replace(".", ","); } }, t);
});
```

**After Effects**

- Une carte : calque de forme Rectangle, Roundness (Arrondi) ≈ 3 % H. Position Y +10 % H → 0 en 14 im, Rotation −5 → 0° en 11 im, Opacity (Opacité) 0 → 100 % en 5 im.
- Courbe : dans le Speed Graph (éditeur de graphe de vitesse), clé de départ à vitesse forte, influence d'arrivée 70 à 80 %, aucun dépassement. Activer Motion Blur (Flou de mouvement) pour les vols.
- Cascade : dupliquer la carte, puis décaler chaque calque de 4 im avec Option + Page Down (Alt + Page Down sous Windows), ou Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques).
- Lignes sur les croches : un repère toutes les 15 im à 120 BPM et 60 fps (touche * du pavé numérique), une ligne par repère. Total : Effect › Expression Controls › Slider Control (Paramètre glissière) et Source Text (Texte source) = `"R$ " + effect("Slider Control")("Slider").value.toFixed(2)`.
- Sortie : Position Y −7 % H en 8 im en Easy Ease (Lissage de vitesse), puis chute de 12 im, cartes à 1-4 im d'écart.
