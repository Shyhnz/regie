## Le prompt tapé et la réponse en flux (typed prompt, simulated typing, streaming AI answer, chat demo)

Un champ (prompt, recherche, URL, chat) se remplit lettre à lettre, l'envoi est validé, puis la réponse arrive : texte en flux, image, étapes d'agent cochées. Demande, attente, résultat : le geste résume un produit d'IA en 1 à 2 s. Il ennuie si la frappe dure plus de 2 s ou si la réponse ne montre rien. Vue dans 60 vidéos, dont 38 notées 4 ou 5.

**Règles de construction**

1. Le geste entier tient en 1 à 2 s. Chez fal : frappe 22 im, clic 6 im plus tard, tuiles 8 im après, plein cadre à f758, soit environ 1 s. Contre-exemples : 140 caractères en 4,8 s (justincooperman), 4 champs de formulaire en 4,6 s (majorbaguette).
2. Prompt court et réel : 20 à 70 caractères, tapés à 30 à 70 car./s, soit 1 caractère toutes les 1 à 2 im à 60 fps (miskinho : 22 car. à 29 car./s ; listudio : 66 car. à 32 car./s). Au-delà, on ne lit plus une frappe (reyzostyle, 2,6 car./im). Cadence, curseur, vitesse variable : voir « Le texte qui s'écrit sur place » (chapitre 3). Une URL se colle d'un coup (tstfully).
3. L'envoi est un changement d'état net, calé sur le temps (vidéos animées sur la musique) : bouton actif au 1er caractère (twoclipping-6dd14e) ou au champ complet (en-ra), clic sur la barre (fal, f728), bulle échangée en 1 image (wani-shola). Laisser lire le texte tapé 7 à 20 im avant l'envoi.
4. L'attente est courte et montrée : roue, « Thinking… » ou reflet gris, 0,3 à 1 s (majorbaguette : 30 im par outil ; ddryo-loos : un outil toutes les 0,3 à 0,5 s). Sur la musique, une étape cochée par temps (bizibeast).
5. La réponse montre un résultat : image, carte, puce verte, chiffre. Le texte de réponse va 2 à 3 fois plus vite que la demande, 66 à 90 car./s (aschapmann, mehul4795), ou mot à mot ; il se lit pendant le maintien.
6. Lisibilité : texte du champ à 4 % de la hauteur au moins (guide Otom, p. 14 ; miskinho 4,4 %). À 1 à 1,8 % (astrodevil, ddryo-loos, jhylee95), la démo est illisible sur téléphone : agrandir le champ seul plutôt que toute l'interface.

**Verdict** : à reprendre, à condition de tenir en 2 s et de finir sur un résultat visible. C'est l'accroche produit la plus directe ; fais du résultat l'objet relais du plan suivant.

**Quand l'utiliser** : promo SaaS et interface d'IA (prompt, recherche, chat, agent), en démonstration ou en accroche (barre vide dans le noir, listudio). On la décide au découpage, un plan « demande → résultat » par fonctionnalité ; police du champ et couleur du caret se fixent au système de design. À éviter pour un long texte à lire, une interface entière en petit, et plus de deux fois par film.

**HyperFrames (GSAP)**

```js
// Champ en ressort → frappe → envoi sur le temps → attente → réponse mot à mot → étapes cochées
const FPS = 60, BEAT = 60 / 120;                  // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT, F = n => n / FPS;
const PROMPT = "neon koi in liquid mercury";        // texte réel, 26 caractères
const field = document.querySelector("#prompt-text");
tl.set(["#bubble-user", "#spinner", ".tick"], { autoAlpha: 0 }, 0);
// 1. le champ éclôt sur le temps 0, dépassement ≈ 3 %
tl.set("#field", { scale: 0.2, autoAlpha: 0, filter: "blur(8px)" }, 0)
  .to("#field", { scale: 1, autoAlpha: 1, filter: "blur(0px)", duration: F(20), ease: "back.out(1)" }, at(0));
// 2. frappe : 26 car. en 24 im, power2.inOut sur le nombre de caractères, fin au demi-temps 2,5
const typ = { n: 0 };
tl.set(field, { textContent: "" }, 0)
  .to(typ, { n: PROMPT.length, duration: F(24), ease: "power2.inOut",
    onUpdate: () => (field.textContent = PROMPT.slice(0, Math.round(typ.n))) }, at(2.5) - F(24))
  .set("#send", { backgroundColor: "#5000B8" }, at(2.5) - F(23))   // bouton actif au 1er caractère
// 3. 15 im de lecture, clic sur le temps 3, bulle échangée en 1 image
  .to("#send", { scale: 0.92, duration: F(2), ease: "power2.in" }, at(3) - F(2))
  .to("#send", { scale: 1, duration: F(6), ease: "power2.out" }, at(3))
  .set("#field", { autoAlpha: 0 }, at(3)).set("#bubble-user", { autoAlpha: 1 }, at(3))
// 4. attente visible : une roue pendant 1 temps
  .set("#spinner", { autoAlpha: 1 }, at(3))
  .to("#spinner", { rotation: 360, duration: BEAT, ease: "none" }, at(3))
  .set("#spinner", { autoAlpha: 0 }, at(4));
// 5. réponse : 2 im par mot, gris clair → encre en 5 im
const words = [...document.querySelectorAll("#answer .w")];          // un <span class="w"> par mot
tl.set(words, { autoAlpha: 0, color: "#BDBDBD" }, 0);
words.forEach((w, i) => tl.set(w, { autoAlpha: 1 }, at(4) + F(2 * i))
  .to(w, { color: "#141414", duration: F(5), ease: "power1.out" }, at(4) + F(2 * i)));
// 6. étapes : la roue cède la place à la coche, une par temps dès le temps 6
document.querySelectorAll("#steps li").forEach((li, i) => tl
  .set(li.querySelector(".spin"), { autoAlpha: 0 }, at(6 + i))
  .fromTo(li.querySelector(".tick"), { autoAlpha: 1, scale: 0.5 },
    { autoAlpha: 1, scale: 1, duration: F(8), ease: "back.out(1.7)", immediateRender: false }, at(6 + i)));
```

**After Effects**

- Champ : calque de forme arrondi, Scale (Échelle) 20 → 103 → 100 % (clés à 0, 12, 20 im) et Effect › Blur & Sharpen › Gaussian Blur (Effet › Flou et netteté › Flou gaussien) 8 → 0 en 8 im, sur le Composition Marker (marqueur de composition) du temps.
- Frappe à vitesse variable : expression sur Source Text (Texte source) : `s = "neon koi in liquid mercury"; t = linear(time, inPoint, inPoint + 24 * thisComp.frameDuration, 0, 1); e = t < 0.5 ? 2 * t * t : 1 - Math.pow(2 - 2 * t, 2) / 2; s.substr(0, Math.round(e * s.length))` (power2.inOut).
- Envoi : Opacity (Opacité) du champ et de la bulle en Toggle Hold Keyframe (Basculer l'image clé maintenue) sur le marqueur du temps 3 ; bouton Scale 100 → 92 → 100 % en 2 + 6 im ; roue : Rotation (Rotation) `time * 720`.
- Réponse : Animation › Animate Text › Opacity (Animation › Animer le texte › Opacité) à 0 % plus Fill Color (Couleur de remplissage) grise ; Range Selector (Sélecteur de plage) › Advanced › Based On : Words (Avancé › Basé sur : Mots), Shape : Ramp Up (Forme : Rampe montante) ; Offset (Décalage) animé de −100 à 100 % en linéaire, 2 im par mot.
- Étapes : une coche par ligne, Scale 50 → 110 → 100 % en 8 im sur son marqueur ; la roue passe à 0 % d'Opacity à la même image.
