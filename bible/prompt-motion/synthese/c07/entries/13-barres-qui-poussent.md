## Les barres qui poussent et se réordonnent (staggered bar chart, bar race, re-sort, before/after bars)

Des barres poussent depuis leur base l'une après l'autre, avec leur chiffre, puis changent de valeur ou de rang. La comparaison se lit d'un coup d'œil : deux barres de 8 et 18 % de la hauteur disent « doublé » en 0,3 s. La cascade donne le rythme, l'accent désigne le gagnant. Vue dans 29 vidéos, dont 24 notées 4 ou 5.

**Règles de construction**

1. Un décalage court et régulier. Pour 7 à 12 barres : 2 à 3 im à 60 fps (ndhabarde11, vanshwtfff), 3 im à 30 fps, soit 100 ms (rammanq, andginja, danilowm). Le guide donne aussi « des barres qui montent avec 100 ms d'écart » (guide Otom, p. 9). Pour 4 ou 5 lignes avec libellés, une double-croche (johnsavage, 7 à 8 im à 128 BPM).
2. Départ vif, arrivée longue, sans rebond. Johnsavage affiche 29 % dès la 1re image, 90 % en 4 im, posée en 10 im ; vanshwtfff pousse en 6 à 8 im. Les longues barres horizontales prennent 16 à 26 im (charlesmendez ; daniel-haida, power2.out, étude 60 fps). Un dépassement d'≈ 15 %, si on en veut un, sur la 1re barre seulement (slvdev, probable).
3. Le chiffre colle à la barre : même départ, même courbe, même durée (johnsavage ; danilowm, Hotéis 283 → 453 → 574 → 601 ; reyzostyle, 31× avec la barre). Chiffres à chasse fixe : voir « Le compteur qui roule ».
4. Un seul accent, qui porte le message : la dernière ou la gagnante (ndhabarde11 orange, vanshwtfff rouge, safarkhanshuvo citron). Dans une bascule, la gagnante change de couleur pendant sa montée (charlesmendez). Voir chapitre 6, « La palette fermée et l'accent qui a un sens ».
5. L'événement qui change le sens tombe sur la grille : clic de bascule au demi-temps (charlesmendez), chute de barre sur une attaque (kloss-xyz-fe0c31, 96,15 s), chiffre posé à −1,3 im d'une marque (reyzostyle). (vidéos animées sur la musique).
6. Lisible et honnête. Libellés d'au moins 2,5 % H (kloss-xyz-15182a) ; à 1 % H c'est illisible (daniel-haida, visheshbaghell). Échelle qui part de 0 (guide Otom, p. 9) et forme fidèle : la cloche de blushpetal795 ne vient pas de la donnée. Au réordonnancement, jamais deux barres superposées (ratheejaisal, f780 : valeurs illisibles).

**Verdict** : à reprendre. La cascade avec accent final et la bascule de comparaison sont les preuves chiffrées les plus nettes du corpus. Le meilleur départ : des barres nées du plan précédent, comme la spirale de [Lism CSS 1.0 release video](https://prompt-motion.com/ddryo-loos-300829) qui se déroule en histogramme en 24 im. Évite le tableau de bord où barres, jauge et courbe bougent ensemble (safarkhanshuvo, vanshwtfff) : un graphique, un message.

**Quand l'utiliser** : en promo SaaS pour la preuve (avant / après, vous contre le concurrent), en explainer de données (classement), en showreel (compétences). On la choisit au découpage pour le plan preuve, puis on la règle à la construction du plan. À éviter pour une valeur seule (préférer « Le compteur qui roule » ou « La jauge qui se remplit »), pour une tendance dans le temps (« La courbe qui se trace ») et au-delà de 12 barres. La durée a un sens : une barre « ~1 min » remplie en 0,17 s se contredit (heyiammallik).

**HyperFrames (GSAP)**

```js
// 4 barres en cascade à la double-croche, chiffre collé à chaque barre,
// puis bascule au demi-temps : notre barre passe devant et vire à l'accent
const FPS = 60, BPM = 120;
const BEAT = 60 / BPM;                                 // 30 im ; double-croche 7,5 im
const at = b => Math.round(b * BEAT * FPS) / FPS;      // temps (même fractionnaire) → image exacte
const F = n => n / FPS;
const rows = ["#r-us", "#r-google", "#r-meta", "#r-organic"];
const before = [6, 58, 24, 12], after = [41, 27, 19, 13];   // % de la piste
const start = 40;                                      // temps 40

// scaleX déforme les coins arrondis : sinon animer width en %
tl.set(".fill", { scaleX: 0, transformOrigin: "0% 50%" }, 0)
  .set(".val", { textContent: 0 }, 0)
  .set("#delta", { autoAlpha: 0 }, 0);
rows.forEach((r, i) => {
  const t = at(start + i / 4);                         // une double-croche d'écart
  tl.to(`${r} .fill`, { scaleX: before[i] / 100, duration: F(12), ease: "expo.out" }, t)
    .to(`${r} .val`, { textContent: before[i], snap: { textContent: 1 },
                       duration: F(12), ease: "expo.out" }, t);   // même courbe que la barre
});
// Bascule : clic au demi-temps, 32 im en ease-in-out
const flip = at(start + 2.5);
tl.to("#toggle .pill", { xPercent: 100, backgroundColor: "#22E55A", duration: F(4), ease: "power2.out" }, flip);
rows.forEach((r, i) => {
  tl.to(`${r} .fill`, { scaleX: after[i] / 100, duration: F(32), ease: "power2.inOut" }, flip)
    .to(`${r} .val`, { textContent: after[i], snap: { textContent: 1 },
                       duration: F(32), ease: "power2.inOut" }, flip);
});
tl.to("#r-us .fill", { backgroundColor: "#22E55A", duration: F(32), ease: "power2.inOut" }, flip)
  .set("#delta", { autoAlpha: 1 }, flip + F(36));       // badge d'écart, puis la phrase de conclusion
```

**After Effects**

- Une barre = un Shape Layer (calque de forme) avec un Rectangle. Avec le Pan Behind (Anchor Point) Tool (outil Déplacer l'arrière-plan, touche Y), poser le point d'ancrage au pied de la barre. Animer Scale (Échelle) en x seulement, de 0 à la valeur.
- Courbe : 2 images clés sur 12 im. Dans le Speed Graph (éditeur de graphe de vitesse), sortie de la 1re clé à influence 0 % et vitesse haute, entrée de la 2e à influence 90 % (≈ expo.out).
- Cascade : décaler chaque calque de 7 ou 8 im en alternance (double-croche à 120 BPM = 7,5 im). Alt + Page Down décale le calque d'une image plus tard. Poser un Composition Marker (marqueur de composition) sur chaque temps pour caler la bascule.
- Chiffre collé : calque de texte, sur Source Text (Texte source) l'expression `Math.round(thisComp.layer("Barre 1").transform.scale[0])`. Barre pleine = piste entière : l'échelle est le pourcentage.
- Bascule : au demi-temps, nouvelles clés de Scale sur 32 im avec Easy Ease (Lissage de vitesse, F9), et clés de Fill › Color (Fond › Couleur) sur la gagnante. Pour un réordonnancement, animer aussi Position y, sans superposer deux rangs.
