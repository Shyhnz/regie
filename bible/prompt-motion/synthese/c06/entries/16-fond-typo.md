## Le mur de mots en filigrane (outlined text marquee wall, giant outline watermark, scrolling ticker background)

Le fond est fait du texte lui-même : le mot clé répété en contour sur des rangées qui défilent, une année ou un chiffre géant en contour, un mur de données ou de prompts presque invisible. Il remplit le cadre avec le sujet du plan. Il tient tant qu'il reste un ton au-dessus du fond et qu'il dure 1 à 2 temps ; plus contrasté ou plus long, il se lit à la place du mot plein. Vue dans 28 vidéos, dont 24 notées 4 ou 5.

**Règles de construction**

1. Un ton d'écart avec le fond, jamais plus : contour de +10 à +20 % de luminance sur sombre (tequilafunks, crazyalphaaa, motiondsgnr), ton sur ton à ≈ 8 % (tankazunori0914, melvynx), données à ≈ 15 % d'opacité (kloss-xyz-15182a). Le mot plein reste le seul élément à plein contraste.
2. Un mur en contour dure 1 à 2 temps : 29 im chez heyiammallik (1 temps à 120 BPM), 27 im chez 3xtihor (1 temps à 128), 1,6 temps chez tequilafunks, ≈ 1,75 chez zaqailo. Un fond de données peut tenir tout un plan (10 s chez kloss-xyz-15182a), car il est illisible à dessein, à ≈ 1 % H.
3. Vitesse : ≈ 15 % L par seconde en sens alternés (tequilafunks 0,56 % L par image à 30 fps, heyiammallik 0,24 % à 60 fps). À ≈ 90 % L par seconde, il ne tient qu'un temps (3xtihor). Le mur qui accélère sur une mesure entière est le cliché de « Le texte en motif ».
4. Le fond répète le sujet ou dit son sens. Soit le même mot que le mot plein (EMOTION, MOTION — DESIGN). Soit sa source : prompt système derrière « before you said hi », génome brut (madebyjmayala), légende répétée qui dit « rien n'a changé » (melvynx). Un texte sans rapport n'est que du bruit.
5. Un seul niveau de lecture : le timecode géant de web3wesley-7bb108 (≈ 45 % H, gris sombre) se bat avec le mot TIME, sombre lui aussi. Un contour CSS sur une police variable montre ses traits internes (motiondsgnr-9dcfa6) : police statique ou SVG.
6. Bords : rangées plus larges que le cadre et bouclées, mot plein entier. Un filigrane rogné ne passe que très sombre (kloss-xyz-fe0c31) ; tolgayhickiran et ndhabarde11 coupent des mots lisibles, défaut que tu rejettes.

**Verdict** : à adapter. Garde le filigrane qui dit quelque chose : année ou numéro de chapitre géant en contour, texte source qui défile, légende répétée ; c'est ton « mot fantôme géant en contour derrière un graphique ». Le mur de rangées reste un tic de tendance : un temps au plus, net, ton sur ton, jamais flou, sinon c'est le mur de mots flous que tu rejettes.

**Quand l'utiliser** : en typo cinétique 1600 et showreel, mur en contour d'un temps derrière le mot plein, sur un temps fort. En explainer chronologique, année ou numéro de chapitre en filigrane, décidé au système de design (voir « La hiérarchie du bloc texte »). En promo SaaS ou IA, données ou prompt qui défilent pour faire vivre les maintiens d'accroche ou de preuve. À éviter derrière un texte de plus de 3 mots et sur toute la durée.

**HyperFrames (GSAP)**

```js
// Mur de mots en contour derrière le mot plein : 8 rangées, sens alternés, 2 temps ; puis filigrane d'année par chapitre
const FPS = 60, BEAT = 60 / 120, at = b => b * BEAT;   // 120 BPM : 1 temps = 30 im
const W = 1920, V = 0.15 * W;                          // ≈ 15 % de la largeur par seconde
// CSS : .row { white-space:nowrap; color:transparent; -webkit-text-stroke:2px #3A3A3A; font-size:12vh }
// Police statique ; chaque rangée répète la phrase sur au moins 4 000 px (aucun bord visible)
const rows = gsap.utils.toArray(".wall .row");
const start = at(5), len = 2 * BEAT;                   // le mur vit du temps 5 au temps 7
tl.set(".wall", { autoAlpha: 0 }, 0)
  .set(rows, { autoAlpha: 0, x: (i, el) => -el.offsetWidth / 4 }, 0)
  .set(".wall", { autoAlpha: 1 }, start)               // sur la coupe, pas en fondu
  .to(rows, { autoAlpha: 1, duration: 1 / FPS, stagger: 1 / FPS }, start)   // une rangée par image
  .to(rows, { x: (i, el) => -el.offsetWidth / 4 + (i % 2 ? 1 : -1) * V * len,
              duration: len, ease: "none" }, start)    // défilement linéaire, sens alternés
  .set(".wall", { autoAlpha: 0 }, start + len);        // coupé net après 2 temps
// Le mot plein, seul à plein contraste, entre au-dessus du mur
tl.set("#word", { autoAlpha: 0 }, 0)
  .set("#word", { autoAlpha: 1 }, start);
// Filigrane d'année : contour 2 px, ≈ 65 % H, un ton au-dessus du fond ; change au 1er temps de chaque mesure
const years = gsap.utils.toArray(".year");             // 1943, 1950, 1956… empilées au même endroit
tl.set(years, { autoAlpha: 0 }, 0);
years.forEach((y, k) => {
  tl.set(y, { autoAlpha: 1 }, at(8 + 4 * k))
    .set(y, { autoAlpha: 0 }, at(12 + 4 * k));
});
```

**After Effects**

- Rangée : un calque de texte ; dans le Character panel (panneau Caractère), Fill Color (couleur de fond) sur No Fill Color (aucune couleur) et Stroke (contour) de 2 px, un ton au-dessus du fond ; la phrase répétée sur au moins deux largeurs de cadre. Dupliquer en 8 rangées (Ctrl+D).
- Défilement : sur Position, l'expression `value + [(index % 2 ? 1 : -1) * 0.15 * thisComp.width * (time - inPoint), 0]` (≈ 15 % de la largeur par seconde, sens alternés).
- Apparition d'une rangée par image : Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques), décalage 1 im ; couper tous les calques après 2 temps (Alt + ]).
- Filigrane d'année : un calque de texte à ≈ 65 % H, en contour seul. Sur Source Text (Texte source), une image clé par chapitre, posée sur le marqueur du 1er temps ; ces images clés sont toujours maintenues.
- Texte source qui défile : texte mono à ≈ 1 % H, Opacity (Opacité) 15 %, Position Y en deux images clés linéaires ; aucun flou, le mur reste net.
