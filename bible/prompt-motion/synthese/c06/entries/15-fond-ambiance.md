## Le fond d'ambiance : halo radial, dégradé fluide, grille fine (radial glow background, vignette, mesh gradient, drifting blurred blobs, faint grid or dot grid)

Derrière le contenu, un fond qui bouge à peine : halo radial et vignette, taches floues qui dérivent (dégradé fluide), grille fine ou trame de points. Il donne profondeur et température sans prendre l'œil, si sa texture reste à 2-8 % de contraste. Son défaut le plus courant est l'immobilité : 22 des 32 occurrences « à adapter » le sont parce que le fond ne bouge jamais. Vue dans 85 vidéos, dont 62 notées 4 ou 5.

**Règles de construction**

1. Contraste de texture de 2 à 8 % : grilles à ≈ 3 % d'opacité (macrohou, lexnlin) ou 5-8 % (adamdesgns). Vignette : coins 15 à 40 % plus sombres (henkvaness, codestackr). Plus fort, le fond vibre : les chevrons tramés d'anthonyriera moirent.
2. Dégradé fluide : 2 à 5 taches de 30 à 60 % du cadre (xelandre, agonaliu, safarkhanshuvo). Leurs couleurs viennent de la palette ou du logo (les 4 du logo chez mehul4795). Sur clair, des pastels proches du fond ; sur sombre, des halos à peine plus clairs (#3A22A8 sur #0B0920 chez kmasiff).
3. Le fond vit pendant les maintiens : dérive de 1 à 15 % du cadre par seconde (slvdev ≈ 1 %, imthatcarlos 10 %, steventey ≈ 12 %). Figé, il fait temps mort (ai-baymax, ezshine : 65 s fixes). Jamais en couleur : la teinte qui tourne de 60° par seconde (henkpoley) est un cliché.
4. Le fond change avec la structure, sur le temps. Le halo change de place à chaque plan (astrodevil), les taches se recomposent à chaque chapitre (polydao), le monde bascule par un iris (sudo-kiran). La grille se construit sur 3 temps (zaqailo, probable) et part en un temps exact (fionntobin).
5. Une seule texture, qui dit quelque chose : grille = ingénierie (prasad-pilla, adamdesgns), points = fichier de travail (kikelopezdesign). La grille de points statique par défaut est un tic des SaaS faits par IA (miskinho, cliché).
6. Particules rares, ≈ 1 % L : lucioles d'anas0ra (montée de 10 % H en 14 im). Clichés : ≈ 15 carrés translucides aux superpositions boueuses (bizibeast), rubans de lignes fines (jasonzhou1993), ton fond « lignes néon » refusé.

**Verdict** : à reprendre pour le dégradé fluide qui dérive lentement, ton fond préféré, posé sur un halo et une vignette. À adapter pour la grille et la trame : seulement si elles disent quelque chose, et en naissant ou en partant sur le temps. Le guide bannit les dégradés (guide Otom, p. 7 et p. 14) ; nos mesures les trouvent dans 5 des 17 vidéos notées 5 : c'est une règle d'éditorial sobre, pas une règle générale.

**Quand l'utiliser** : promo SaaS / interface (dégradé pastel, papier quadrillé), showreel éditorial (grille de construction), style nuit et lueur (halo), explainer de données (grille fine). Il porte tout le film et la signature ; on le choisit à la direction artistique et au système de design. À éviter figé (voir « Le maintien : temps de lecture ou temps mort ») ; pour battre la mesure, voir « Le décor qui bat la mesure ».

**HyperFrames (GSAP)**

```js
// Dégradé fluide (recette NuOps) : position des taches = fonction pure du temps ; grille retirée en 1 temps
const FPS = 60, BEAT = 60 / 128, at = b => b * BEAT;   // 128 BPM
const DUR = 15, W = 1920, H = 1080;
const COLORS = ["#F9BABF", "#FDE8D7", "#C9E5FC", "#F3E6F5"];   // pastels pris dans la palette
// [centre x, centre y, amplitude x, amplitude y, pulsation x, pulsation y, phase], en fractions du cadre
const P = [[0.30, 0.80, 0.30, 0.20, 0.31, 0.37, 0.0], [0.70, 0.75, 0.25, 0.18, 0.27, 0.33, 1.7],
           [0.25, 0.30, 0.20, 0.16, 0.23, 0.29, 3.1], [0.80, 0.25, 0.22, 0.18, 0.33, 0.25, 4.4]];
const box = document.querySelector("#mesh");   // position:absolute; inset:0; overflow:hidden
const blobs = COLORS.map(c => {
  const b = document.createElement("i"), sz = 0.5 * W;   // 50 % de la largeur
  b.style.cssText = `position:absolute;left:0;top:0;width:${sz}px;height:${sz}px;margin:${-sz / 2}px 0 0 ${-sz / 2}px;` +
    `border-radius:50%;background:radial-gradient(circle, ${c} 0%, ${c} 28%, transparent 70%);filter:blur(90px)`;
  box.appendChild(b); return b;
});
const st = { t: 0 };
const draw = () => blobs.forEach((b, i) => {
  const [cx, cy, ax, ay, wx, wy, ph] = P[i];   // vitesse max ≈ 5 % du cadre/s
  const x = W * (cx + ax * 0.5 * Math.sin(st.t * wx + ph)), y = H * (cy + ay * 0.5 * Math.cos(st.t * wy + ph * 1.3));
  b.style.transform = `translate(${x.toFixed(1)}px, ${y.toFixed(1)}px)`;
});
draw();
tl.to(st, { t: DUR, duration: DUR, ease: "none", onUpdate: draw }, 0)   // dérive continue
  .set(box, { opacity: 0.45 }, 0)                                 // discret sous les textes longs
  .to(box, { opacity: 0.9, duration: 12 / FPS, ease: "power2.out" }, at(28));   // plein sous la signature
// Grille de construction : tracée en 5 im au 1er temps, retirée en exactement 1 temps (sine.in)
tl.set(".grid-line", { scaleX: 0, transformOrigin: "0% 50%" }, 0)
  .to(".grid-line", { scaleX: 1, duration: 3 / FPS, ease: "power1.out", stagger: { amount: 2 / FPS } }, at(0))
  .set(".grid-line", { transformOrigin: "100% 50%" }, at(29))
  .to(".grid-line", { scaleX: 0, duration: BEAT, ease: "sine.in" }, at(29));
```

**After Effects**

- Dégradé fluide : un Solid (solide) clair, puis Effect › Generate › 4-Color Gradient (Effet › Générer › Dégradé 4 couleurs) avec 4 pastels de la palette, Blend (Fusion) ≈ 300. Sur Point 1 à 4, l'expression `wiggle(0.3, 150)` : dérive lente, identique à chaque rendu.
- Halo et vignette : Effect › Generate › Gradient Ramp (Dégradé), Ramp Shape: Radial Ramp (Forme : radiale), centre un peu plus clair. Vignette : Solid noir, Ellipse Tool (outil Ellipse) pour un Mask (masque) inversé, Mask Feather (Contour progressif du masque) ≈ 400 px, Opacity (Opacité) 25 à 40 %.
- Grille : Effect › Generate › Grid (Grille), Border (Bordure) 1 px, Opacity 3 à 5 %. Tracé : Effect › Transition › Linear Wipe (Balayage linéaire), Transition Completion (Fin de transition) 100 → 0 % en 5 im au 1er temps ; retrait 0 → 100 % en un temps (28 im à 128 BPM), Easy Ease In (Lissage de vitesse entrant).
- Trame de points : Shape Layer (calque de forme), une Ellipse de 2 px, puis Add › Repeater (Ajouter › Répéteur) deux fois, horizontal puis vertical, pas de 45 à 67 px.
