## Les motifs radiaux : orbites, cadrans, rayons et tunnels (orbit rings with satellites, dial and radar sweep, sunburst, speed lines, concentric ring tunnel)

Une géométrie tourne ou s'étend autour d'un centre : satellites, cadran, radar, rayons, lignes de vitesse, anneaux en tunnel. Tout pointe vers le centre, donc vers le mot ou le logo qui s'y trouve, et la rotation fait vivre un plan tenu. Le meilleur cas monte un astérisque de 12 rayons à raison d'un par image. Vue dans 49 vidéos, dont 44 notées 4 ou 5.

**Règles de construction**

1. Le centre porte le message : mot, logo ou point. La géométrie l'entoure entre 25 et 82 % H (astérisque 40 %, radar 60 %, cadran d'itsuki-dev 82 %). Décor discret : guides de 1 px gris sombre (raphaelaubryy).
2. Naissance depuis le centre en 12 à 22 im, ease-out : astérisque power1.out 22 im, cadran expo.out 15 im, satellites 14 im. La duplication radiale va à un rayon ou un satellite par image.
3. Rotation de tenue lente et constante, ≈ 1° par image (40° en 41 im, ease none, roundtablespace). Les vitesses rapides vont au balayage : 22° par image chez [QuickDesign brand promo](https://prompt-motion.com/quickdesignio-dd93d0). Des anneaux à vitesses différentes donnent la profondeur (web3wesley, sudo-kiran-49176d).
4. Calage, tiré des vidéos animées sur la musique : naissance, épaississement et pose sur les temps (roundtablespace f28, f56, f365). Lignes de vitesse posées en 1 im sur le temps (micheleharmonic). Anneaux qui pulsent sur chaque noire à 0 im (monokern). Avant la coupe, on accélère : torsion expo.in de 7 im (web3wesley), poussée de +33 % en 7 im power2.in (zheke, étude 60 fps).
5. Une orbite finit quelque part : les satellites freinent et se rangent en croix ou en couronne. Contre-exemple : chez [Muse connector tracker promo](https://prompt-motion.com/elliot-garreffa-f334bc), un point qui glisse sur l'ellipse est seul à bouger pendant 2 s.
6. Le soleil rayonnant revient 9 fois, dont 5 jugées « cliché » : il tourne sans rien dire. S'il sert, c'est en ponctuation sur le 1er temps, assombri en 20 im (ibrahimwasim240). Le moiré op-art scintille : un demi-temps au plus.

**Verdict** : à adapter. Aiguille, orbite verrouillée et cadran-ligne de base sont à reprendre. Le soleil qui tourne derrière un titre est un cliché : remplace-le par des lignes de vitesse sur le temps. Ton tunnel filaire néon se traverse comme au chapitre 5 (« La plongée traversante »).

**Quand l'utiliser** : en showreel éditorial et en typo cinétique 1600, pour l'accroche ou le fond d'un mot tenu. En promo SaaS, il met en orbite les intégrations autour du logo (notdwd, réseau de partenaires de steventey). Le cadran dit « mesure », le radar « surveillance ». On le choisit à la direction artistique s'il devient le motif signature, puis à la construction du plan. À éviter derrière un texte long et en décor continu. Le badge circulaire qui tourne relève du chapitre 3 (« Le texte en motif : anneaux, orbites, échos, bandeaux »).

**HyperFrames (GSAP)**

```js
// A. Aiguille qui laisse un rayon par image (étude 60 fps), 128 BPM
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128, at = b => b * BEAT;
const T1 = at(1);                                    // cadran sur le temps 1
const RAYS = gsap.utils.toArray("#dial .ray");       // 12 traits SVG, viewBox centré sur 0 0
tl.set(RAYS, { autoAlpha: 0 }, 0).set("#dial", { autoAlpha: 0, scale: 0.13 }, 0)
  .set("#dial", { autoAlpha: 1 }, T1)
  .to("#dial", { scale: 1, duration: f(22), ease: "power1.out" }, T1)        // 5 → 40 % H
  .to("#hand", { rotation: 360, svgOrigin: "0 0", duration: f(12), ease: "none" }, T1)
  .to("#wave", { scale: 1.35, autoAlpha: 0, duration: f(19), ease: "power2.out" }, T1 + f(7));
RAYS.forEach((el, i) => tl.set(el, { autoAlpha: 1, rotation: i * 30, svgOrigin: "0 0" }, T1 + f(i + 1)));
tl.set("#hand", { autoAlpha: 0 }, T1 + f(12))
  .to(RAYS, { attr: { "stroke-width": 15 }, duration: f(2), ease: "power2.out" }, at(2))  // ×5
  .to("#dial", { rotation: 40, duration: f(41), ease: "none" }, at(2));      // ≈ 1° par image

// B. Quatre satellites tournent, freinent et se verrouillent en croix sur le temps 6
const LOCK = at(6), SPIN = f(20), R = 216;          // rayon : 20 % d'un cadre de 1 080 px
const sats = gsap.utils.toArray(".sat");
const orbit = { a: 540 };                            // 1,5 tour avant la croix, sens antihoraire
const place = () => sats.forEach((el, i) => {
  const a = (orbit.a + i * 90) * Math.PI / 180;
  gsap.set(el, { x: R * Math.cos(a), y: R * Math.sin(a) });
});
tl.set(sats, { autoAlpha: 0 }, 0)
  .set(sats, { autoAlpha: 1 }, LOCK - SPIN)
  .to(orbit, { a: 0, duration: SPIN, ease: "expo.out", onUpdate: place }, LOCK - SPIN);
```

**After Effects**

- Aiguille : un Shape Layer (calque de forme) avec un trait, Add › Repeater (Ajouter › Répéteur), Rotation 30°. Copies 1 → 12 en 12 im, en Hold Keyframes (images clés maintenues) ; Stroke Width (épaisseur du contour) ×5 sur le temps 2.
- Orbite : Layer › New › Null Object (Calque › Nouveau › Objet nul) au centre, satellites parentés à 216 px ; Rotation du nul 540 → 0° en 20 im, influence d'arrivée 90 % dans le Speed Graph (éditeur de graphe de vitesse).
- Radar : un cône en Gradient Fill (remplissage dégradé), Rotation par l'expression `time*180`. Traîne : Effect › Time › Echo (Effet › Temps › Écho), Number of Echoes 10, Decay 0,7.
- Lignes de vitesse : Effect › Noise & Grain › Fractal Noise (Bruit et grain › Bruit fractal) étiré en hauteur, puis Effect › Distort › Polar Coordinates (Déformation › Coordonnées polaires) en Rect to Polar. Effect › Time › Posterize Time (Postérisation temporelle) à 20 pour l'animation « en trois ».
- Anneaux à brèche : Ellipse avec Trim Paths (Réduire les tracés) à 85 %, Rotation `time*v`, une vitesse v par anneau.
