## Le coup de flash : surexposition, image négative, glitch RVB (flash frame, overexposure flash, invert flash, RGB split glitch hit)

Pendant une à quatre images, tout le cadre passe à la couleur d'accent, au négatif ou au décalage RVB, puis revient. Posé sur un coup fort ou un mot-choc, il fait sentir l'impact avant la lecture. Ici, la couleur du coup ; le flash blanc qui cache une coupe est au chapitre 4 (« Le flash et la surexposition »). Vue dans 67 vidéos, dont 59 notées 4 ou 5.

**Règles de construction**

1. Pic court, retour selon le type. Flash de couleur : pic de 1 à 2 im, retombée de 4 à 14 im en power1.out à power3.out (samaote 10 im ; zheke 14 im, étude 60 fps). Négatif : 2 im francs, retour sec, sans fondu (lexnlin, itsuki-dev, micheleharmonic). Flash local : déclin linéaire en 0,3 s (rebutonepress ; parkerrex 9 im à 30 fps).
2. Le pic tombe sur l'image du temps ou 1 à 2 im avant l'attaque audible : −1,8 im (lexnlin), −1 im (kloss-xyz, himanshutwtxs, ndhabarde11), −0,3 im (samaote). Contre-exemples : 3 im avant le temps, hors grille (aistocksavvy) ; 4 im avant le temps et 8 im avant l'impact (m1n9-k7).
3. Une couleur pleine de la palette : l'accent, le crème, ou la couleur du plan suivant, qu'il annonce (majin-appsheet : rose pâle, rose vif, rouge #D6002F en 3 im). Le gris moyen éteint l'image : #7F7E7B (teslachartz), #7B716E « boueux » (ho-ba), voile gris à 65 % « délavé » (oliahmed205).
4. Rare, donc hiérarchisé : 4 négatifs en 11 s (lexnlin), un seul sur l'entrée de la grosse caisse (itsuki-dev), réservé aux 2 plus gros impacts (chrisjdimarco), crash 3 fois aux débuts de section (kamstudiolabs). À chaque arrivée, c'est un tic (codestackr, gorden-sun).
5. Le négatif est une vraie inversion fond ↔ figure. Garder la teinte d'accent (lexnlin) ou laisser venir les complémentaires (micheleharmonic : bleu ↔ orange). Un flash peut aussi être sombre : bleu nuit #090B1D 28 im sur la coupure de la musique (fionntobin, voir « Le temps fort », chapitre 9).
6. Pas plus de 3 flashs plein cadre par seconde (règle d'accessibilité courante, risque photosensible). Le stroboscope négatif 2 im / 2 im de majin-appsheet bat à 7,5 Hz pendant 13 im : à réserver à moins d'une demi-seconde, en amplitude réduite.

**Verdict** : à adapter. Le flash d'accent et le négatif sont à reprendre, 2 à 4 fois par film, sur les attaques majeures et dans une couleur de la palette. Le glitch RVB décoratif reste un cliché (chapitre 4, « Le glitch en tranches et RVB, un cliché ») : c'est l'accent répété que tu rejettes.

**Quand l'utiliser** : en typo cinétique 1600 et en showreel, sur le mot-choc, le drop ou l'arrivée du logo. En promo SaaS, le flash local signale un événement d'interface : validation, alerte, limite atteinte. Sa couleur se fixe au système de design, ses places à la construction du plan. À éviter dans un explainer posé en voix off, à chaque coupe, et sur un fond déjà très clair.

**HyperFrames (GSAP)**

```js
// Flash couleur d'accent sur le mot-choc, puis négatif de 2 im sur l'attaque suivante
const FPS = 60, F = n => n / FPS;      // images → secondes
const BEAT = 60 / 120;                 // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT;
const HIT = at(20) - F(1);             // pic 1 im avant le temps 20 (attaque audible)
// #flash : calque plein cadre, fond = accent de la palette (#D8704F), au-dessus de la scène
tl.set("#flash", { autoAlpha: 0 }, 0)
  .set("#scene", { filter: "none" }, 0)
  .set("#word", { autoAlpha: 0, scale: 3 }, 0)
  // 1. Pic : 1 image pleine ; le mot-choc apparaît dessous, à ×3
  .set("#flash", { autoAlpha: 1 }, HIT)
  .set("#word", { autoAlpha: 1 }, HIT)
  // 2. Retombée power3.out en 10 im ; le mot se pose à ×1 en 8 im
  .to("#flash", { autoAlpha: 0, duration: F(10), ease: "power3.out" }, HIT + F(1))
  .to("#word", { scale: 1, duration: F(8), ease: "expo.out" }, HIT);

// Négatif franc de 2 im, sans retombée : la luminance s'inverse, la teinte reste
// (invert puis hue-rotate 180° : le corail reste corail, comme dans la gravure)
const NEG = at(24) - F(2);             // 2 im avant l'attaque du temps 24
tl.set("#scene", { filter: "invert(1) hue-rotate(180deg)" }, NEG)
  .set("#scene", { filter: "none" }, NEG + F(2));

// Variante « différence » : aplat rouge en mix-blend-mode: difference, 1 seule image
tl.set("#diff", { autoAlpha: 0 }, 0)
  .set("#diff", { autoAlpha: 1 }, at(28) - F(1))
  .set("#diff", { autoAlpha: 0 }, at(28));
```

**After Effects**

- Poser un marqueur sur chaque attaque forte (Layer › Markers › Add Marker (Calque › Marqueurs › Ajouter un marqueur)), puis placer chaque pic 1 im avant son marqueur.
- Flash d'accent : Layer › New › Solid (Calque › Nouveau › Solide) plein cadre, couleur d'accent. Opacity (Opacité) 100 % pendant 1 im, puis 100 → 0 % en 10 im ; dans le Speed Graph (éditeur de graphe de vitesse), influence 0 % au départ et 75 % à l'arrivée.
- Négatif : Layer › New › Adjustment Layer (Calque › Nouveau › Calque d'effets) long de 2 im, avec Effect › Channel › Invert (Effet › Couches › Inverser), Channel (Couche) RGB. Puis Effect › Color Correction › Hue/Saturation (Correction colorimétrique › Teinte/Saturation), Master Hue (Teinte globale) 180° : l'accent garde sa teinte.
- Différence : un Solid rouge d'1 im, Blending Mode (mode de fusion) Difference (Différence) dans la colonne Mode de la timeline.
- Flash local : Effect › Stylize › Glow (Effet › Esthétiques › Lueur) sur l'élément ; Glow Intensity (Intensité de la lueur) monte en 1 im, redescend en 20 im en clés linéaires.
