## L'impact : onde de choc annulaire et gerbe d'éclats (shockwave ring, ripple rings, radial burst, sparks, confetti)

Au point de contact, un anneau fin s'élargit en s'amincissant puis s'efface, souvent avec un ou deux autres en cascade et une gerbe de traits ou d'étincelles. Il dit où et quand le coup arrive sans cacher le sujet ; au mieux, son rayon suit 1 − e^(−t/τ), τ = 5,5 im à 30 fps. Le flash qui l'accompagne en transition est au chapitre 4 (« Le flash et la surexposition ») ; le silence qui le précède, au chapitre 9 (« Le temps fort : montée, silence d'un temps, impact sur la révélation »). Vue dans 70 vidéos, dont 64 notées 4 ou 5.

**Règles de construction**

1. Ease-out franc : la moitié de la course dans le premier tiers. Mesures : 1 − e^(−kt) (web3wesley, rms 0,6 %), power2.out (sudo-kiran, steventey), power1.out (roundtablespace), expo.out (grace-sunnyy). Exception : l'onde à vitesse constante qui sort du cadre en 13 im (lukasersil).
2. Coup fort : de 5-25 % H jusqu'au-delà du cadre en 10 à 22 im (0,17 à 0,37 s à 60 fps). Sur un objet : de 1,1× à 2-2,5× sa taille en 5 à 20 im (raphaelaubryy, melvynx). Trait de 0,3 à 1 % H qui s'amincit ; opacité qui tombe en sine.out sur 9 im (samaote). Pour un clic, « un petit cercle qui s'étend puis disparaît » (guide Otom, p. 11).
3. Calage, d'après les vidéos animées sur la musique : l'anneau naît sur l'image du temps, ou 1 à 2 im avant l'attaque audible. Mesures : 0 im (sudo-kiran), +0,5 im (roundtablespace), mi-course sur la grosse caisse (codestackr). Contre-exemple : le climax de prasad-pilla (musique posée), 4,5 im avant le demi-temps.
4. Cascade : 2 ou 3 anneaux décalés de 3 à 4 im (0xfemyn, shinskinakamoto), le second plus fin et plus lent (quickdesignio). Couleurs de la palette ou de l'objet touché : chaque barre du logo lâche un anneau de sa couleur (sudo-kiran-4f8b59).
5. Gerbe : 15 à 60 traits ou étincelles, de 5 à 35 % H, qui filent en ease-out et s'éteignent en 6 à 20 im. Les éclats ne freinent pas comme l'onde : deux vitesses (web3wesley). Chute sous gravité seulement si l'objet est détruit (kantamk, jazzen-chen).
6. Un à trois impacts par film, sur des coups qui comptent. [Motion designer portrait showreel](https://prompt-motion.com/ndhabarde11-f155b4) réserve l'anneau aux 3 rebonds de la balle ; [Supademo launch video](https://prompt-motion.com/jhylee95-e1152f) garde son éclat pour le drop. Le même anneau à chaque mot devient un tic (chrisjdimarco, maxalexweber) ; confettis et étoiles dorées de validation sont des clichés (abderrahmen-g, bthreeagency).

**Verdict** : à reprendre, avec parcimonie. L'anneau ponctue tes atterrissages et ta « compression puis explosion ». Les confettis sont un cliché : remplace-les par un seul anneau ou par des éclats tirés du sujet (gélules, sucre, glyphes).

**Quand l'utiliser** : en promo SaaS, pour un clic, une validation (cadenas, coche), l'arrivée d'un chiffre ou du logo. En typo cinétique 1600 et en showreel : drop, contact d'un objet qui tombe, accroche de la première seconde. Le style (épaisseur, couleurs, courbe) se fixe au système de design, la pose à la construction du plan. À éviter à chaque succès, mot ou coupe, et en explainer à voix off posée.

**HyperFrames (GSAP)**

```js
// Impact sur le temps 1 : 3 anneaux SVG en cascade (3 im) qui s'amincissent, gerbe de 36 traits
const FPS = 60, F = n => n / FPS;
const BEAT = 60 / 120, at = b => b * BEAT;  // 120 BPM : 1 temps = 30 im
const hit = at(1);  // contact pile sur le temps (étude sudo-kiran : 0 im)
const svg = document.querySelector("#impact");  // <svg viewBox="0 0 1920 1080"> plein cadre
const NS = "http://www.w3.org/2000/svg", H = 1080, cx = 960, cy = 540;
const add = (tag, a) => { const e = document.createElementNS(NS, tag);
  for (const k in a) e.setAttribute(k, a[k]); return svg.appendChild(e); };
let seed = 7; const rnd = () => (seed = (seed * 16807) % 2147483647) / 2147483647;  // seedé

// 1. Anneaux : rayon 6 → 110 % H en 22 im, trait 1,2 → 0,2 % H (attr, pas scale)
["#D9F24A", "#E5484D", "#4C7DFF"].forEach((c, i) => {
  const t = hit + F(3 * i);
  const ring = add("circle", { cx, cy, r: 0.06 * H, fill: "none", stroke: c, "stroke-width": 0.012 * H, opacity: 0 });
  tl.set(ring, { opacity: 1 }, t)
    .to(ring, { attr: { r: 1.1 * H, "stroke-width": 0.002 * H }, duration: F(22), ease: "power2.out" }, t)
    .to(ring, { opacity: 0, duration: F(9), ease: "sine.out" }, t + F(13));
});

// 2. Gerbe : la tête file en 6 im, la queue la rattrape en 14 im
for (let i = 0; i < 36; i++) {
  const a = (i / 36) * 2 * Math.PI + rnd() * 0.12, d = (0.2 + 0.15 * rnd()) * H;  // 20 à 35 % H
  const ex = cx + Math.cos(a) * d, ey = cy + Math.sin(a) * d;
  const s = add("line", { x1: cx, y1: cy, x2: cx, y2: cy, stroke: "#F4EDE4", "stroke-width": 3,
                          "stroke-linecap": "round", opacity: 0 });
  tl.set(s, { opacity: 1 }, hit + F(1))  // la gerbe part l'image après le contact
    .to(s, { attr: { x2: ex, y2: ey }, duration: F(6), ease: "power3.out" }, hit + F(1))
    .to(s, { attr: { x1: ex, y1: ey }, duration: F(14), ease: "power2.out" }, hit + F(3))
    .set(s, { opacity: 0 }, hit + F(17));
}
```

**After Effects**

- Composition Marker (marqueur de composition) sur l'attaque : touche * du pavé numérique ; LL affiche la Waveform (forme d'onde).
- Anneau : Layer › New › Shape Layer (Calque › Nouveau › Calque de forme), Add › Ellipse puis Add › Stroke (Ajouter › Contour), sans Fill (Fond). Animer Ellipse Path › Size (Taille, le diamètre) de 12 à 220 % H en 22 im et Stroke Width (Largeur du contour) de 13 à 2 px ; pas Scale (Échelle), qui épaissit le trait. Opacity (Opacité) 100 → 0 % sur les 9 dernières images.
- Courbe : dans le Speed Graph (éditeur de graphe de vitesse), première clé à influence 0 % et vitesse forte, dernière à 85 % (≈ power2.out). Cascade : dupliquer deux fois, recolorer, décaler de 3 im avec Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques).
- Gerbe : un trait du centre vers l'extérieur à la Pen Tool (outil Plume), Add › Trim Paths (Réduire les tracés) : End 0 → 100 % en 6 im, Start 0 → 100 % de +2 à +16 im. Puis Add › Repeater (Répéteur), Copies 36, Transform › Rotation 10°, point d'ancrage au centre.
- Natif : Effect › Generate › Radio Waves (Générer › Ondes radio) pour des ondes répétées ; Effect › Simulation › CC Particle World pour des étincelles qui retombent (Birth Rate élevé 2 im puis 0). Motion Blur (flou de mouvement) activé.
