## La palette fermée et l'accent qui a un sens (restricted palette, single accent color, semantic color coding)

Deux à cinq couleurs tenues de bout en bout, dont une seule teinte saturée par rôle : le produit, l'action, le mot clé, « toi ». Ou un code fixe : une couleur par étape, vert pour le gain, rouge pour le coût. L'œil apprend le code en deux plans, puis lit la couleur avant le texte. Chez daniel-haida, fond et surfaces couvrent ≈ 95 % de l'image ; l'or ne marque que 6 éléments. Vue dans 123 vidéos, dont 91 notées 4 ou 5.

**Règles de construction**

1. 3 à 5 couleurs : deux neutres de fond (noir chaud, crème ou papier) qui couvrent l'essentiel, puis 1 à 3 teintes à rôle (hbcoop 3, sahildesigner23 3, web3wesley 5). Une exception de moins d'une seconde passe (rendesr, tequilafunks).
2. Un rôle par couleur, tenu du premier au dernier plan et à toutes les échelles : 4 étapes chez theviableedge, 4 flux du câble à la puce chez sayan-shanky, rouge/vert pendant 5 min 37 chez henkvaness. Si le sens glisse d'une scène à l'autre, le code se brouille (ismailfahmi, à adapter).
3. L'accent reste rare : un mot accent par plan au plus (zheke), ≈ 5 à 10 % de la surface (kyonax-on-tech), 3 fois en 23 s (antonio-kodheli). Le guide le réserve « à ce qui compte : le chiffre, le mot clé, le bouton » (guide Otom, p. 6). Nos mesures nuancent le « un seul accent » : un seul par rôle (4 chez theviableedge, noté 5).
4. Vert et rouge sont des états, jamais des décors : gain, livré, succès contre coût, erreur, dépassement (daniel-haida, sudeepsd, henkvaness, marouanegazouzi). Si la marque est rouge, l'accent garde le rouge et les états prennent le vert seul (aschapmann).
5. Un changement de couleur est un événement calé : 1 à 2 im sur le temps (daniel-haida, 0 et −1 im), ou 3 im avant le geste pour guider l'œil (tankazunori0914). Les fondus restent courts entre teintes proches (iammxfschr : 5-6 im) ou passent par le blanc (daniel-haida : 12 + 16 im). Entre teintes éloignées, jamais de fondu RVB : même levabashidze, noté 5, traverse un violet #8A5CC0 en 7 im.
6. La marque fournit la palette (4 carrés du logo chez theviableedge, trio du logo chez sudo-kiran-b055de). Donne les codes hex exacts (guide Otom, p. 5), puis fais lister les couleurs réellement utilisées avant le rendu (guide Otom, p. 14).

**Verdict** : à reprendre. C'est la réponse directe au « même accent répété partout » que tu rejettes : l'accent n'apparaît que là où il veut dire quelque chose.

**Quand l'utiliser** : dans tous les styles ; c'est une décision de direction artistique, figée au système de design en jetons nommés par rôle, avant le premier plan. En promo SaaS : accent = produit et action, vert/rouge = données. En explainer de données : une couleur par série ou par flux. En typo 1600 : l'accent sur le point et un mot par plan (voir « Le mot accent : couleur, italique, deux tons »). À éviter : le monochrome strict quand la marque doit rester en mémoire (davidmarcus, à adapter), et les aplats saturés à 100 % sans neutre (henkpoley, cliché volontaire).

**HyperFrames (GSAP)**

```js
// Palette fermée à rôles fixes (120 BPM, 60 i/s) : un jeton = un sens, tout le film
const FPS = 60, BEAT = 60 / 120, F = n => n / FPS, at = b => b * BEAT;
const ROLE = {
  fond: "#0A0D18", surface: "#161B2D", texte: "#F3F1EA", lu: "#8E8E8E",
  marque: "#E8B84B",                    // rare : logo, courbe, élément actif
  gain: "#34D399", perte: "#F87171",    // états, jamais décoratifs
};
Object.entries(ROLE).forEach(([k, v]) => document.documentElement.style.setProperty(`--${k}`, v));

// 1. Changement d'état = événement : or → vert en 2 im, fini sur le temps 12
tl.set("#pill", { backgroundColor: ROLE.marque }, 0)
  .to("#pill", { backgroundColor: ROLE.gain, duration: F(2), ease: "none" }, at(12) - F(2));

// 2. Anticipation : la cible prend l'accent 3 im avant que le cadre y saute
tl.set("#target", { color: ROLE.marque }, at(16) - F(3))
  .to("#frame", { x: 320, duration: F(8), ease: "power3.out" }, at(16));

// 3. Hiérarchie par la valeur : les lignes lues passent au gris 1 im avant la nouvelle
tl.set("#line-new", { autoAlpha: 0 }, 0)
  .to(".line.read", { color: ROLE.lu, duration: F(3), ease: "power1.out" }, at(20) - F(1))
  .set("#line-new", { autoAlpha: 1 }, at(20))
  .fromTo("#line-new", { yPercent: 100 }, { yPercent: 0, duration: F(10), ease: "power3.out", immediateRender: false }, at(20));

// 4. Rouge → bleu sans boue : interpoler en OKLCH (valeurs approchées), par le magenta
const shape = document.querySelector("#shape");
const k = { l: 0.6, c: 0.22, h: 27 };                       // ≈ #EB2A2A
tl.to(k, { l: 0.48, c: 0.26, h: -93, duration: F(7), ease: "power2.inOut",   // -93° = 267°
  onUpdate: () => { shape.style.backgroundColor = `oklch(${k.l} ${k.c} ${((k.h % 360) + 360) % 360})`; },
}, at(24));
```

**After Effects**

- Un calque PALETTE : Layer › New › Null Object (Calque › Nouveau › Objet nul), avec un Effect › Expression Controls › Color Control (Options pour expressions › Paramètre couleur) par rôle : fond, texte, marque, gain, perte.
- Chaque couleur du film passe par Effect › Generate › Fill (Effet › Générer › Remplir), Color reliée au rôle : `thisComp.layer("PALETTE").effect("marque")("Color")`. Changer de marque change tout le film ; une couleur sans lien est une erreur.
- Bascule d'état : 2 clés de Color à 2 im d'écart, la seconde sur le marqueur du temps ; pour une coupe nette, Animation › Toggle Hold Keyframe (Activer/désactiver l'image clé maintenue). Anticipation : la clé de couleur de la cible 3 im avant la clé de Position du cadre.
- Lignes lues : Fill de #111111 à #8E8E8E en 3 im, 1 im avant l'entrée de la nouvelle ligne.
- After Effects interpole les couleurs en RVB. Entre rouge et bleu, garde la couleur et anime Effect › Color Correction › Hue/Saturation (Correction colorimétrique › Teinte/Saturation) › Master Hue (Teinte globale) de 0 à −120° en 7 im : la teinte passe par le magenta sans perdre sa saturation.
