## Le script couleur : étalonnage, désaturation et lumière qui racontent (color script, narrative grade shift, semantic desaturation, motivated light)

La teinte, la saturation ou la lumière de toute la scène changent avec le récit : nuit vers jour, froid quand le héros est seul, gris quand l'abondance devient menace. La couleur dit l'état ou l'avant/après sans un mot. Dans la meilleure occurrence, la saturation tombe de 0,58 à 0,15 en 26 images sur le premier temps d'une mesure, et ne revient jamais. Vue dans 31 vidéos, dont 28 notées 4 ou 5.

**Règles de construction**

1. Une couleur = un état, tenu tout le chapitre. La bascule tombe sur un premier temps de mesure (samaote, ±2 im). On rompt le système le temps d'un chapitre, puis on revient (kloss-xyz : ambre pour ELIZA, bleu nuit pour les hivers de l'IA). On peut réserver une teinte au final (ajith-io : triade gardée pour le logo).
2. Désaturer dit perte, menace ou inertie. Même objet, même place : seule la couleur part. Saturation divisée par 4 (samaote), luminosité −40 % (sudo-kiran), gris #6B7280 à #8A8F9C (cansincengiz-me, sudo-kiran). C'est l'« état AVANT (couleurs atténuées, gris) » face à l'« état APRÈS (couleurs de la charte) » (guide Otom, p. 12).
3. La durée de la bascule porte le sens. 1 im : rupture (devius-maximus). 8 à 15 im : tournant (gabrielbuzziv, anas0ra). 22 à 26 im, une croche : arrêt du temps (samaote). 1,7 s qui accélère sur les 12 dernières images : plongée au noir pendant le break (leonkohli). 8 s et plus sans coupe : le temps passe (faroukzy, x4b47x).
4. Chaud = présence, foyer, produit ; froid = solitude, nuit, menace (anilraok, kamstudiolabs, faroukzy : faisceau #FFF2D6 devenu #FFC45C). Flaques chaudes de 20 à 30 % de la largeur sur un sol bleu nuit (mandelduck) ; halos de 8 à 25 % du cadre.
5. La lumière a une source visible : lampe, lanterne, fenêtre ou personnage. Interrupteur en 1 im avec halo (itsolelehmann), optique en 12 im ease-out (kamstudiolabs), fenêtres à 21 im d'écart (x4b47x). Le porteur sort : la pièce tombe au noir en 18 im.
6. Contre-exemples : saut orange → mauve en 1 im sans motif, lu comme une faute de raccord (axtonliu) ; retour au jour sans indice (anas0ra) ; scintillement sans son, lu comme un bug (x4b47x). À chaque plan, la bascule se confond avec la rotation de fonds (« Les fonds pleins qui changent sur le temps », même chapitre).

**Verdict** : à reprendre. C'est l'avant/après le plus économe : le problème en gris, la solution aux couleurs de la marque. Une bascule par chapitre au plus, motivée par une source ou le texte.

**Quand l'utiliser** : en promo SaaS et en cas client (problème désaturé, solution en couleur), en court métrage à personnages (jour/nuit, chaud/froid), en explainer de données (menace) et en typo 1600 (une couleur par chapitre). Elle se décide à la direction artistique, en écrivant le script couleur chapitre par chapitre, puis se cale au découpage. À éviter quand la palette tourne déjà sur chaque temps, ou sans motif narratif à porter.

**HyperFrames (GSAP)**

```js
// Script couleur : le problème se désature au 1er temps de la mesure 5, la lampe rend la couleur à la mesure 7
const FPS = 60, F = n => n / FPS;            // images → secondes
const BEAT = 60 / 120;                       // 120 BPM, mesures de 4 temps
const at = b => b * BEAT;
const BAR = m => at((m - 1) * 4);            // 1er temps de la mesure m
// #scene porte tout le décor ; #flash : calque crème plein cadre ; #glow : halo radial de la lampe
tl.set("#scene", { filter: "saturate(1) brightness(1)" }, 0)
  .set("#flash", { autoAlpha: 0 }, 0)
  .set("#glow", { autoAlpha: 0, scale: 0.6 }, 0);
// 1. Le temps s'arrête : flash d'1 im juste avant le temps, puis la couleur se vide en 24 im
tl.set("#flash", { autoAlpha: 1 }, BAR(5) - F(1))
  .set("#flash", { autoAlpha: 0 }, BAR(5))
  .to("#scene", { filter: "saturate(0.25) brightness(0.6)", duration: F(24), ease: "power1.out" }, BAR(5))
  .to(".caption", { color: "#8A8F9C", duration: F(24), ease: "power1.out" }, BAR(5));
// 2. Deux mesures tenues en gris. 3. La lampe s'allume comme un interrupteur (1 im), son halo s'ouvre en 12 im
tl.set("#lamp", { backgroundColor: "#F3E0D1" }, BAR(7))
  .set("#glow", { autoAlpha: 1 }, BAR(7))
  .to("#glow", { scale: 1, duration: F(12), ease: "power2.out" }, BAR(7))
  .to("#scene", { filter: "saturate(1) brightness(1)", duration: F(12), ease: "power2.out" }, BAR(7))
  .to(".caption", { color: "#FFFFFF", duration: F(12), ease: "power2.out" }, BAR(7));
// 4. Allumage étagé : .floor listés du bas vers le haut, un étage toutes les 6 im
tl.to(".floor", { color: "#F4DDA8", filter: "brightness(1.6)", duration: F(6),
                  ease: "none", stagger: F(6) }, BAR(8));
```

**After Effects**

- Layer › New › Adjustment Layer (Calque › Nouveau › Calque d'effets) « script couleur » au-dessus de la scène. Effect › Color Correction › Hue/Saturation (Correction colorimétrique › Teinte/Saturation) : Master Saturation (Saturation globale) 0 → −75 en 24 im, depuis le marqueur du temps.
- Sur le même calque, Effect › Color Correction › Exposure (Exposition) 0 → −0,75 (environ −40 % de luminosité). Speed Graph (éditeur de graphe de vitesse) : influence 0 % au départ, 70 % à l'arrivée (≈ power1.out).
- Chaud ou froid : Effect › Color Correction › Tint (Teinte), Map Black To (Mapper le noir sur) #0C1220 et Map White To (Mapper le blanc sur) #BCD3FF pour la nuit ; Amount to Tint (Quantité) 0 → 60 % sur la bascule.
- Lampe : Shape Layer (calque de forme) Ellipse crème, Effect › Blur & Sharpen › Gaussian Blur (Flou et netteté › Flou gaussien) pour le halo, mode Add (Addition). Opacity (Opacité) en Hold Keyframes (images clés maintenues) : l'allumage tient en 1 im.
- Allumage étagé : un calque par étage, décalés de 6 im (Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques), avec Overlap (Chevauchement)). Panne : Hold Keyframes irrégulières, 3 à 6 im.
