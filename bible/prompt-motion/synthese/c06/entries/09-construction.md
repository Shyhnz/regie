## La construction pièce par pièce : logo et pictogrammes assemblés (logo build, piece-by-piece assembly, converging fragments, logo sting)

Le logo se monte avec 3 à 6 morceaux qui tombent, convergent des bords, sortent d'un point ou se recomposent après un éclatement, puis se verrouillent sur le temps. Le spectateur voit la marque se faire : il la retient mieux qu'un logo posé. Dans les vidéos notées 4 et 5, l'assemblage dure 0,2 à 0,9 s. Au-delà, ou avec trop de pièces, le logo arrive tard et brouillé. Vue dans 36 vidéos, dont 31 notées 4 ou 5.

**Règles de construction**

1. 3 à 6 pièces lisibles, de 5 % H au moins (3 chez safarkhanshuvo et bizibeast, 4 chez xelandre, 6 chez 0xfemyn). Au-delà, elles voyagent en nuage avec un seul minutage (quickdesignio, 26 im).
2. Une pièce part toutes les 3 à 6 im à 60 fps (0,05 à 0,1 s) : ajith-io-c52e09 3 im, sudo-kiran-6609ed 5 im, theviableedge 5-6 im. Ordre fixe : de bas en haut (imthatcarlos) ou dans le sens de lecture.
3. Trajectoire courbe, arrivée en ease-out sans rebond. On découple x et y : la montée part 7 im avant le virage (theviableedge). Une rotation de 15 à 45° se résorbe à l'arrivée (sudo-kiran, bizibeast, 0xfemyn). Dépassement nul ou ≤ 1,3 % (lexnlin, pankajkumar).
4. Calage, tiré des vidéos animées sur la musique : le verrouillage tombe sur le temps (sudo-kiran f122 à 30 fps, bizibeast f2192, jesscaroline7 f90, safarkhanshuvo f844). Le désordre peut partir au demi-temps : [Poster breaking its frame](https://prompt-motion.com/pankajkumar-dev-0bee87) éclate f1252 et se recompose sur le temps 44.
5. Un seul accent au verrouillage : onde (sudo-kiran, bizibeast), flash de 8 im (jesscaroline7) ou halo qui décroît en 10 im (imthatcarlos). Le nom suit, par un volet de masque de 12 im (ajith-io-c52e09) ou depuis le bord du symbole (chapitre 3, « La signature : lockup du logo et point relais »).
6. Durée totale 0,25 à 0,9 s (manuelogomigo 15 im, safarkhanshuvo 51 im), puis un lockup tenu, pas 0,63 s comme [Alan agent platform promo](https://prompt-motion.com/prasad-pilla-2c0cba). Le guide propose 5 s, dont 2 s de tracé (guide Otom, p. 12) : la Bible garde le court.

**Verdict** : à reprendre. Cousine de ta « feuille qui devient logo » : les pièces viennent de la scène (repères, pixels) et arrivent en courbe. Une seule construction par film : [Crux motion design showreel](https://prompt-motion.com/marouanegazouzi-6071d5) en monte une au début, et la carte de fin perd son effet.

**Quand l'utiliser** : en promo SaaS et en showreel, pour l'accroche ou la signature (chapitre 10, « La signature finale : logo, slogan, appel, sans temps mort »). On découpe le logo en 3 à 6 pièces dès le système de design, puis on cale le verrouillage sur un 1er temps au découpage. À éviter pour un logo fin ou détaillé. Avec un simple PNG, révéler par un masque plutôt que par le tracé (guide Otom, p. 12), comme le pop sur le temps de [Quetzal social app reel](https://prompt-motion.com/miskinho-443898).

**HyperFrames (GSAP)**

```js
// Trois pièces convergent en arc, se verrouillent sur le temps, puis onde et nom
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128, at = b => b * BEAT;         // 128 BPM
const LOCK = at(30);                                // la dernière pièce se pose sur le temps 30
const FLIGHT = f(40), GAP = f(5);                   // vol de 40 im, une pièce toutes les 5 im
// Départs hors champ (px, relatifs à la place finale) et rotation
const pieces = [
  { el: "#piece-square", x: 900, y: -520, r: 45 },
  { el: "#piece-dot", x: -820, y: -420, r: 0 },
  { el: "#piece-tri", x: 300, y: 640, r: -40 },
];
tl.set(".piece", { autoAlpha: 0 }, 0)
  .set("#wordmark", { clipPath: "inset(0 100% 0 0)" }, 0)
  .set("#shock", { autoAlpha: 0, scale: 0.2 }, 0);
pieces.forEach((p, i) => {
  const t0 = LOCK - FLIGHT - (pieces.length - 1 - i) * GAP;  // arrivées en cascade
  tl.set(p.el, { x: p.x, y: p.y, rotation: p.r, autoAlpha: 1 }, t0)
    .to(p.el, { x: 0, duration: FLIGHT, ease: "power2.out" }, t0)
    // y part 7 im plus tard avec une courbe plus raide : la trajectoire devient un arc
    .to(p.el, { y: 0, duration: FLIGHT - f(7), ease: "power4.out" }, t0 + f(7))
    .to(p.el, { rotation: 0, duration: FLIGHT, ease: "power3.out" }, t0);
});
// Un seul accent au verrouillage : une onde fine qui s'éteint en 18 im
tl.set("#shock", { autoAlpha: 0.8 }, LOCK)
  .to("#shock", { scale: 1.2, autoAlpha: 0, duration: f(18), ease: "power2.out" }, LOCK)
  // Le nom sort d'un masque collé au logo, sur le demi-temps suivant, en 12 im
  .to("#wordmark", { clipPath: "inset(0 0% 0 0)", duration: f(12), ease: "power3.out" }, LOCK + BEAT / 2);
```

**After Effects**

- Un Shape Layer (calque de forme) par pièce, Anchor Point (point d'ancrage) au centre. Clés d'arrivée sur un Composition Marker (marqueur de composition) posé sur le temps, clés de départ hors champ 40 im avant.
- Clic droit sur Position › Separate Dimensions (Séparer les dimensions). Décaler la 1re clé de Y Position de 7 im. Dans le Speed Graph (éditeur de graphe de vitesse), influence d'arrivée 85 % pour X et 95 % pour Y : l'arc apparaît. Rotation 45 → 0° sur la même durée.
- Décaler les pièces de 5 im (Option + Page Down déplace le calque d'une image). Activer le Motion Blur (flou de mouvement).
- Accent : une Ellipse en contour fin, Scale (Échelle) 20 → 120 % et Opacity (Opacité) 80 → 0 % en 18 im ; ou un Solid (solide) blanc, Opacity 100 → 0 % en 8 im.
- Nom : Effect › Transition › Linear Wipe (Effet › Transition › Balayage linéaire), Transition Completion 100 → 0 % en 12 im, Feather (Contour progressif) 0, au demi-temps suivant.
