## La poussée vers le sujet : lente, calibrée ou en punch sur le temps (push-in, punch-in, camera creep, beat zoom bump, calibrated reframe)

Le cadre grossit vers un sujet sans le traverser. Trois régimes : la dérive lente (+3 à +15 % en 2 à 3,5 s) qui garde un maintien vivant, la poussée calibrée (×1,35 à ×2,3 en 0,3 à 0,9 s) qui cadre le bouton ou le mot clé, et le punch (+10 à +30 % en 2 im) qui frappe un temps fort. Elle guide l'œil sans couper ; sans cible, elle n'est que du bruit. Vue dans 50 vidéos, dont 36 notées 4 ou 5.

**Règles de construction**

1. Amplitude selon la fonction. Dérive : +3 à +15 % en 2 à 3,5 s (Quetzal social app reel : +7 % en 95 im, +10 % en 80 im). Poussée calibrée : ×1,35 à ×2,3 en 0,3 à 0,9 s. Punch : +10 à +30 % en 2 im, retour en 3 à 4 im. Le guide Otom donne une entrée produit par zoom arrière 108 → 100 % en 2 s (guide Otom, p. 9) : même amplitude qu'une dérive, sens inverse.
2. Courbes. La poussée calibrée est en ease-in-out (power2 ou power3.inOut) : 7, 31, 66, 90 % du trajet aux images 4, 8, 11, 14 ([Design portfolio video reel](https://prompt-motion.com/kikelopezdesign-7cc9e8)). La dérive est linéaire ou décélère jusqu'à l'arrêt. Le punch monte en ease-out et revient vite.
3. Le cadre final contient la cible entière, avec au moins 6 % de marge (guide Otom, p. 7). Trois showreels coupent « FRAME » en « FR » pendant 0,3 à 0,45 s ; FundMyCompute laisse un « s » géant au coin 22 im. Seul le décor peut être coupé.
4. Calage (vidéos animées sur la musique) : la poussée se pose 0 à 2 im avant le temps (UGC ad generator promo, Stock analysis app promo) ; le punch part sur le temps à 0-1 im (Poster breaking its frame : +30 % en 2 im, écart 0 im).
5. Flou de mouvement obligatoire au-delà de ×1,5 en moins de 10 im. Sans flou, ×2,2 en 8 im se lit comme une coupe (Supasito launch video, musique posée). À partir de 18 im, une poussée sans flou reste fluide (FundMyCompute, Tally).
6. Une poussée par scène, vers une cible nommée. Le punch reste local : 4 coups en 1,5 s sur une seule section (monokern). Pour une dérive continue, chaque scène repart du zoom de la précédente (Ora 2 image model launch film : 1,0 → 1,04 par scène, aucun saut aux raccords).

**Verdict** : à reprendre. La poussée calibrée est ton « zoom qui cadre le mot clé seul », à condition de calculer le cadre final ; le punch reste un accent rare, pas une ponctuation à chaque mesure.

**Quand l'utiliser** : en promo SaaS / interface pour désigner un bouton, un champ ou une valeur (démonstration, appel à l'action) ; en typo cinétique 1600, punch sur un temps fort et poussée calibrée sur le mot clé ; en explainer, poussée ancrée quand la voix nomme le détail. La dérive se décide au système de design (une règle de caméra pour toute la vidéo) ; poussées et punchs se placent à la construction du plan. À éviter sans cible, quand le plan suivant doit naître de l'objet (préférer la plongée traversante, famille 01) ou quand la mise en page ne laisse pas de marge.

**HyperFrames (GSAP)**

```js
// Dérive pendant le maintien, poussée calibrée sur #cta (posée 2 im avant le temps 8),
// puis punch sur le temps 10. #punch (origine 50 % 50 %) contient #cam (origine 0 0) et la scène.
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 120, at = b => b * BEAT;           // 120 BPM : 1 temps = 30 im
const W = 1920, H = 1080, FILL = 0.45, MAX = 2.3;    // la cible finit à 45 % de la largeur
await document.fonts.ready;                           // mesurer après les polices (scène visible)
const r = document.querySelector("#cta").getBoundingClientRect();   // mesuré à l'échelle 1
const s = Math.min(MAX, (W * FILL) / r.width);
const clamp = (v, lo) => Math.min(0, Math.max(lo, v));             // ne jamais montrer le bord de la scène
const x = clamp(W / 2 - (r.x + r.width / 2) * s, W - W * s);
const y = clamp(H / 2 - (r.y + r.height / 2) * s, H - H * s);
const LAND = at(8) - f(2), PUSH = f(26);
tl.set("#cam", { transformOrigin: "0 0", x: 0, y: 0, scale: 1 }, 0)
  .set("#punch", { transformOrigin: "50% 50%", scale: 1, filter: "blur(0px)" }, 0)
  // 1. dérive : +4 % autour du centre, linéaire
  .to("#cam", { scale: 1.04, x: -W * 0.02, y: -H * 0.02, ease: "none",
                duration: LAND - PUSH - at(2) }, at(2))
  // 2. poussée calibrée : power3.inOut, flou au pic de vitesse
  .to("#cam", { scale: s, x, y, duration: PUSH, ease: "power3.inOut" }, LAND - PUSH)
  .to("#punch", { filter: "blur(4px)", duration: PUSH / 2, ease: "power2.in",
                  yoyo: true, repeat: 1 }, LAND - PUSH)
  // 3. punch sur le temps 10 : +15 % en 2 im, retour en 4 im
  .to("#punch", { scale: 1.15, filter: "blur(6px)", duration: f(2), ease: "power2.out" }, at(10))
  .to("#punch", { scale: 1, filter: "blur(0px)", duration: f(4), ease: "power3.out" }, at(10) + f(2));
// Pas de will-change: transform sur le texte zoomé : il serait pixelisé.
```

**After Effects**

- Layer › Pre-compose (Calque › Précomposer) toute la scène. Avec le Pan Behind Tool (outil Déplacer l'arrière-plan, touche Y), placer l'Anchor Point (Point d'ancrage) de la précomposition sur la cible : l'échelle grossit autour d'elle.
- Dérive : Scale (Échelle) 100 → 104 % entre le début et la fin du maintien, images clés linéaires.
- Poussée : Scale 104 → 230 % en 26 im, finie 2 im avant le marqueur du temps (marqueurs posés avec la touche * du pavé numérique sur le calque audio). Easy Ease (Lissage de vitesse, F9), puis Graph Editor (Éditeur de graphique) › Speed Graph (graphe de vitesse), influence 75 % aux deux clés. Activer Motion Blur (Flou de mouvement) sur le calque et dans la composition.
- Punch : un Adjustment Layer (calque d'effets) avec Effect › Distort › Transform (Effet › Déformation › Transformation), Scale 100 → 115 % en 2 im puis retour en 4 im ; décocher Use Composition's Shutter Angle et régler Shutter Angle à 180°.
- Contrôle : activer Title/Action Safe (zones de sécurité du titre et de l'action) et vérifier sur l'image d'arrivée que le mot clé est entier, avec au moins 6 % de marge.
