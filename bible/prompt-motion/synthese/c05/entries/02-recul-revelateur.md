## Le recul révélateur (pull-back reveal, zoom-out, Powers of Ten, content-to-context)

La caméra recule : le plan plein cadre rétrécit et se révèle comme une partie d'un ensemble plus grand (fenêtre d'un logiciel, écran d'un appareil, case d'une grille, point dans un monde). Il change le sens de ce qu'on vient de voir : « ce n'était qu'une case parmi cent ». Dans les vidéos notées 5, le recul dure 6 à 46 images à 60 fps et part ou arrive sur un temps. Vue dans 42 vidéos, dont 38 notées 4 ou 5.

**Règles de construction**

1. Deux courbes selon la fin. Le recul qui révèle freine : sine.out en 29 im (3D motion design showreel), power3.out en 46 im (Synced lyrics), ease-out en 24 à 27 im (AgentHud, [Photo print app launch film](https://prompt-motion.com/twoclipping-221cab)). Le recul qui fait disparaître accélère : expo.in en 6 im à 30 fps (Claude motion design reel). Le long trajet de contexte en contexte : ease-in-out, 45 à 60 im.
2. Interpoler le log de l'échelle. En échelle linéaire, ×0,1 en 36 im donne 0,5 s de démarrage mou puis ×4 en 0,3 s ([Design portfolio video reel](https://prompt-motion.com/kikelopezdesign-7cc9e8)). Une taille divisée par 2 toutes les 10 à 12 im donne une vitesse perçue constante ([Sahi trading terminal reveal](https://prompt-motion.com/dale-vaz-cc612a)).
3. Taille d'arrivée : un appareil ou une fenêtre occupe 55 à 62 % de la largeur ; une case de grille 17 à 36 %. Une inclinaison de −3 à −15° donne la profondeur ([Poster breaking its frame](https://prompt-motion.com/pankajkumar-dev-0bee87) −3°, DistilBook −10°, [GenVizu product launch](https://prompt-motion.com/listudio-820c7b) −15°).
4. Calage, tiré des vidéos animées sur la musique : départ sur le temps (+0 im 3D showreel, −0,4 im Synced lyrics), durée d'un temps (25 im à 144 BPM, [Distilbook motion showreel](https://prompt-motion.com/itisrazak-3ad902)) ou de 2 croches (Synced lyrics) ; l'arrivée ou le mot qui nomme l'ensemble tombe sur le temps suivant. Contre-exemple : [Trezio app motion reel](https://prompt-motion.com/agonaliu-466a8f), ×0,6 mou en 40 im, pic hors grille.
5. Le contexte se construit pendant le recul : l'interface arrive en fondu de la 6e à la 17e image (3D motion design showreel), les cartes entrent par les bords à 1 im d'écart ([Claude self-promo spot](https://prompt-motion.com/slvdev-64c45a)). Ensuite le contenu vit dans sa case et la caméra dérive (environ 2° en 40 im).
6. Sans révélation, ce n'est qu'un dézoom : le 108 → 100 % en 2 s avec fondu (guide Otom, p. 9) est une entrée douce, pas cette famille. Le recul final peut rimer avec l'ouverture : même cadrage exact (Design portfolio) ou sortie de la pupille du début ([Psychedelic hypnotic eye showreel](https://prompt-motion.com/monokern-ade5b6)).

**Verdict** : à reprendre. C'est le miroir de la plongée traversante et la meilleure image de récapitulatif avant le logo. Le recul jusqu'au point prolonge ton « texte qui rétrécit en point puis révélation circulaire ».

**Quand l'utiliser** : en promo SaaS / interface (l'écran dans l'appareil, l'appareil dans un mur de clients), en showreel (récapitulatif avant le logo) et en explainer de données (changer d'échelle, une case parmi cent). Fonctions : preuve, récapitulatif, chute, transition par le point. On le prévoit au découpage, avec l'ouverture pour la rime, et on le cale aux enchaînements. À éviter sans révélation à l'arrivée et pour animer une tenue : c'est le rôle de la poussée lente.

**HyperFrames (GSAP)**

```js
// Recul vers la fenêtre d'un logiciel (3D showreel, étude 60 fps) : sine.out 29 im
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128, at = b => b * BEAT;         // 128 BPM : 1 temps = 28,125 im
const GO = at(24);                                  // 1er temps de la mesure 7
// #context = le logiciel ; #preview = sa fenêtre, qui contient le plan A.
// Mesurer après document.fonts.ready, #context affiché à l'échelle 1.
const c = document.querySelector("#context").getBoundingClientRect();
const p = document.querySelector("#preview").getBoundingClientRect();
const S0 = c.width / p.width;                       // échelle où l'aperçu remplit le cadre
const ox = p.x + p.width / 2 - c.x, oy = p.y + p.height / 2 - c.y;
const cam = { z: Math.log(S0) };                    // on anime ln(échelle) : vitesse perçue juste
const apply = () => { const s = Math.exp(cam.z), k = (s - 1) / (S0 - 1);
  gsap.set("#context", { transformOrigin: `${ox}px ${oy}px`, scale: s,
    x: (c.width / 2 - ox) * k, y: (c.height / 2 - oy) * k }); };
apply();                                            // état de départ : plein cadre
tl.set("#chrome", { autoAlpha: 0 }, 0)
  .to(cam, { z: 0, duration: f(29), ease: "sine.out", onUpdate: apply }, GO)
  .to("#chrome", { autoAlpha: 1, duration: f(11), ease: "power1.out" }, GO + f(6))  // calques, timeline
  .to("#drift", { scale: 0.97, duration: at(4), ease: "none" }, GO + f(29));       // dérive lente

// Recul jusqu'au point (Claude motion design reel) : 0,2 s, expo.in, point sur le temps
tl.to("#arena", { scale: 0.01, rotation: 45, duration: 0.2, ease: "expo.in" }, at(16) - 0.2)
  .set("#arena", { autoAlpha: 0 }, at(16))
  .set("#particles", { autoAlpha: 1, scale: 0.08 }, at(16))
  .to("#particles", { scale: 1, duration: at(3), ease: "power2.out" }, at(16));  // ≈ 3 temps
```

**After Effects**

- Construire le contexte (logiciel, appareil, grille) en 1920 × 1080, le plan A précomposé dans sa fenêtre : Layer › Pre-compose (Calque › Précomposer). Commutateur Collapse Transformations / Continuously Rasterize (Réduire les transformations / Rastériser en continu) : texte net à 165 %.
- Layer › New › Null Object (Calque › Nouveau › Objet nul) posé au centre de la fenêtre, parent du contexte (colonne Parent & Link (Parent)). Scale (Échelle) du nul : expression `t = linear(time, t0, t0 + 29/60, 0, 1); e = Math.sin(t*Math.PI/2); s = 100*Math.pow(1.65, 1 - e); [s, s]` (sine.out sur le log).
- Position du nul : du centre de l'écran à sa place, mêmes 29 im ; Speed Graph (éditeur de graphe de vitesse), 1re clé Linear (Linéaire), 2e clé influence entrante 70 %.
- Interface autour : Opacity (Opacité) 0 → 100 % des images 6 à 17 du recul ; puis Scale 100 → 97 % en Linear sur 4 temps (dérive).
- Recul jusqu'au point : Scale 100 → 1 % et Rotation 0 → 45° en 0,2 s ; Animation › Keyframe Assistant › Exponential Scale (Assistant d'image clé › Échelle exponentielle), Motion Blur (flou de mouvement) actif.
