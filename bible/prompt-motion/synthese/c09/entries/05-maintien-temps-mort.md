## Le maintien : temps de lecture ou temps mort (reading hold, living hold, dead hold, static end card)

Le maintien est le moment où l'image s'arrête après une entrée. Les meilleures vidéos le limitent à un temps ou moins (0,4 à 0,8 s), le gardent vivant (poussée lente, pulsation sur le temps) et ne coupent jamais sur une image immobile. Au-delà d'environ 1 s sans geste, c'est du temps mort : 22 des 81 cas relevés sont jugés clichés, et le carton final figé de [Gene Spectra promo](https://prompt-motion.com/madebyjmayala-b9204d) occupe 28 % du film. Vue dans 80 vidéos, dont 55 notées 4 ou 5 ; les modèles viennent des 33 vidéos animées sur la musique.

**Règles de construction**

1. Un maintien dure un temps au plus : 0,4 à 0,8 s, soit 24 à 48 im à 60 fps. Le temps de lecture se calcule par mot, environ 1 s pour 4 mots (guide Otom, p. 6) : « X = ? » tenu 1,3 s pour 3 mots est trop long ([SuperX feature release teaser](https://prompt-motion.com/robj3d3-b18fad), contre-exemple).
2. Un gel est une note de silence, comptée en temps et placée : ½ temps de vide avant un drop, 22 à 24 im pour lire une chute (zheke, noté 5) ; 22 à 24 im d'image fixe avant chaque geste calé ([Product intro synced to music](https://prompt-motion.com/bogdandragomir-35e024), étude 60 fps).
3. Au-delà d'un temps, l'image reste vivante : poussée de 2 à 3 % sur la durée du maintien, ou un détail qui pulse sur chaque temps. Une dérive de 1 % par seconde ne suffit pas (lexnlin-6161a6) ; chez zheke, « I'M OPUS 5.5 » tient 40 im avec une poussée lente et une micro-secousse sur le temps.
4. Ne jamais couper sur une image immobile : le plan sortant accélère (power2.in à power4.in) jusqu'à l'image de coupe, le plan entrant arrive déjà lancé en ease-out (notdwd-7de38a, zheke).
5. Le carton final tient une mesure au plus et reste animé : 46 im pour la signature de [Dub promo video](https://prompt-motion.com/steventey-0d20e4), 30 im pour [Claude motion design reel](https://prompt-motion.com/tequilafunks-97f6c9). Au-delà de 2 s figées, c'est du temps mort : 2,45 s chez [Shin Majin-shiki promo](https://prompt-motion.com/majin-appsheet-2d3c1a), 6,5 s sans action nouvelle (28 %) chez [Prompt Motion site promo](https://prompt-motion.com/antonio-kodheli-490109).
6. Le guide Otom demande un texte immobile au moins 1,5 s (p. 7) et un écran final d'au moins 2,5 s (p. 14). Nos mesures en font du temps mort : la musique pilote la durée, jamais une durée forfaitaire.

**Verdict** : à adapter. Le maintien court et vivant est à reprendre ; le maintien long et figé est le défaut le plus fréquent des vidéos générées. Remplace-le par une poussée de 3 %, une pulsation sur le temps ou un compteur qui roule, ton effet préféré pour occuper une lecture.

**Quand l'utiliser** : dans tous les styles, à chaque fin d'entrée ; c'est surtout un contrôle. On le décide au découpage (durée de chaque plan en temps, temps de lecture par mot) et on le vérifie au contrôle qualité : aucun trou de plus d'un temps, aucune coupe sur image fixe. Les plans longs et calmes ne se justifient que dans un court-métrage contemplatif ou un tutoriel en voix off, jamais dans une promo de 15 s.

**HyperFrames (GSAP)**

```js
// Maintien vivant d'un temps, sortie qui accélère jusqu'à la coupe (128 BPM, 60 im/s)
const FPS = 60, BEAT = 60 / 128;                     // 1 temps = 28,125 im
const at = b => Math.round(b * BEAT * FPS) / FPS;    // calé sur une image entière
const IN = 12 / FPS;                                 // entrée de 12 im

// Entrée du chiffre sur le temps 12
tl.set("#stat", { autoAlpha: 1, scale: 1.15, y: 40 }, at(12))
  .to("#stat", { scale: 1, y: 0, duration: IN, ease: "power3.out" }, at(12))
  // Maintien de lecture : poussée linéaire de 3 %, jamais de gel complet
  .to("#stat", { scale: 1.03, duration: at(13.5) - at(12) - IN, ease: "none" }, at(12) + IN)
  // Le soulignement pulse sur le temps 13, au milieu du maintien
  .to("#underline", { scaleX: 1.06, duration: 4 / FPS, ease: "power2.out",
                      yoyo: true, repeat: 1 }, at(13))
  // Sortie : accélère jusqu'à l'image de coupe (temps 14), +19 % et flou
  .to("#stat", { scale: 1.22, filter: "blur(6px)", duration: at(14) - at(13.5),
                 ease: "power3.in" }, at(13.5))
  .set("#scene-a", { autoAlpha: 0 }, at(14))
  .set("#scene-b", { autoAlpha: 1 }, at(14));

// Carton final : une mesure (temps 28 à 32), le logo respire sur chaque temps
for (let b = 28; b < 32; b++) {
  tl.to("#logo", { scale: 1.02, duration: 6 / FPS, ease: "sine.out",
                   yoyo: true, repeat: 1 }, at(b));
}
```

**After Effects**

- Mesurer chaque maintien : écart entre la dernière image clé d'entrée et la première image clé de sortie. Au-delà de 28 im (un temps à 128 BPM et 60 fps), raccourcir ou animer.
- Maintien vivant : Scale (Échelle) de 100 à 103 % sur toute la durée, clic droit sur les images clés › Keyframe Interpolation (Interpolation d'image clé) › Linear (Linéaire).
- Pulsation sur le temps, sans images clés : expression sur Scale (Alt-clic sur le chronomètre) : `b = 60/128; p = (time % b)/b; s = 100 + 2*Math.exp(-8*p); [s, s]`.
- Sortie accélérée : images clés de Scale 103 → 122 % et Effect › Blur & Sharpen › Gaussian Blur (Effet › Flou et netteté › Flou gaussien) 0 → 6, de la mi-temps à l'image de coupe ; Easy Ease Out (Lissage de vitesse sortant, Ctrl/Cmd + Maj + F9) sur la première pour partir lentement. Couper avec Split Layer sur l'image de vitesse maximale.
- Carton final d'une mesure au plus, avec l'expression de pulsation sur le logo ; ne jamais finir sur Layer › Time › Freeze Frame (Calque › Temps › Figer l'image).
