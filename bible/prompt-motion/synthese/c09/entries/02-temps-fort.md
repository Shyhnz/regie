## Le temps fort : montée, silence d'un temps, impact sur la révélation (riser, pre-drop silence, drop on the reveal, hero hit)

La musique prépare (intro sans grosse caisse, montée, graves coupés), se tait, puis frappe son attaque la plus forte sur la révélation. Pendant le silence, l'image se vide aussi : une image figée, ou un point seul sur noir. Dans la meilleure occurrence, 13 im immobiles et −97 dB précèdent un drop de +35,7 dB posé sur un flash d'une image. Le contraste vide puis plein fait du moment clé l'événement le plus fort du film. Vue dans 79 vidéos, dont 69 notées 4 ou 5.

**Règles de construction**

1. Deux ou trois temps forts par film de 15 s, tous sur un premier temps de mesure. Drop d'entrée sur la mesure 2, vers 1,9 à 2,1 s (grace-sunnyy, misbahsy, codestackr, tequilafunks, steventey). Second drop sur la mesure 7, f675 (grace-sunnyy, zheke, reflex-cloud). Coup final sur la mesure 8, f788 (fionntobin, johnsavage, manuelogomigo).
2. Coupes franches et flashs sont réservés à ces accents : 3 coupes franches en 15 s chez lukasersil, 2 flashs pour les 2 attaques majeures chez kyonax-on-tech et reyzostyle. Le reste s'enchaîne par morphing ou volet.
3. Le silence dure de 6 im à un temps (0,1 à 0,47 s à 128 BPM) : 6 im (grace-sunnyy), 10 (zheke, stephanlivera), 13 (lukasersil), 29 (fionntobin). Au-delà, il devient temps mort : 73 im immobiles chez tdinh-me (musique partielle, noté 3).
4. L'image se vide avec le son, à 1 im près (pankajkumar-dev : écran « 06 / SILENCE » et −80 dB sur les mêmes images). Garder une image figée, ou un point de 0,4 à 4 % du cadre au centre exact de la révélation à venir.
5. Entrer dans le silence en accélérant : coupes de 14, 14, 7, 7, 3 et 4 im (fionntobin), anneau en sine.in sur 4 im (grace-sunnyy), implosion power1.inOut sur 10 im (lukasersil). La montée sonore accompagne la contraction.
6. L'impact tombe sur l'image du temps, 0 à 2 im avant l'attaque audible : flash d'une image, éclatement en expo.out ou coupe franche. Après le drop, la quantité de mouvement est multipliée par 1,5 à 4,25 (ndhabarde11, quickdesignio, topi-003, tequilafunks).

**Verdict** : à reprendre, une à trois fois par film. C'est ta « compression puis explosion » et ton « texte qui rétrécit en point puis révélation circulaire », mis en musique. Répété sur chaque argument (hqmank : silence puis impact sur trois mots de suite), il devient l'accent unique que tu rejettes.

**Quand l'utiliser** : en typo cinétique 1600, en promo SaaS et en showreel, pour la révélation (produit, nom, logo), l'accroche d'ouverture et la signature. On le choisit à l'étape « musique et grille » : on compose ou on repère le drop, puis le découpage place la révélation sur sa mesure. À éviter dans un explainer en voix off (le silence coupe la phrase), entre deux arguments de même poids, ou plus de trois fois en 15 s.

**HyperFrames (GSAP)**

```js
// Temps fort de la mesure 7 : contraction, silence écrit avec un point, éclatement
const FPS = 60, BPM = 128;
const BEAT = 60 / BPM;                         // 28,125 im
const at = b => Math.round(b * BEAT * FPS) / FPS;
const F = n => n / FPS;                        // images → secondes
const drop = at(24);                           // 1er temps de la mesure 7 = f675

tl.set(["#dot", "#reveal"], { autoAlpha: 0 }, 0)
  .set("#flash", { opacity: 0 }, 0)
  // 1. Contraction : l'anneau se referme en ease-in, fini 6 im avant le temps
  .to("#ring", { scale: 0, duration: F(4), ease: "sine.in" }, drop - F(10))
  // 2. Silence écrit : la scène disparaît, un point de 0,4 % H reste au centre (6 im)
  .set("#scene-a", { autoAlpha: 0 }, drop - F(6))
  .set("#dot", { autoAlpha: 1 }, drop - F(6))
  // 3. Impact sur l'image du temps : flash d'une image, puis retombée
  .set("#dot", { autoAlpha: 0 }, drop)
  .set("#flash", { opacity: 1 }, drop)
  .to("#flash", { opacity: 0, duration: F(6), ease: "power2.out" }, drop + F(1))
  // 4. Révélation : naît du point, 70 % de l'échelle en 3 im
  .set("#reveal", { autoAlpha: 1, scale: 0.2 }, drop)
  .to("#reveal", { scale: 1, duration: F(14), ease: "expo.out" }, drop)
  // 5. Éclats depuis le centre, 1 im de décalage
  .fromTo(".shard", { scale: 0.1, autoAlpha: 1 },
    { scale: 1.6, autoAlpha: 0, duration: F(28), ease: "expo.out",
      stagger: { each: F(1), from: "center" }, immediateRender: false }, drop);
// Bande-son composée sur la même table : graves coupés de drop - F(28) à drop - F(6),
// silence de drop - F(6) à drop, attaque la plus forte du morceau à drop.
```

**After Effects**

- Placer un marqueur de composition sur le drop (image 675). Afficher l'onde de la piste (touches L L) et vérifier que le creux de son couvre les 6 images avant le marqueur. Sur une piste non composée, couper le creux avec Edit › Split Layer (Édition › Fractionner le calque) ou baisser Audio Levels (Niveaux audio) à −48 dB sur ces 6 im.
- Contraction : calque de forme Ellipse « anneau », Scale (Échelle) 100 → 0 % de l'image 665 à 669. Dans le Speed Graph (éditeur de graphe de vitesse), influence 60 % sur la clé de départ et 0 % à l'arrivée : l'anneau accélère.
- Silence : Layer › New › Solid (Calque › Nouveau › Solide) noir plein cadre de l'image 669 à 674, et une Ellipse de 0,4 % de la hauteur au centre.
- Impact : Solid blanc d'une image sur le marqueur, puis Opacity (Opacité) 100 → 0 % en 6 im. Révélation : Scale 20 → 100 % en 14 im, influence 0 % au départ et 90 % à l'arrivée (≈ expo.out).
- Éclats : petites formes dupliquées, décalées d'1 im par Animation › Keyframe Assistant › Sequence Layers (Assistant d'image clé › Séquencer les calques), Scale 10 → 160 % et Opacity 100 → 0 % en 28 im. Activer le Motion Blur (flou de mouvement).
