## L'accélération par subdivisions et la rafale (accelerando, subdivision build-up, rapid-fire burst, burst and breathe)

La cadence des coupes double par paliers sur la grille, à tempo fixe (1 temps, puis ½, puis ¼), jusqu'au drop ou au logo ; ou une rafale de mots ou de plans à la croche ou à la double-croche, encadrée de passages qui respirent. C'est un roulement de batterie visuel : la densité qui monte fabrique la tension juste avant la révélation. Dans [Motion designer showreel](https://prompt-motion.com/eyishazyer-af035b), 8 mots tiennent exactement 4 temps : 28, 28, 14, 14, 7, 7, 7, 7 im. Vue dans 55 vidéos, dont 47 notées 4 ou 5 ; les modèles viennent des 42 vidéos animées sur la musique.

**Règles de construction**

1. Diviser par deux, par paliers, sur la grille : 1 temps → ½ → ¼, parfois ⅛ en toute fin. Chaque coupe tombe sur round(k × images par temps) ; l'accélération entière tient une mesure (tequilafunks, eyishazyer, zheke, rendesr, zaqailo, crazyalphaaa).
2. Résoudre sur le premier temps d'une mesure : logo, drop ou flash. Chez zheke (noté 5), ½ temps de vide avec un seul point précède le drop : la rafale s'arrête, l'impact frappe.
3. La durée d'un plan décide de ce qu'on peut y mettre. 15 im (0,25 s) : un mot neuf, lisible dès la 2e image. 7 im : seulement un mot court ou déjà vu (rappels de zheke). 3 à 4 im : une couleur ou une forme, jamais un texte, ni un graphique (14 im ne suffisent pas pour des chiffres, [Claude motion design reel](https://prompt-motion.com/ghinaiya-nirmal-5d8fec)).
4. Changer de fond et de traitement à chaque coupe, garder le mot au centre du cadre : le contraste rend chaque coupe lisible malgré la vitesse (eyishazyer, topi-003, monokern).
5. Une seule rafale par film, encadrée de passages qui respirent : chez topi-003, 2 s de rafale entre deux sections lentes paraissent plus rapides. Six styles d'affilée font catalogue ([Claude motion design showreel](https://prompt-motion.com/ayushunleashed-ece3e3)) ; huit plans égaux de 7,5 s restent plats ([Clay-style music video](https://prompt-motion.com/davidshulmanfl-371638), contre-exemple).
6. Garder l'avance de 1 à 2 im sur chaque coup ; une piste qui dérive fait tomber la rafale sur les contretemps ([Chaotic Claude POV video](https://prompt-motion.com/kloss-xyz-15182a)).

**Verdict** : à reprendre. C'est la « compression » de ta compression-explosion, à l'échelle du montage ; limite-la à une rafale par film, sinon elle devient l'accent répété que tu rejettes.

**Quand l'utiliser** : en typo cinétique 1600 et en showreel, pour la montée avant le logo ou le drop ; en promo SaaS, pour un défilé de fonctions ou de logos clients que l'on ne demande pas de lire. Se décide au découpage (la dernière mesure avant la chute) sur une grille posée à l'étape musique. À éviter quand chaque mot doit être lu (prix, chiffres, preuve) et sans musique, où rien ne justifie les paliers.

**HyperFrames (GSAP)**

```js
// Accelerando sur 3,5 temps, ½ temps de vide, drop au 1er temps (128 BPM, 60 im/s)
const FPS = 60, BEAT = 60 / 128;                   // 1 temps = 28,125 im
const at = b => Math.round(b * BEAT * FPS) / FPS;  // image entière la plus proche
const LEAD = 1 / FPS;                              // la coupe précède le coup d'1 image
const cards = gsap.utils.toArray(".burst-card");   // 7 cartes plein cadre, un fond chacune
const steps = [1, 1, 0.5, 0.25, 0.25, 0.25, 0.25]; // durées en temps (3,5 temps)

let b = 24;                                        // 1er temps de la mesure 7
tl.set(cards, { autoAlpha: 0 }, 0);
cards.forEach((card, i) => {
  const t = at(b) - LEAD;
  if (i > 0) tl.set(cards[i - 1], { autoAlpha: 0 }, t);
  tl.set(card, { autoAlpha: 1 }, t)
    .set(card.querySelector(".word"), { scale: 1.3, filter: "blur(8px)" }, t)
    .to(card.querySelector(".word"), { scale: 1, filter: "blur(0px)",
        duration: 3 / FPS, ease: "power3.out" }, t);  // net dès la 3e image
  b += steps[i];
});

// b = 27,5 : la rafale s'arrête, un point seul naît pendant ½ temps
tl.set(cards[cards.length - 1], { autoAlpha: 0 }, at(b) - LEAD)
  .set("#dot", { autoAlpha: 1, scale: 0 }, at(b) - LEAD)
  .to("#dot", { scale: 1, duration: 10 / FPS, ease: "back.out(3)" }, at(b) - LEAD)
  .set("#dot", { autoAlpha: 0 }, at(28) - LEAD)
  .set("#logo-scene", { autoAlpha: 1 }, at(28) - LEAD);  // drop : 1er temps de la mesure 8
```

**After Effects**

- Composition à 60 fps ; à 128 BPM, 1 temps = 28,125 im. Poser un marqueur par temps sur le calque audio (touche * du pavé numérique), puis noter les paliers : 28, 28, 14, 7, 7, 7, 7 im.
- Un calque de texte par mot, chacun sur son propre Layer › New › Solid (Calque › Nouveau › Solide) de couleur différente ; régler la durée de chaque paire avec Alt + [ et Alt + ].
- Mettre les mots bout à bout avec Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques), sans chevauchement, puis reculer le groupe d'une image (Alt + Page Up) pour l'avance sur le coup.
- Entrée de chaque mot en 3 im : Scale 130 → 100 % et Effect › Blur & Sharpen › Gaussian Blur (Effet › Flou et netteté › Flou gaussien) 8 → 0, Easy Ease In (Lissage de vitesse entrant, Maj + F9) sur la seconde image clé ; copier les images clés d'un mot à l'autre.
- Après le dernier mot, 14 im de noir avec un calque de forme Ellipse : Scale 0 → 125 → 100 % en 10 im ; le logo commence sur le marqueur du premier temps de la mesure suivante.
