## La musique calquée sur le montage (arrangement mirrors the edit, score to picture, song form drives visual form)

La forme du morceau suit celle du film : intro sans grosse caisse ni basse pendant l'accroche, entrée du kick sur le premier vrai plan, coupure sous la scène calme, retour sur la révélation, queue qui s'éteint avec le fondu. Chaque changement de section offre à l'image une ponctuation toute faite. Chez les meilleurs, un showreel de 15 s fait 8 mesures à 128 BPM, un chapitre par mesure. Vue dans 54 vidéos, dont 45 notées 4 ou 5 (31 animées sur la musique, seules retenues comme modèles).

**Règles de construction**

1. Relever la forme du morceau en mesures avant de construire : intro, entrée du kick, break, retour, impact, queue. Pour 15 s : 8 mesures à 128 BPM, un chapitre par mesure (levabashidze, fionntobin, ghinaiya-nirmal, ajith-io-b5626e).
2. L'intro sans kick porte l'accroche : 1 mesure (1,875 s) en showreel, 2 mesures chez itisrazak, 4 s en promo de 30 à 40 s (aschapmann, bizibeast). La 1re image pleine tombe sur l'entrée du kick : +0,5 im chez levabashidze, f117,7 chez miskinho (+18 dB de graves).
3. Le break loge la scène calme ou le problème, 1 à 6 temps (fionntobin 1, chatgptastra 6). L'image s'y fige ou y attend : gel de 29 im, compteur bloqué à 99 % pendant 21 im (levabashidze). Juste avant le drop, 0,2 à 0,35 s de silence total au plus (leonkohli, ho-ba), puis la révélation sur le 1er temps.
4. En promo longue, un riser culmine sur chaque limite de scène (bizibeast ; 0,75 s chez wani-shola). Si la bande-son est composée en code, l'écrire sur la même table : 120 BPM, scènes en secondes rondes, 1 temps = 30 im, tout à ±2 im (macrohou).
5. Le coup le plus fort verrouille le logo (−8 dB à 13,12 s chez reflex-cloud), puis la queue décroît : fondu au noir sur les 0,4 dernières s pendant que la musique passe de −9 à −46 dB (eyishazyer), ou 35 im linéaires avec elle (math-files). La vidéo s'arrête sur un nombre entier de mesures.
6. Contre-exemples : une boucle sans sections après 7,2 s laisse 20 gestes sur 34 près d'une barre, soit le hasard (56 %, ai-baymax). Les 12 vidéos à musique posée ont 3,33 de moyenne, aucune 5/5 ; les 129 animées sur la musique, 4,06 et 14 des 17 notées 5.

**Verdict** : à reprendre. C'est la charpente de la grille 1600 : la musique pilote le montage. Le guide Otom propose d'ajouter la musique « au montage (niveau 3) » (guide Otom, p. 13) ; nos mesures disent l'inverse, et la Bible tranche pour la musique d'abord.

**Quand l'utiliser** : dans toute vidéo avec musique, en typo cinétique 1600, promo SaaS (problème dans le break, solution au retour de la basse) et showreel éditorial. Elle structure l'accroche, la transition vers la preuve et la chute sur le logo. On la décide à l'étape musique et grille, avant le découpage : chaque plan reçoit sa section. À éviter : une nappe d'ambiance sans sections sous un film à rebondissements ; en explainer en voix off, garder une nappe basse et caler sur les phrases.

**HyperFrames (GSAP)**

```js
// Sections relevées sur la piste (128 BPM, 60 i/s) : elles pilotent les scènes
const FPS = 60, BEAT = 60 / 128, BAR = 4 * BEAT, F = n => n / FPS;
const bar = (m, b = 1) => (m - 1) * BAR + (b - 1) * BEAT;   // mesure m, temps b
const S = { drop: bar(2), cut: bar(7, 4), impact: bar(8), end: bar(9) };

// Intro sans kick : la balle seule, un rebond par temps, contact sur chaque temps
for (let b = 1; b <= 4; b++) {
  tl.to("#ball", { y: "-18vh", duration: BEAT / 2, ease: "sine.out" }, bar(1, b))
    .to("#ball", { y: 0, duration: BEAT / 2, ease: "power1.in" }, bar(1, b) + BEAT / 2);
}
// Drop : la balle fonce vers la caméra et devient l'aplat sur le 1er temps de la mesure 2
tl.set(["#flood", "#endcard", "#black"], { autoAlpha: 0 }, 0)
  .to("#ball", { scale: 16, duration: F(19), ease: "expo.in" }, S.drop - F(19))
  .set("#flood", { autoAlpha: 1 }, S.drop);
// Mesures 2 à 7 : un chapitre par mesure, coupe sur le 1er temps
gsap.utils.toArray(".chapter").forEach((ch, i) => {
  tl.set(".chapter", { autoAlpha: 0 }, bar(2 + i)).set(ch, { autoAlpha: 1 }, bar(2 + i));
});
// Coupure de basse (dernier temps de la mesure 7) : le compteur attend à 99 %
tl.set("#pct", { textContent: "99 %" }, S.cut)
  .set("#pct", { textContent: "100 %" }, S.impact - BEAT / 4)
// Impact : fond crème et marque sur le 1er temps de la mesure 8
  .set("#endcard", { autoAlpha: 1 }, S.impact)
  .from("#brand", { yPercent: 100, duration: F(18), ease: "power3.out", immediateRender: false }, S.impact)
// Queue : poussée de 2 %, puis fondu au noir sur les 0,4 dernières s, avec la musique
  .to("#endcard", { scale: 1.02, duration: S.end - S.impact, ease: "none" }, S.impact)
  .to("#black", { autoAlpha: 1, duration: 0.4, ease: "none" }, S.end - 0.4);
```

**After Effects**

- Importer la piste, afficher la Waveform (forme d'onde) avec LL, et poser un marqueur de composition sur chaque section (touche * du pavé numérique, Add Marker / Ajouter un marqueur), renommé « intro », « drop », « break », « impact ».
- Composition › Composition Settings (Paramètres de composition) : 60 i/s, durée d'un nombre entier de mesures (15 s = 8 mesures à 128 BPM).
- Une précomposition par chapitre (Layer › Pre-compose, Calque › Précomposer), point d'entrée aimanté (Maj) sur le marqueur de sa mesure.
- Break : Layer › Time › Freeze Frame (Calque › Temps › Figer l'image) sur le compteur pendant la coupure ; la marque entre sur le marqueur « impact ».
- Queue : Opacity (Opacité) d'un solide noir de 0 à 100 % sur les 24 dernières images, alignée sur la décroissance de la Waveform. Pour filtrer une intro : Effect › Audio › High-Low Pass (Passe-haut/Passe-bas) en Low Pass, Cutoff Frequency (fréquence de coupure) ouverte en 1 temps avant le drop.
