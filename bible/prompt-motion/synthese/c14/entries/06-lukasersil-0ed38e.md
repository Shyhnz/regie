**Leçons**

1. Grille en code : temps n = n × 28,125 im à 128 BPM ; placer chaque événement sur l'image arrondie (0 à +1 im), jamais à l'œil sur l'audio.
2. Décaler d'un quart de temps exact (7 im) : cercle f225, carré f232, triangle f239 ; rebonds 3D f366, f373, f380 ; coupes du rewind toutes les 7 im.
3. Ressort d'apparition : back.out(2.2) sur 17 im, pic +15 % à +8 im ; l'objet suivant démarre quand le précédent atteint son pic.
4. Sortie vers la coupe en accélération : power1.in ou power2.in sur 8-10 im, dernière image 1-2 im avant le temps (iris f884-f891, coupe f892).
5. Avant le drop : implosion power1.inOut 10 im, 13 im d'image figée, flash blanc d'1 image sur le temps 12, puis la nouvelle dimension.
6. Un geste mécanique par demi-temps : MOTION se comprime 13 im (none) dès le demi-temps 24,5, s'élargit 13 im dès le temps 25, déborde 6 im.

**HyperFrames (GSAP)**

```js
// PLANE → VOLUME, f206 → f402 (3,3 s) : volet, ressorts au 1/4 de temps, mosaïque, gel, flash, rebonds 3D
const FPS = 60, BEAT = 60 / 128;           // 1 temps = 0,46875 s = 28,125 im
const F = n => n / FPS;                     // images → secondes
const B = n => n * BEAT;                    // temps musicaux → secondes
const tl = gsap.timeline({ paused: true });
// volet : têtes de barres power1.inOut 12 im depuis les deux bords, papier crème sine.out 10 im
tl.from(".bar", { xPercent: i => (i % 2 ? 110 : -110), duration: F(12), ease: "power1.inOut",
    stagger: F(1) }, F(206))
  .from("#paper", { opacity: 0, duration: F(10), ease: "sine.out" }, F(212))
// 3 formes : ressort back.out(2.2) 17 im (pic +15 % à +8 im), décalées d'1/4 de temps
  .from(["#circle", "#square", "#triangle"], { scale: 0, duration: F(17),
    ease: "back.out(2.2)", stagger: B(0.25) }, B(8))
// mosaïque : explosion sine.inOut 13 im du centre, implosion power1.inOut 10 im
  .from(".tile", { scale: 0, duration: F(13), ease: "sine.inOut",
    stagger: { amount: F(6), from: "center" } }, F(285))
  .to(".tile", { scale: 0, duration: F(10), ease: "power1.inOut",
    stagger: { amount: F(3), from: "edges" } }, F(315))
// gel f325 → f337 (13 im, rien ne bouge), flash blanc d'1 image sur le temps 12
  .set("#flash", { opacity: 1 }, F(338)).set("#flash", { opacity: 0 }, F(339))
  .set("#plane", { autoAlpha: 0 }, F(339)).set("#volume", { autoAlpha: 1 }, F(339))
// orbite de caméra : power1.out sur 41 im
  .to("#rig", { rotationY: -35, duration: F(41), ease: "power1.out" }, F(339));
// rebonds : arche sine.out 9 im + sine.in 12 im, cube, prisme, sphère décalés de 7 im
["#cube", "#prism", "#sphere"].forEach((s, i) => {
  const t0 = B(13 + i / 4);                // f366, f373, f380
  tl.to(s, { yPercent: -14, duration: F(9), ease: "sine.out" }, t0)
    .to(s, { yPercent: 0, duration: F(12), ease: "sine.in" }, t0 + F(9));
});
```
