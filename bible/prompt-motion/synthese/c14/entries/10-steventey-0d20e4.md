**Leçons**

1. Écris la timeline en quarts de seconde (15 im à 120 BPM), piste calée 4 im plus tard : chaque coupe précède le coup.
2. Tous les compteurs en power3.out, de 33 à 140 im : la moitié de la valeur en 17-19 % du temps, les derniers chiffres roulent jusqu'au bout.
3. Un seul ressort pour tout ce qui naît (ζ ≈ 0,5, ω ≈ 0,26 rad/im) : dépassement 12-15 % à 15 im, repos vers 30 im, soit un temps.
4. Relais de vitesse : sortie power3.in de 12 im, entrée power3.out de 11 im ; la vitesse maximale tombe sur l'image du raccord.
5. Rafale : 15 im par carte = 1 image grise unie, 2 im de fondu linéaire, ≈ 6 im d'animation, 5-6 im figées.
6. Signature : iris de 5 im sur l'impact, marque réduite de moitié en expo.out 34 im, logotype à 13,25 s, un mot du slogan toutes les 6 im.

**HyperFrames (GSAP)**

```js
// Compression → éclair → lien court → clic (f80 → f269), 120 BPM à 60 i/s
const FPS = 60, BEAT = 30;                 // 1 temps = 30 im
const F = n => n / FPS;                   // images → secondes
const Q = n => F(15 * n);                 // croche n du code (quarts de seconde) = 4 im avant le son
// ressort mesuré (pastille, logo) : zeta 0,52, omega 0,26 rad/im, dépassement ≈ 15 %
const spring = (z = 0.52, w = 0.26, frames = 40) => p => {
  const t = p * frames, wd = w * Math.sqrt(1 - z * z);
  return 1 - Math.exp(-z * w * t) * (Math.cos(wd * t) + (z * w / wd) * Math.sin(wd * t));
};
const tl = gsap.timeline({ paused: true });
// l'URL floue se comprime en trait puis en point : 10 im power2.in, finit sur la croche 6 (1,5 s)
tl.to("#url", { scaleX: 0.087, duration: F(10), ease: "power2.in" }, Q(6) - F(10))
  .set("#url", { autoAlpha: 0 }, Q(6) + F(1))
// éclair gris : pic à 31 % sur 1 image, retombe en 11 im
  .fromTo("#flash", { opacity: 0.31 }, { opacity: 0, duration: F(11), ease: "power1.out" }, Q(6) + F(1))
// la pastille jaillit du point avec le ressort (pic f107, repos ≈ f130)
  .fromTo("#pill", { scale: 0 }, { scale: 1, duration: F(40), ease: spring() }, Q(6) + F(2))
  .from("#slug .ch", { autoAlpha: 0, duration: F(1), stagger: F(1) }, Q(6) + F(7))
// curseur : 12 im power2.out, posé 1 im avant le clic
  .fromTo("#cursor", { x: "18vw", y: "36vh" }, { x: 0, y: 0, duration: F(12), ease: "power2.out" }, Q(8) - F(13))
// clic sur la croche 8 (2,0 s) : pression, halo orange, anneau ; le drop audio tombe 4 im après
  .to("#pill", { scale: 0.92, duration: F(1), ease: "none" }, Q(8))
  .to("#pill", { scale: 1, duration: F(6), ease: "power2.out" }, Q(8) + F(1))
  .fromTo("#halo", { opacity: 1 }, { opacity: 0.25, duration: F(7), ease: "power1.out" }, Q(8))
  .fromTo("#ring", { scale: 0.08, opacity: 1 }, { scale: 1, opacity: 0, duration: F(15), ease: "power2.out" }, Q(8) + F(1))
  .from("#globe", { yPercent: 45, duration: F(21), ease: "power2.out" }, Q(8) + F(4))
// compteur héros sur la croche 9,2 (2,3 s) : 131 im, power3.out
  .to(clicks, { v: 1284093, duration: F(131), ease: "power3.out",
      onUpdate: () => (counterEl.textContent = Math.round(clicks.v).toLocaleString("en-US")) }, F(138));
```

**After Effects**

- Composition 60 i/s : marqueurs toutes les 15 im depuis 0 (croches du code). Décale le calque audio pour que la grosse caisse tombe 4 im après chaque marqueur (f4, f34, f64…).
- Compteurs : Source Text (Texte source) par expression, t = linear(time, début, fin, 0, 1) ; valeur = cible × (1 − (1 − t)³). Durées : 131, 52, 33, 34 et 140 im.
- Ressort de la pastille et du logo sur Scale (Échelle) : t = time − inPoint ; s = 100 × (1 − exp(−8,1 t) × (cos(13,3 t) + 0,61 sin(13,3 t))).
- Rafale : Solid (solide) #808080 d'une image à chaque coupe, puis Opacity (Opacité) de la carte 0 → 100 % en 2 im linéaires ; carte pleine 1 im avant le temps, 5 im de maintien.
- Signature : disque blanc Scale 0 → plein cadre en 5 im (influence 33 %), marque Scale 200 → 100 % en 34 im, vitesse initiale maximale, influence entrante 90 % (≈ expo.out).
