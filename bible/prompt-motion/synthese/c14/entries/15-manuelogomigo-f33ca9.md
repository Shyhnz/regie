**Leçons**

1. Timeline sur n × 28,125 im depuis 0 (32 temps = 15 s) ; l'attaque audio arrive 1,5 im après : caler l'image sur le code, pas sur l'onde.
2. Un passage de scène = un expo.inOut d'environ un temps (23-30 im) : 90 % du trajet se fait dans les 10 images centrales.
3. Gonflement vers l'aplat : expo.in d'un temps (f200 → f229) et coupe sur l'aplat 1 im avant le temps 8 ; tenir l'aplat 5 im.
4. Compteur de progression : power1.inOut 64 im jusqu'à 99, tenir 99 pendant 7 im, puis 100 et la coche sur le temps.
5. Cascades au quart de temps : puces toutes les 7 im, couches toutes les 14 im (½ temps), lettres du logo toutes les 3,25 im.
6. Après 11 im d'immobilité, le pop du logo part 2 im après l'attaque la plus forte : back.out(3), +25 %, puis glissement expo.inOut d'un temps.

**HyperFrames (GSAP)**

```js
// f53 → f246 (0,9-4,1 s) : glisser-lancer le fichier, compteur, barre → aplat, volets
const FPS = 60, BEAT = 60 / 128;            // 1 temps = 0,46875 s = 28,125 im
const F = n => n / FPS;                      // images → secondes
const B = n => n * BEAT;                     // temps musicaux → secondes (grille dès 0)
const tl = gsap.timeline({ paused: true });  // #file centré (xPercent/yPercent −50), left/top en %
const pct = { v: 1 }, num = document.querySelector("#pct");
// le fichier glisse à gauche et rétrécit pendant que la zone de dépôt entre
tl.to("#file", { left: "31.8%", scale: 0.71, duration: F(24.5), ease: "power2.inOut" }, F(53.5))
  .from("#dropzone", { xPercent: 60, autoAlpha: 0, duration: F(18), ease: "power3.out" }, F(60))
// lancer d'un temps exact, arc en y (sommet sur le temps 3)
  .to("#file", { left: "64%", duration: B(1), ease: "power3.inOut" }, F(72.5))
  .to("#file", { top: "42.5%", rotation: -8, duration: F(10), ease: "power2.out" }, F(76.5))
  .to("#file", { top: "52%", rotation: 0, duration: F(14), ease: "power2.in" }, F(86.5))
// temps 4 : la carte s'écrase en barre ; titre qui monte derrière son masque
  .to("#file", { scaleY: 0.11, scaleX: 1.6, duration: F(12), ease: "power3.in" }, B(4) + F(1))
  .from("#title .line", { yPercent: 100, duration: F(35), ease: "power3.out" }, F(123))
// compteur 1 → 99 en power1.inOut 64 im, barre en trame synchronisée
  .to(pct, { v: 99, duration: F(64), ease: "power1.inOut",
      onUpdate: () => { num.textContent = Math.round(pct.v); } }, B(4.5))
  .fromTo("#bar .fill", { scaleX: 0.015 }, { scaleX: 0.99, duration: F(64), ease: "power1.inOut" }, B(4.5))
// 99 tenu 7 im, puis 100 % et coche sur le temps 7
  .call(() => { num.textContent = 100; }, null, B(7))
  .to("#bar .fill", { scaleX: 1, duration: F(2) }, B(7))
  .from("#check", { scale: 0, duration: F(10), ease: "back.out(2)" }, B(7) + F(2))
// la barre pleine grossit jusqu'au plein cadre : expo.in d'un temps, coupe 1 im avant le temps 8
  .to("#bar", { scaleX: 1.6, scaleY: 30, duration: F(29.5), ease: "expo.in" }, F(200))
  .set("#flat", { autoAlpha: 1 }, B(8) - F(1))
// 5 im d'aplat, vignettage, puis volets en bandes d'un demi-temps
  .set("#vignette", { autoAlpha: 1 }, F(230))
  .to("#bands .b", { xPercent: i => (i % 2 ? 101 : -101), duration: F(14),
      ease: "sine.inOut", stagger: F(1) }, F(231));
```
