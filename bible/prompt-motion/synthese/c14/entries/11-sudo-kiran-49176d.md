**Leçons**

1. À 120 BPM et 60 fps, écrire la timeline sur f = 30 n : coupes, pleins cadres et départs y tombent ; la musique sonne 1-2 im plus tard.
2. Iris ou plongée : power3.in sur 12 à 24 im, l'objet ne remplit le cadre que dans les 4 dernières images, plein cadre sur le temps.
3. Compteur ou jauge : power2.out sur 60 im exactement ; la 2e jauge démarre 6 im après avec la même courbe.
4. Avant une chute, une levée : −7 % H en 8 im (sine.inOut), puis chute power1.in 12 im ; cartes décalées de 1 à 4 im.
5. Lettres qui tombent : 9 im sine.out jusqu'à 15 % H sous leur place, retour 12 im sine.inOut, 3 im entre lettres.
6. Récap en doubles-croches : coupe toutes les 7,5 im ; 1 image de fondu sur les croches, coupe sèche sur les doubles-croches intermédiaires.

**HyperFrames (GSAP)**

```js
// Chapitre 06 INTERFACE, f600 → f720 (2 s = 1 mesure) : cartes, compteur, anticipation, chute
const FPS = 60, BEAT = 0.5;                 // 120 BPM : 1 temps = 30 im
const F = n => n / FPS;                      // images → secondes
const B = n => n * BEAT;                     // temps → secondes (temps 20 = f600)
const tl = gsap.timeline({ paused: true });
const t0 = B(20);                            // flash crème plein cadre sur le temps
// 5 cartes, 4 im de décalage régulier, 1re carte 1 im après le temps
tl.from(".card", { opacity: 0, duration: F(15), ease: "power1.out", stagger: F(4) }, t0 + F(1))
  .from(".card", { yPercent: 14, duration: F(14), ease: "power2.out", stagger: F(4) }, t0 + F(1))
  .from(".card", { rotation: -5, duration: F(11), ease: "power1.out", stagger: F(4) }, t0 + F(2));
// compteur +0 → +248 % : power2.out sur exactement 60 im (2 temps)
const c = { v: 0 };
tl.to(c, { v: 248, duration: F(60), ease: "power2.out",
    onUpdate: () => document.querySelector("#growth").textContent = "+" + Math.round(c.v) + " %" }, t0 + F(12));
// anneau 0 → 87 % : même courbe, 6 im plus tard
tl.fromTo("#ring", { strokeDashoffset: 100 }, { strokeDashoffset: 13,
    duration: F(60), ease: "power2.out" }, t0 + F(18));
// anticipation : la carte sombre se lève de 7 % H en 8 im…
tl.to("#card-dark", { y: "-7vh", duration: F(8), ease: "sine.inOut" }, t0 + F(97))
// …puis tombe hors champ en 12 im (gravité) en basculant
  .to("#card-dark", { y: "90vh", rotation: -17, duration: F(12), ease: "power1.in" }, t0 + F(104))
  .to(".card:not(#card-dark)", { y: "95vh", rotation: -8, duration: F(10),
    ease: "power1.in", stagger: F(1.5) }, t0 + F(108));
// coupe sèche vers DESIGN sur le temps 24 (f720), 1 im de fondu
tl.set("#ch06", { autoAlpha: 0 }, B(24) + F(1)).set("#recap", { autoAlpha: 1 }, B(24));
// récap : un mot toutes les 7,5 im (double-croche)
["DESIGN","ANIMATE","TYPE","SHAPE"].forEach((w, k) =>
  tl.set("#word", { textContent: w }, B(24) + F(Math.round(7.5 * k))));
```
