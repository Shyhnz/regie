## Le trait sur le mot : souligner, surligner, raturer, écrire (underline draw-on, highlighter wipe, strike-through, handwriting write-on)

Un trait se dessine sur le texte ou l'écrit : soulignement, pavé de surligneur balayé derrière un mot, rature puis correction, crochets, écriture au pinceau. Le trait désigne ou corrige le mot comme le ferait un éditeur : un changement d'avis se raconte en moins d'une seconde. Le geste est bref : une rature se trace en 4 im à 60 fps, sur le temps. Vue dans 50 vidéos, dont 41 notées 4 ou 5.

**Règles de construction**

1. Un trait, un mot, une fois par plan. Le trait porte la seule couleur d'accent : surligneurs aux couleurs du logo (itisrazak-3ad902), seul jaune du film (henkvaness-0e06af). Le guide Otom réserve l'accent « à ce qui compte » (guide Otom, p. 6).
2. Durées mesurées : rature 4 à 8 im (fionntobin 4, paulo-kombucha 4-5, kmasiff 7, sudo-kiran-4f8b59 8) ; soulignement 4 à 12 im (hanifproduktif 4, itsuki-dev et kangaroohere 6, m1n9-k7 12 au pinceau) ; surligneur 2 à 18 im. Toujours de gauche à droite, en ease-out ; quasi linéaire pour un trait « à la main ».
3. Le trait arrive après le mot, jamais avec lui : 4 im après le claquement chez marouanegazouzi-6071d5, après la dernière lettre chez kangaroohere-b10f8d et teslachartz-c58b32. Seule exception : l'écriture, où le trait est l'entrée.
4. Calage : le trait part sur le temps ou finit dessus. fionntobin +0,1 im, itsuki-dev −0,4 im ; kangaroohere finit sur le temps f151 ; sudo-kiran-4f8b59 va du demi-temps au temps.
5. Le mot raturé reste lisible : 50 % d'opacité ou gris, trait de 0,5 à 1 % H. La correction arrive au temps suivant : 9 im plus tard chez quickdesignio, 16 im chez ajith-io-c52e09. Le guide décrit la même scène, « barré par un trait qui se dessine » (guide Otom, p. 13), mais sans sa pause de 1,5 s.
6. Écriture : 1,5 à 4 im par lettre (lexnlin 1,5, ajith-io-ea7f2d 1,6, lemomo-ai 4), pointe à vitesse constante. Une annotation fait au moins 4 % H (guide Otom, p. 14) : à 2,5 % H, celles de himanshutwtxs et chatgptastra ne se lisent pas en 0,3 à 1 s.

**Verdict** : à reprendre, une fois par film. La rature suivie de sa correction raconte un avant/après en moins d'une seconde. Un soulignement sous chaque titre devient l'accent répété partout que tu rejettes.

**Quand l'utiliser** : en typo cinétique 1600, la rature puis la correction portent le pivot problème → solution. Le surligneur ou le soulignement marquent le mot clé de l'accroche ou de la chute. En promo SaaS, surligneur sur le bénéfice, soulignement sous le slogan de signature. En explainer ou tableau blanc, écriture manuscrite et annotations à 4 % H. On fixe le geste au système de design (une couleur, une épaisseur), on le place à la construction du plan ; à éviter si un zoom ou une couleur accentue déjà le mot.

**HyperFrames (GSAP)**

```js
// Rature sur le temps, correction tapée au temps suivant, surligneur, soulignement, pinceau
const FPS = 60, BEAT = 60 / 120, at = b => b * BEAT;    // 120 BPM
// .strike et .hl : pavés absolus posés sur le mot (le .hl derrière le texte)
tl.set([".strike", ".hl"], { scaleX: 0, transformOrigin: "0% 50%" }, 0)
  .set([".fix .ch", ".fix .dots"], { autoAlpha: 0 }, 0)   // correction cachée
  .to(".strike", { scaleX: 1, duration: 4 / FPS, ease: "power2.out" }, at(8))
  .to(".old", { opacity: 0.5, duration: 4 / FPS, ease: "none" }, at(8))
  .set(".fix .dots", { autoAlpha: 1 }, at(8) + 8 / FPS)  // « … » de saisie
  .set(".fix .dots", { autoAlpha: 0 }, at(9))
  // correction : 1 lettre par image, à partir du temps suivant
  .to(".fix .ch", { autoAlpha: 1, duration: 1 / FPS, ease: "none", stagger: 1 / FPS }, at(9))
  // surligneur sur le mot corrigé, une fois posé : expo.out, 18 im
  .to(".hl", { scaleX: 1, duration: 18 / FPS, ease: "expo.out" }, at(10));

// Soulignement manuscrit (path SVG) : 6 im, fini sur le temps
const u = document.querySelector("#underline path"), L = u.getTotalLength();
tl.set(u, { strokeDasharray: L, strokeDashoffset: L }, 0)
  .to(u, { strokeDashoffset: 0, duration: 6 / FPS, ease: "power2.out" }, at(12) - 6 / FPS);

// Écriture : masque qui avance à vitesse constante, 1,5 im par lettre, la pointe suit
const n = 14, d = n * 1.5 / FPS;                           // « Keep thinking. »
tl.set("#write", { clipPath: "inset(0% 100% 0% 0%)" }, 0)
  .set("#nib", { x: 0 }, 0)
  .to("#write", { clipPath: "inset(0% 0% 0% 0%)", duration: d, ease: "none" }, at(16))
  .to("#nib", { x: () => document.querySelector("#write").offsetWidth,
                duration: d, ease: "none" }, at(16));
```

**After Effects**

- Rature et soulignement : Shape Layer (calque de forme) Ligne sur le mot, Stroke (contour) de 0,5 à 1 % H. Add › Trim Paths (Ajouter › Réduire les tracés), End (Fin) 0 → 100 % en 4 im (rature) ou 6 im (soulignement), départ sur le marqueur du temps ; Influence (influence) ≈ 70 % sur l'image clé d'arrivée (≈ power2.out).
- Mot raturé : Opacity (Opacité) 100 → 50 % sur les mêmes 4 im. Correction : calque de texte, Animate › Opacity (Animer › Opacité) à 0 %, Range Selector › Start (Sélecteur de plage › Début) 0 → 100 % en 6 im, au temps suivant.
- Surligneur : Shape Layer Rectangle sous le texte, Anchor Point (point d'ancrage) au bord gauche, Scale (Échelle) X 0 → 100 % en 18 im, Influence ≈ 90 % à l'arrivée (≈ expo.out). Texte en défonce : Blending Mode Difference (mode de fusion Différence), ou un double du texte en Alpha Matte (Cache alpha).
- Écriture : Effect › Transition › Linear Wipe (Effet › Transition › Effacement linéaire), Transition Completion (Achèvement de la transition) 100 → 0 % en n × 1,5 im, images clés linéaires. La pointe (petit calque) va du début à la fin du mot sur les mêmes images clés.
