## Le mot qui change sur place : roulette, palettes, morph (slot-machine word roll, word swap, split-flap, glyph-travel morph)

Un mot change dans un emplacement fixe d'une phrase : roulement vertical masqué, palettes retournées lettre à lettre, ou glyphe qui voyage et change le sens. Le reste ne bouge pas, donc l'œil ne relit que ce qui change : « 100+ » reste fixe pendant que « LLMs. » devient « APIs. » en 12 im. Le morph de glyphe est le plus fort : il fait lire le changement de sens (ask → task). Vue dans 45 vidéos, dont 40 notées 4 ou 5.

**Règles de construction**

1. Un seul emplacement change, le reste de la phrase reste fixe (« Your » chez utopyaszx, « I ___ it. » chez wani-shola). Si la largeur change, la ligne se recentre pendant l'échange : 6 % L chez utopyaszx, masque interpolé sur 13 im chez wani-shola.
2. Échange de 6 à 14 im. Roulette : l'ancien sort vers le haut pendant que le nouveau monte du bas, masque à la hauteur de la ligne, lettres à 1 im d'écart (misbahsy et ajith-io-4c248f, 12 im).
3. Un mot par temps ou par demi-temps : 15 im à 120 BPM et 30 fps (rammanq), 14 im à 128 BPM et 60 fps (safarkhanshuvo). En dessous de 0,23 s par mot, on ne lit plus : 4 im chez andginja, jugé « à adapter ». La rafale ne sert que d'accélération avant le dernier mot (jesscaroline7).
4. Le dernier mot résout : il passe en accent ou en noir, une seule fois (SEO en rouge chez utopyaszx, « product » en noir chez samuel-yostt, « launched » en orange chez twoclipping-6dd14e). Le guide demande aussi un mot d'accent en couleur et en italique (guide Otom, p. 13).
5. Morph de glyphe quand le sens bascule, pas pour une liste : ask → task, draft → craft, MOTION → EMOTION. Le glyphe voyageur garde l'accent pendant le trajet et vire à l'encre sur l'attaque. La rature qui se dessine sur le mot réfuté (guide Otom, p. 13) prépare le changement.
6. Pas de fondu où deux mots se lisent ensemble (sudo-kiran-4f8b59, viktoroddy : « à adapter »), ni le même glitch huit fois (madhav-xo).

**Verdict** : à reprendre. La roulette masquée est l'outil de base pour dire « une promesse, plusieurs cas » sans relancer la mise en page. Le morph de glyphe est la version forte, de la même famille que tes match cuts : un signe devient un autre et porte le sens.

**Quand l'utiliser** : en promo SaaS pour l'accroche ou la présentation (cas d'usage, langues, version 1.3 → 1.4), en typo cinétique 1600 pour une rafale calée sur les temps, en showreel pour un jeu de mots. On écrit la phrase gabarit au script, on règle la cadence sur la grille musicale. Garde le morph pour le pivot du message. À éviter au-delà de 5 ou 6 mots s'il faut les lire tous.

**HyperFrames (GSAP)**

```js
// Roulette : « Your [keywords. → articles. → rankings. → SEO.] », un mot par temps, ligne recentrée
// HTML : <p id="line">Your <span id="slot" style="display:inline-block;overflow:hidden;vertical-align:bottom;position:relative">
//   <span class="w">keywords.</span><span class="w" style="position:absolute;left:0">articles.</span>…</span></p>
const FPS = 60, BEAT = 60 / 120, at = b => b * BEAT, f = n => n / FPS;
const W = gsap.utils.toArray("#slot .w");
tl.set(W.slice(1), { yPercent: 100 }, 0)
  .set("#slot", { width: () => W[0].offsetWidth }, 0);
W.slice(1).forEach((w, i) => {
  const t = at(2 + i) - f(2);                       // l'échange démarre 2 im avant le temps
  tl.to(W[i], { yPercent: -100, duration: f(8), ease: "power2.in" }, t)       // l'ancien sort par le haut
    .to(w, { yPercent: 0, duration: f(10), ease: "power3.out" }, t)           // le nouveau monte du bas
    .to("#slot", { width: () => w.offsetWidth, duration: f(12), ease: "power2.inOut" }, t); // recentrage
});
tl.to(W.at(-1), { color: "#E8251C", duration: f(4), ease: "none" }, at(1 + W.length)); // le dernier résout

// Morph de glyphe « ask? » → « task » (étude 60 fps) : MotionPathPlugin requis
// #q = le « ? » corail ; #t = le « t » final (caché), déjà à sa place devant « ask »
const M = at(12), box = s => document.querySelector(s).getBoundingClientRect();
tl.set("#t", { autoAlpha: 0 }, 0)
  .to("#q", { scale: 0.3, duration: f(3), ease: "power2.in" }, M)            // le « ? » se rétracte
  .to("#q", { motionPath: () => { const dx = box("#t").left - box("#q").left;
      return { path: [{ x: 0, y: 0 }, { x: dx / 2, y: -0.19 * innerHeight }, { x: dx, y: 0 }], curviness: 1.2 }; },
      duration: f(6), ease: "power2.inOut" }, M + f(3))                      // arc au-dessus du mot, 6 im
  .set("#q", { autoAlpha: 0 }, M + f(9))
  .set("#t", { autoAlpha: 1, scale: 0.3, color: "#D9694F" }, M + f(9))
  .to("#t", { scale: 1, duration: f(4), ease: "sine.out" }, M + f(9))        // le « t » pousse en 4 im
  .set("#t", { color: "#111111" }, M + f(13));                               // vire à l'encre sur l'attaque
```

**After Effects**

- Roulette : un calque de texte par mot, même Anchor Point (point d'ancrage) ; un rectangle de la hauteur de la ligne en Alpha Matte (Cache alpha) pour tous. Sortant : Position Y de 0 à −1 ligne en 8 im, Influence (influence) ≈ 70 % au départ. Entrant : de +1 ligne à 0 en 10 im, Influence ≈ 85 % à l'arrivée. Départ 2 im avant le marqueur du temps.
- Recentrage : le texte fixe est parenté à un Null Object (objet nul) ; une expression sur `sourceRectAtTime().width` du mot actif donne le décalage, lissé sur 12 im.
- Palettes : deux calques superposés (MOTION, DESIGN). Animate › Scale (Animer › Échelle) par caractère, Y de 100 à 0 % pour le sortant puis de 0 à 100 % pour l'entrant, 2 im chacun ; Offset (Décalage) du Range Selector (sélecteur de plage) animé pour 1 im d'écart par lettre.
- Morph de glyphe : le « ? » converti en forme (Layer › Create › Create Shapes from Text (Calque › Créer › Créer des formes à partir du texte)). Scale de 100 à 30 % en 3 im, Position en arc sur 6 im (sommet ≈ 19 % H, Influence 50 / 50 %), puis coupe vers le « t » corail qui pousse en 4 im et passe au noir sur le marqueur d'attaque.
