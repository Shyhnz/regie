## La 3D et la lumière de cinéma (3D render, cinematic lighting, camera work)

Des volumes rendus en temps réel (Three.js), une lumière motivée qui raconte (heure dorée, braises, espace) et un vrai découpage de caméra : orbite, grue, poursuite. Ces vidéos racontent plus qu'elles ne calent : 2 sur 16 animées sur la musique, 41 s en médiane. Vu dans 16 vidéos, dont 9 notées 4 ou 5 (aucune notée 5, moyenne 3,56).

**Ce qui le définit**

- Palette : #050403 noir qui laisse la lumière sculpter ; #FFB347 lumière chaude (orange dans 15 vidéos sur 16) ; #E8641E feu, fusion ; #9FD8FF contrepoint froid ; #F4A574 ciel d'heure dorée ; #F2EEE8 blanc chaud des titres.
- Polices : peu de texte. Grotesque très grasse pour les chiffres (Inter Display Black, 14-18 % de la hauteur) ; didone ou serif italique pour les cartons (Bodoni), 4-6 % ; mono pour la télémétrie, ≈ 1,5 %.
- Matières : lueur (11 vidéos), profondeur de champ (7), vignettage (6), flou de mouvement (5). Image figée médiane 13 % : la caméra bouge.

**Quand le choisir** : une métaphore produit forte (un PDF qui fissionne), un explainer d'infrastructure (un data centre), un court-métrage de marque de 30 s et plus. Ton visuel en 3 adjectifs (guide Otom, p. 5) : « cinématographique, chaud, contemplatif ». À éviter en promo SaaS courte si la 3D ne porte pas le message : la « 3D générique » est la première cause de casse de style des vidéos notées 4-5.

**Tempo et cadence (mesurés)**

- Tempo : 2 vidéos sur 16 animées sur la musique (116 et 107 BPM), 9 partielles. Durée médiane 41 s (quartiles 31-70 s).
- Cadence : plan médian 2,8 s (2,3 s dans les vidéos calées), jusqu'à 8,5 s si la caméra bouge (axtonliu).
- Calage (les 2 vidéos animées sur la musique) : chiffres à 22 puis 19 im, chacun à ±1 im d'un accent qui accélère, silence de 0,5 s au flash puis impact (ajith) ; chutes dans les silences, 4 coupes de 13-14 im au climax (gorden-sun).
- Contre-exemple : nolkeeg, en durées libres, a 11 gestes clés sur 17 à ±2 im.

**Courbes signature** (pas d'étude 60 fps) : orbites et travellings linéaires (45° en 8,5 s, axtonliu) ; poussées et grues en ease-in-out lent (80 im, anilraok) ; roulis ease-in-out sans dépassement en 14-24 im (nft-chen). Impact : flash 3 im, retombée 15 im, caméra qui bondit de 10-15 % et revient en 8 im (ajith). Personnage : écrasement 8 % sur 5 im, atterrissage écrasé 20 % (anilraok).

**Transitions types** : fondu ou passage par le fond (44 %), souvent dans un brouillard couleur du fond ; la caméra fait la transition : poussée (44 %), canevas parcouru (25 %). Voir *Le fondu et le passage par le fond* au chapitre 4, *La poussée vers le sujet : lente, calibrée ou en punch sur le temps* et *Filmer une scène 3D : orbite, grue, poursuite et angles* au chapitre 5.

**Structure type** : chute (25 %, 2,7× le corpus), escalade puis résolution (19 %), dispositif unique (19 %) ; musique calquée sur le montage (50 %, 2,2×). Découpage type (axtonliu) : large d'exposition, insert mécanique, gros plan matière, contre-plongée héroïque, grue qui libère le ciel pour le titre. Voir *La chute : constat puis retournement* et *Le dispositif unique : une métaphore ou un concept décliné dans chaque scène* au chapitre 10, *La musique calquée sur le montage* au chapitre 9.

**Règles du style**

1. Une lumière chaude motivée plus un contrepoint froid (#FFB347 / #9FD8FF), qui changent avec le récit. Voir *Le script couleur : étalonnage, désaturation et lumière qui racontent* au chapitre 6.
2. La caméra ne s'arrête jamais : image figée sous 15 %. Défauts relevés : plan fixe de 94 s (rebutonepress), carton final figé 6,5 s (anilraok). La Bible corrige les 2,5 s figées du guide Otom (p. 14) : poussée lente pendant la tenue.
3. Une seule matière, des modèles à la hauteur de la lumière. Ce qui casse : la sonde low-poly sous un trou noir photoréaliste, les illustrations plates dans le feu (ajith, 30 s).
4. Texte ancré dans la scène ou très gros (14-18 %) ; le texte HTML plat posé sur la 3D casse le diorama (anas0ra).
5. Héros à 10 % de la hauteur au moins ; la balle de gorden-sun (2-4 %) et sa caméra qui traverse le décor sont ses défauts.
6. Promo calée : tempo choisi avant la caméra, chaque geste écrit en temps (ajith), jamais en durées libres.

**Verdict** : à adapter. Dans une promo SaaS, la 3D sert un ou deux plans d'une typographie cinétique : ton anneau de texte en orbite, ton nuage de particules qui devient interface. Un film tout en 3D exige un concept fort. Le guide Otom ne traite pas la 3D ; son « pas de dégradé » (p. 7) ne vaut pas ici.

**HyperFrames (GSAP)**

```css
:root { --bg:#050403; --warm:#FFB347; --ember:#E8641E; --cold:#9FD8FF; --title:#F2EEE8;
  --sans:"Inter Display", sans-serif; --serif:"Bodoni Moda", serif; } /* polices auto-hébergées */
.figure { font:900 16vh/0.9 var(--sans); color:var(--title); }
#flash { position:absolute; inset:0; background:#FFF4D6; opacity:0; }
```

```js
// Kit : caméra Three.js pilotée par la timeline, 116 BPM à 60 fps
const FPS = 60, BEAT = 60 / 116, F = n => n / FPS, at = b => b * BEAT;
const cam = { orbit: 0, dist: 9, height: 1.2 };          // proxy animé par GSAP
const shot = () => {                                       // image = état de la timeline
  camera.position.set(Math.sin(cam.orbit) * cam.dist, cam.height, Math.cos(cam.orbit) * cam.dist);
  camera.lookAt(0, 0.8, 0); renderer.render(scene, camera);
};
// 1. Exposition : orbite de 45° sur 8 temps, linéaire
tl.to(cam, { orbit: Math.PI / 4, duration: at(8), ease: "none", onUpdate: shot }, 0);
// 2. Poussée vers le sujet : 9 → 5 m en 4 temps, ease-in-out
tl.to(cam, { dist: 5, height: 0.9, duration: at(4), ease: "sine.inOut", onUpdate: shot }, at(8));
// 3. Impact au temps 16 : flash 3 im, retombée 15 im, caméra +12 %, retour 8 im
tl.set("#flash", { autoAlpha: 1 }, at(16) - F(1))
  .to("#flash", { autoAlpha: 0, duration: F(15), ease: "expo.out" }, at(16) + F(2))
  .to(cam, { dist: 4.4, duration: F(2), ease: "power2.out", onUpdate: shot }, at(16))
  .to(cam, { dist: 5, duration: F(8), ease: "power2.out", onUpdate: shot }, at(16) + F(2));
// 4. Grue de sortie qui libère le ciel pour le titre
tl.to(cam, { height: 6, dist: 12, duration: at(6), ease: "power2.out", onUpdate: shot }, at(24));
```
