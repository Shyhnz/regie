## Le carnet : feutre, crayon et papier dessiné (hand-drawn notebook, marker, pencil, whiteboard, paper cut-out)

Tout semble tracé à la main sur papier : feutre de tableau blanc, graphite qui tremble, aquarelle détourée en autocollant, écriture manuscrite. Le trait qui se dessine porte le film dans 7 vidéos sur 8, souvent guidé par une voix. Style le plus humain du corpus, et l'un des plus lents. Vu dans 8 vidéos, dont 7 notées 4 ou 5 (aucune notée 5, moyenne 3,88).

**Ce qui définit le style**

- **Palette** : papier `#F2F1EC` (crème dans les 8 vidéos) ; feutre noir `#2A2A2A` (titres, contours) ; feutre orange `#D8693F` (étapes, accents) ; feutre bleu `#2F5DB8` (annotations) ; rouge `#B23A3E` (seuils, alertes) ; surligneur `#E6DC9E` translucide.
- **Polices** : manuscrites dans les 8 vidéos (Caveat ×4, Patrick Hand ×3), en bas de casse, de 2,5 à 10 % de la hauteur ; mono ou machine à écrire pour cartes et chiffres.
- **Matières** : grain de papier (5 vidéos), vignettage (4), ombres douces sous feutres et autocollants (3).
- **Mouvement** : tracés à vitesse de main, trait qui « bouillonne », caméra qui parcourt un seul canevas (4 plans-séquence ou presque).

**Quand le choisir** : tutoriel, onboarding, explainer intime, recette, récit à la première personne. Ton visuel en 3 adjectifs (guide Otom, p. 5) : humain, artisanal, pédagogique. En promo SaaS : dessiner un flux, puis le croquis devient l'interface. À éviter pour un lancement énergique de 15 s.

**Tempo et cadence mesurés** : 1 vidéo animée sur la musique, 2 en voix off, 2 en synchro partielle, 3 muettes. Durée médiane 45 s (30 à 73 s). Image figée médiane 23 %, temps mort relevé dans les 8 vidéos. Seul modèle de calage musical : [Sketchbook animals come alive](https://prompt-motion.com/abderrahmen-g-9e8ed0) à 120 BPM. Coupes 1 im avant le temps, montage qui accélère de 2 temps à 1, ½ puis ¼ (plans de 1 s à 0,13 s), tempo ralenti vers 80 BPM pour la nuit. Sur la voix, le dessin précède la phrase de 0,4 à 0,7 s (un toutes les 1,2 s) (voir *Le calage sur la voix off* au chapitre 9).

**Courbes signature** (pas d'étude 60 fps) : tracé linéaire à vitesse de main (environ 4 im par lettre, un soulignement en 12 im) ; panoramique filé en 14 im, `power2.inOut`, avec flou directionnel ; carte jetée qui se pose par paliers 15° → 8° → 4° → 0° en 3 images ; balle qui tombe en 12 im, étirée 1,3:1, et rebondit avec 65 % de restitution. Voir *Le tracé qui se dessine : plume, connecteur, logo au trait* au chapitre 6.

**Transitions types** : coupe sur le temps (38 % des vidéos), objet relais (38 %), volet par la matière du dessin (25 %, 4,9 fois la part du corpus : vague, nuit qui tombe, gomme), vider le cadre (12 %). Voir *Le volet par la matière du décor* au chapitre 4 et *Parcourir un canevas* au chapitre 5.

**Structure type** : signature finale (62 %), fil rouge (38 %, 2,5 fois le corpus : thermomètre, balle, canevas), récapitulatif en rafale (25 %), boucle finale. Voir *Le fil rouge : un objet, un exemple ou un plan continu traverse le film* au chapitre 10.

**Règles du style**

1. Trois encres au plus, à rôle fixe : noir pour la structure, orange pour les étapes, bleu pour les alternatives ; rouge et surligneur pour l'alerte et la désignation.
2. Le trait vit, la lecture reste stable : contours redessinés toutes les 3 à 4 im (1 à 4 px), mais texte immobile pendant qu'on le lit (skill motion-premiers-principes).
3. Écrire assez gros : le message à 6 % de la hauteur au moins (64 px en 1080p). Un texte de 1,5 à 3,5 % est relevé comme défaut dans 5 vidéos sur 8.
4. Chaque changement de page est motivé (gomme en 23 im, vague, nuit qui tombe, plongée dans un point), jamais un effacement sec.
5. Pas plus de 1,5 s sans trait en cours : un feutre qui écrit, un objet qui bouge ou un panoramique. Des tenues de 1,75 à 4,5 s sont relevées dans 6 vidéos sur 8.
6. Ce qui tombe pèse : écrasement 2:1 à l'impact, rebond amorti à 65 %. Les chutes sans rebond sont reprochées à 3 vidéos : le « pas de rebond » du guide Otom (p. 5) ne vaut pas ici.

**Verdict** : à adapter. En promo SaaS, garder le croquis qui devient l'interface et caler les tracés sur une grille de tempo. L'utilisateur a gardé les variantes « dessiné main » et « collage papier » dans sa panoplie (effets aimés) ; il rejette le texte minuscule, défaut typique du style.

**HyperFrames (GSAP)**

```js
// Kit « carnet » : papier, trois feutres, trait qui vit, tracés calés sur le temps
const css = `:root{--papier:#F2F1EC;--encre:#2A2A2A;--orange:#D8693F;--bleu:#2F5DB8;
  --alerte:#B23A3E;--surligneur:#E6DC9E;--main:'Caveat','Patrick Hand',cursive;
  --machine:'IBM Plex Mono',monospace} .note{font:400 6vh/1.1 var(--main)}`;
document.head.insertAdjacentHTML("beforeend", `<style>${css}</style>`);
const FPS = 60, BEAT = 60 / 120, at = b => b * BEAT, DUR = at(32);
const EASE = { trait: "none", pano: "power2.inOut", pose: "power3.out", balle: "power2.in" };
const draw = (sel, beat, dur) => document.querySelectorAll(sel).forEach(p => {
  const L = p.getTotalLength();
  tl.set(p, { strokeDasharray: L, strokeDashoffset: L }, 0)
    .to(p, { strokeDashoffset: 0, duration: dur, ease: EASE.trait }, at(beat) - 1 / FPS);
});
draw("#souligne path", 4, 12 / FPS);   // tracé linéaire, 1 im avant le temps
// Trait qui bouillonne : une pose toutes les 4 im, aléa seedé
const rnd = s => { const x = Math.sin(s * 12.9898) * 43758.5453; return x - Math.floor(x); };
gsap.utils.toArray(".boil").forEach((el, i) => {
  for (let k = 0; k * 4 / FPS < DUR; k++)
    tl.set(el, { x: (rnd(i * 97 + k) - 0.5) * 4, y: (rnd(i * 31 + k) - 0.5) * 4,
                 rotation: (rnd(i * 7 + k) - 0.5) * 0.8 }, k * 4 / FPS);
});
// Carte jetée : 15° → 8° → 4° → 0°, une pose toutes les 5 im (12 i/s)
[[15, -30], [8, -12], [4, -4], [0, 0]].forEach(([r, y], k) =>
  tl.set("#carte", { autoAlpha: 1, rotation: r, y }, at(8) + k * 5 / FPS));
// Panoramique filé : 1,1 largeur en 14 im
tl.to("#canevas", { x: -1.1 * 1920, duration: 14 / FPS, ease: EASE.pano }, at(16) - 14 / FPS);
```

**After Effects**

- Fond : Layer › New › Solid (Calque › Nouveau › Solide) `#F2F1EC`, grain par Effect › Noise & Grain › Fractal Noise (Bruit fractal) en Overlay (Incrustation) à 8 %.
- Tracés : calque de forme, Add › Trim Paths (Ajouter › Raccorder les tracés), End de 0 à 100 % en linéaire (12 im pour un soulignement). Écriture : masque et Effect › Generate › Stroke (Générer › Trait), Paint Style « Reveal Original Image ».
- Trait qui bouillonne : Effect › Distort › Turbulent Displace (Déformation › Déplacement turbulent), Amount 4, Size 3, Evolution `posterizeTime(15); time*500`. Jamais sur le texte à lire.
- Canevas : dessins enfants d'un Null Object (Objet nul), Position en 14 im, Easy Ease (Lissage de vitesse) à 70 % d'influence, Motion Blur (Flou de mouvement).
- Calage : à 120 BPM et 30 fps, un repère toutes les 15 im ; coupes 1 im avant le repère.
