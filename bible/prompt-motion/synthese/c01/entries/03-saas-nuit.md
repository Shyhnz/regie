## La promo SaaS sur fond nuit : interface, halo et accent néon (dark SaaS promo, glowing UI, single neon accent)

L'interface du produit, reconstruite, est le héros : des cartes sur fond nuit, un halo derrière chaque scène, un seul accent de marque, des chapitres et des preuves chiffrées. **Palette type** : fond marine vignetté #0A0D18 (ou violet #0B0716), cartes #161B2D, halo radial #2A1B5C, accent #E8B84B (or ; ou #7C5CFF, #CBFA4E), vert des gains #34D399 (21 vidéos sur 32), respiration claire #F4F4F4. **Polices** : grotesque néo grasse en casse de phrase avec point final (Inter dans 15 vidéos, Plus Jakarta Sans), titres à 5-12 % de la hauteur ; mono (JetBrains Mono) pour chiffres et code dans 22 ; serif italique pour le mot accent dans 8. **Matières** : halo (29 vidéos), flou de mouvement (20). **Mouvement** : cartes qui arrivent, compteurs, poussées vers un chiffre. Vu dans 32 vidéos, dont 25 notées 4 ou 5 (aucune notée 5, moyenne 3,78).

**Quand le choisir** : lancement d'un SaaS, d'une fintech, d'un outil de développeur ou d'IA, en 15 à 30 s, pour des acheteurs ; ton premium et technique. Trois adjectifs pour la charte (guide Otom, p. 5) : précis, nocturne, premium. C'est la base naturelle de NuOps (marine #000F1E, sarcelle #02D6B6, Manrope + JetBrains Mono). À éviter si l'interface ne peut pas être agrandie, pour un public non technique, ou au-delà de 31 s (moyenne 3,71).

**Tempo et cadence (mesurés)** : 20 vidéos sur 32 animées sur la musique (moyenne 3,95, contre 3,50 sans musique) ; 120 BPM dans 12, 128 dans 5. Durée médiane 18 s, plan médian 2,3 s, image figée 31 %. Modèles de calage (animés sur la musique) : Crux coupe sur le temps, gestes secondaires sur les demi-temps, plans médians 0,73 s ; AIsa tient chaque mot-choc une croche (7 im à 128 BPM) ; Taxtello part sur les demi-temps, arrive 1 im avant le temps ; Trezio, une transition majeure par mesure.

**Courbes signature** (étude 60 fps de Taxtello) : arrivées power2.out en 22-42 im, 95 % du trajet fait 1 à 3 im avant le temps ; aspirations power2.in en 9-14 im ; transformations power1.inOut à power2.inOut en 18-58 im, pic de vitesse sur le temps ; révélations sine.out. Dépassement décrit dans 16 vidéos : gardez un back.out court sur pastilles et logo. Le guide Otom (p. 7) interdit le rebond ; la Bible le garde (14 des 17 vidéos notées 5 en ont).

**Transitions types** : *L'objet relais* (31 %), *Le flash et la surexposition* (31 %), *La plongée éclair* dans un O ou un point, au chapitre 4. *Le fondu et le passage par le fond* (44 %) est le tic des notées 3 ; le glitch en tranches (22 %), un cliché. Le guide Otom (p. 7) propose le fondu enchaîné par défaut ; la Bible le corrige : 2 des 17 vidéos notées 5 seulement s'en servent.

**Structure type** : *L'arc de pitch : problème → solution → preuves → appel* (38 %, 1,8 × le corpus), *Le chapitrage : un chapitre par mesure* (38 %), *La signature finale : logo, slogan, appel, sans temps mort* (69 %), au chapitre 10.

**Règles du style**

1. Texte à lire : au moins 6 % de la hauteur (64 px en 1080p, skill motion-premiers-principes). L'interface sous 2 % n'est qu'un décor ; le chiffre clé est cadré seul par une poussée (voir *La maquette d'appareil et l'interface reconstruite*, chapitre 7).
2. Image figée sous 15 % (notées 4 : 29 % ; notées 3 : 60 %), aucun maintien de plus de 1 s ; le halo dérive pendant les lectures (voir *Le fond d'ambiance*, chapitre 6).
3. Un accent de marque, plus le vert des gains et le rouge des pertes (voir *La palette fermée et l'accent qui a un sens*, chapitre 6).
4. Une transition motivée par chapitre, aucun effet plus de deux fois. Contre-exemples : flash blanc 14 fois en 30 s ([Tennis game launch video](https://prompt-motion.com/deifosv-04e4d3)), glitch 9 fois ([Fitters Bible app promo](https://prompt-motion.com/adamdesgns-478d6d)).
5. Rendu à 60 fps (moyenne 3,94 contre 3,62 à 30 fps), musique choisie avant la construction.

**Verdict** : à adapter. Le décor est juste ; la cadence manque pour atteindre 5. Les 17 vidéos notées 5 ont un plan médian de 0,47 s, 10 % d'image figée, un plus long maintien de 1,27 s ; cette famille, 2,3 s, 31 % et 2,15 s. Un même effet est répété dans 18 vidéos sur 32 (3 sur 17 chez les notées 5). Le texte d'interface illisible fait perdre le point dans 15 vidéos (3 sur 17). Pour viser 5 : ce décor, avec la cadence de *La typographie cinétique à accent unique, façon 1600*. Le halo peut devenir un dégradé fluide (mesh gradient) de marque, aimé de l'utilisateur ; le guide Otom (p. 7) bannit les dégradés, la Bible les garde ici.

```js
// Kit « SaaS nuit » : 120 BPM, courbes de l'étude 60 fps de Taxtello
await document.fonts.ready;                         // mesurer après les polices
const BEAT = 60 / 120, at = b => b * BEAT;          // 1 temps = 30 im
const F = n => n / 60;                              // images -> secondes
const E = { arrive: "power2.out", suck: "power2.in", morph: "power2.inOut" };
const kpi = document.querySelector("#kpi"), n = { v: 0 };
tl.set("#card", { y: 420, autoAlpha: 0 }, 0)        // 95 % du trajet 2 im avant le temps 9
  .to("#card", { y: 0, autoAlpha: 1, duration: F(36), ease: E.arrive }, at(9) - F(32))
// Poussée calibrée sur le chiffre clé, puis compteur
  .to("#ui", { scale: 2.4, transformOrigin: "62% 30%", duration: F(40), ease: E.morph }, at(10.5))
  .to(n, { v: 48260, duration: F(39), ease: E.arrive,
      onUpdate: () => { kpi.textContent = Math.round(n.v).toLocaleString("de-DE"); } }, at(11))
// Aspiration 9 im, disparu 3 im avant le temps 13
  .to("#ticket", { scale: 0, autoAlpha: 0, duration: F(9), ease: E.suck }, at(13) - F(12))
// Barre -> anneau : le pic de vitesse sur le temps 15
  .to("#bar", { "--curl": 1, duration: F(18), ease: E.morph }, at(15) - F(9))
// Le halo dérive : jamais d'image figée
  .to("#halo", { scale: 1.06, xPercent: 3, duration: at(8), ease: "sine.inOut", yoyo: true, repeat: 3 }, 0);
```

**After Effects**

- Composition Settings (Paramètres de composition) à 60 i/s, un repère par temps (Layer › Markers › Add Marker (Calque › Repères › Ajouter un repère)).
- Fond : Layer › New › Solid (Calque › Nouveau › Solide) #0A0D18, puis Effect › Generate › Gradient Ramp (Générer › Dégradé) radial, #2A1B5C au centre, qui dérive ; Effect › Stylize › Glow (Lueur diffuse) sur les seuls accents.
- Interface construite deux fois plus grande, Layer › Pre-compose (Calque › Précomposer) avec Collapse Transformations (Rastérisation en continu) : la poussée ×2,4 reste nette.
- Graph Editor (Éditeur de graphique) : arrivées influence 0 % puis 70-75 % (≈ power2.out) ; aspirations sortante 75 %, entrante 0 % (≈ power2.in).
