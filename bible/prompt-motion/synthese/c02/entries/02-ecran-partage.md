## L'écran partagé : texte d'un côté, visuel de l'autre (split layout, headline-left / UI-right, side-by-side comparison)

Le cadre est coupé en deux zones stables : une colonne de texte (surtitre, titre, sous-titre ou chiffre géant) sur le tiers gauche, et une zone visuelle (interface, appareil, graphique) sur les 55 à 60 % restants. L'œil sait d'avance où lire et où vérifier, donc on peut enchaîner une fonction toutes les 2 à 4 s. Répété à l'identique, le gabarit fait diaporama : [FigPad product promo](https://prompt-motion.com/ai-baymax-0ef9dd) garde la même mise en page sur 6 sections et plafonne à 3/5. Vue dans 43 vidéos, dont 26 notées 4 ou 5.

**Règles de construction**

1. Proportions : colonne de texte de 30 à 38 % de la largeur, marge gauche de 5 à 7 %, bloc centré verticalement (centre à 40-50 %). Visuel sur 45 à 60 % de la largeur, bord droit vers 93 %. Mesuré sur [Database client launch video](https://prompt-motion.com/iammxfschr-d68f90) et [ViralGrow product promo](https://prompt-motion.com/samuel-yostt-891f87).
2. Trois niveaux dans la colonne : surtitre mono 1 à 1,2 % H, titre de 2 lignes à 5-6 % H (ou chiffre de 16 à 21 % H), corps gris de 2 à 3,5 % H. Le guide Otom (p. 14) exige 8 % H pour un titre et 4 % H pour le texte secondaire. C'est plus que dans les vidéos, et plus juste pour un téléphone.
3. Pas plus de 3 ou 4 scènes sur le même gabarit. Ensuite, inverser les côtés ([Enxovaly baby app promo](https://prompt-motion.com/gabrielbuzziv-4ff0c6), marges 8 %) ou centrer le plan pivot ([Dubz Up motion showreel](https://prompt-motion.com/devius-maximus-beab45)).
4. Garder une zone fixe pendant que l'autre change : téléphone immobile, disque posé sur la couture, carte qui glisse au lieu de disparaître. Le guide Otom (p. 12) le dit pour l'avant/après : « chaque indicateur reste à sa place ». Contre-exemple : [YouTube transcript product ad](https://prompt-motion.com/tstfully-0aa6b4) (3/5) change tout par fondu.
5. Le visuel doit se lire : une interface en texte de 1 % H est illisible sur téléphone ([Datagran ChatGPT ads explainer](https://prompt-motion.com/charlesmendez-73b6e4)). Il faut alors la recadrer sur la zone utile.
6. Ordre d'entrée : surtitre, puis titre 4 à 6 im plus tard, puis visuel sur le demi-temps. Le panneau de partage part 2 im avant un 1er temps, en power3.out de 24 im : la moitié de la course tient en 4 im, la coupe se lit sur le temps. Un volet linéaire de 34 im manque de punch ([Moroccan political history timeline](https://prompt-motion.com/triglyceee-bd5b08)).

**Verdict** : à adapter. Reprends la colonne de texte face à l'interface pour enchaîner les fonctions vite. Casse la répétition toutes les 3 ou 4 scènes (côté inversé, plan centré, zoom calibré sur l'interface). Fais aussi passer chaque changement par un pivot qui reste ou un panneau qui glisse, jamais par un fondu générique : c'est ta règle des transitions motivées.

**Quand l'utiliser** : en promo SaaS ou interface, pour la démonstration d'une fonction ou la preuve chiffrée ; en explainer données avec le chiffre géant face au graphique. On le choisit au système de design (gabarit et repères), puis on décide des alternances au découpage. À éviter pour l'accroche et la chute de style 1600, où un mot seul centré frappe plus fort, et en 9:16, où l'on empile au lieu de couper en largeur.

**HyperFrames (GSAP)**

```js
// Panneau qui coupe le cadre, texte à gauche, UI à droite, puis pivot
const FPS = 60, f = n => n / FPS;          // images → secondes
const BEAT = 60 / 120;                      // 120 BPM : 1 temps = 30 im
const at = b => b * BEAT;
// Gabarit : colonne texte x 7 → 38 % ; carte UI x 52 → 93 %, centrées en hauteur
tl.set("#panel", { xPercent: 100 }, 0)      // panneau sombre = moitié droite
  .set(["#eyebrow", "#title .line", "#sub"], { autoAlpha: 0 }, 0)
  .set("#title .line", { y: 20 }, 0)        // 1,9 % de 1080 px
  .set("#ui-card", { autoAlpha: 0, x: 80, scale: 0.96 }, 0)
  .set("#col-b", { autoAlpha: 0 }, 0);      // colonne de la scène suivante
// 1. Le panneau s'arrête à 50 % : power3.out 24 im, départ 2 im avant le temps 4
tl.to("#panel", { xPercent: 0, duration: f(24), ease: "power3.out" }, at(4) - f(2));
// 2. Surtitre mono, puis titre 6 im après : fondu 7 im, montée 24 im
tl.to("#eyebrow", { autoAlpha: 1, duration: f(6) }, at(4) + f(12))
  .to("#title .line", { autoAlpha: 1, duration: f(7), stagger: f(4) }, at(4) + f(18))
  .to("#title .line", { y: 0, duration: f(24), ease: "power1.out", stagger: f(4) }, at(4) + f(18))
  .to("#sub", { autoAlpha: 1, duration: f(10) }, at(5));
// 3. Carte UI sur le demi-temps : power2.out 22 im, 95 % du trajet 1 im avant le temps 5
tl.to("#ui-card", { autoAlpha: 1, x: 0, scale: 1, duration: f(22), ease: "power2.out" }, at(4.5));
// 4. Scène suivante : seule la colonne texte change ; la carte reste (pivot)
//    et se recadre ×1,6 sur la zone utile (règle 5)
tl.to("#col-a", { autoAlpha: 0, y: -16, duration: f(10), ease: "power2.in" }, at(8) - f(10))
  .set("#col-b", { autoAlpha: 1 }, at(8))
  .from("#col-b .line", { y: 20, autoAlpha: 0, duration: f(18), ease: "power2.out",
                          stagger: f(4), immediateRender: false }, at(8))
  .to("#ui-card", { scale: 1.6, x: -240, y: -90, duration: f(30), ease: "power2.inOut" }, at(8));
```

**After Effects**

- Composition 1920 × 1080 à 60 i/s. Poser des Guides (repères) (View › Show Rulers (Affichage › Afficher les règles), puis tirer depuis la règle) à 134, 730, 998 et 1786 px : colonne texte de 7 à 38 %, visuel de 52 à 93 %.
- Panneau : calque de forme Rectangle 960 × 1080, Anchor Point (point d'ancrage) au bord gauche. Position x de 1920 à 960 px en 24 im, la première clé 2 im avant un marqueur de temps. Dans le Speed Graph (éditeur de graphe de vitesse), influence d'arrivée à 85 % pour un power3.out.
- Texte : surtitre, titre et sous-titre en calques séparés, ferrés sur le repère 7 %. Sur le titre, Animate › Opacity et Position (Animer › Opacité et Position) avec un Range Selector (Sélecteur de plage) (Advanced › Based On: Lines (Avancé › Basé sur : Lignes)) : opacité en 7 im, montée de 20 px en 24 im, 4 im entre lignes.
- Carte UI : précomposition de la capture, Position +80 px → 0 et Scale (Échelle) 96 → 100 % en 22 im, influence 75 %. Layer › Layer Styles › Drop Shadow (Calque › Style de calque › Ombre portée), très diffuse.
- Pivot : la précomposition carte court sur les deux scènes ; seuls les calques texte sont coupés (Edit › Split Layer (Édition › Scinder le calque)). Pour l'alternance, dupliquer la scène et déplacer la colonne sur un repère à 60 %.
