## Formats et zones sûres : vertical, carré, cinémascope (aspect ratio, 9:16 and 1:1 layouts, letterbox, safe margins, caption zone)

La mise en page est pensée pour son format : zones fixes empilées en 9:16, 4:5 ou 1:1, bandes noires 2,39:1 qui accueillent les sous-titres, bande basse réservée aux légendes, marges latérales constantes, rien de coupé par le bord. Chaque format a ses zones lisibles. Une interface de bureau réduite dans un cadre vertical tombe à 0,5 % de la hauteur pour le texte courant : illisible sur téléphone. **Règles de construction**

1. Choisir le format avant d'écrire la première scène. Le guide Otom (p. 5) le dit : produire en 16:9 puis recadrer en 9:16 fait sortir les textes du cadre. Pour un fil mobile, le 4:5 occupe le plus de place (p. 16) ; [Step race app promo](https://prompt-motion.com/marklaunches-3b9492) y met une seule idée par écran.
2. Marges latérales de 6 % : [Ball escaping twelve rings](https://prompt-motion.com/kantamk-61f410) (6 %) et [Festival lineup promo reel](https://prompt-motion.com/gonzalomacagno-2de1a9) (6,5 %). Le guide Otom (p. 7) impose 6 % sur chaque bord, sans texte. [Kinetic type showreel](https://prompt-motion.com/zheke-38deff) (5/5) le contredit avec un en-tête à 2 % : réservé à la typo géante voulue.
3. Rien de coupé par le bord. « THE OWNER DIES » réduit à « NER DIES » pendant 9 s ([Celld job ownership explainer](https://prompt-motion.com/0xnfrith-5be616)) est un bug, pas un style. Seul un objet (fenêtre, carte) peut déborder pour suggérer sa taille ([Launch video remake comparison](https://prompt-motion.com/notdwd-c2037d)).
4. En 9:16 et 1:1, des zones fixes empilées : titre dans le haut (9-20 % H), action au centre (28-78 %), légende vers 85-92 %. Elles ne bougent pas d'un plan à l'autre. Laisser ≈ 15 % libre en bas, pas 40 % : sinon recentrer le bloc ([What is Git explainer](https://prompt-motion.com/yunn260414-60d996) reste tassé en haut).
5. Taille minimale : aucun texte à lire sous 3 % H ; à 2,4 % H, le code de [UK dubstep track with ASCII visuals](https://prompt-motion.com/rames-jusso-589f80) est déjà illisible sur mobile. Le guide Otom (p. 14) dit 4 %. Une interface de bureau à 0,5 % H ([PicTwin AI app ad](https://prompt-motion.com/l3d1c-0e35a3)) appelle des recadrages serrés de 2 à 3 ×. Même chose pour un texte de code à 1,2-1,6 % H ([Second brain service promo](https://prompt-motion.com/theviableedge-9065be)).
6. Cinémascope : bandes de 12,5 à 12,8 % (138 px sur 1080), sous-titres centrés à 90-91 % H dans la bande, jamais sur l'image. L'entrée des bandes est un événement : 6 im sur le temps fort, sortie en 24 im.

**Verdict** : à reprendre. Format décidé d'abord, zones fixes, marges de 6 % et contrôle image par image : c'est la parade directe à ton rejet des mots coupés par le bord. Le cinémascope est à adapter : il coûte 25 % de la hauteur, à réserver au récit.

**Quand l'utiliser** : toujours. Le format se choisit à la direction artistique, les zones et marges au système de design, et on les contrôle à chaque rendu. Le carré à en-tête fixe sert la typo cinétique style 1600, la pile 9:16 la promo SaaS sur Reels, le 2,39:1 le court-métrage, la 3D et les personnages. À éviter : le cinémascope sur une démo d'interface, et le texte qui déborde « pour suggérer une liste infinie ».

**HyperFrames (GSAP)**

```js
// Carré 1080 : l'accroche se range en en-tête fixe, les verbes vivent dans la zone libre
// + bandes cinémascope qui claquent, sous-titre dans la bande basse
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128, at = b => b * BEAT;   // 128 BPM : 1 temps = 28,125 im
const S = 1080, SAFE = 0.06 * S;              // marge de sécurité 6 % (guide Otom p. 7)
// En CSS : #hook en position absolue, left = SAFE ; .verb dans la zone y 20 → 94 %
tl.set("#hook", { transformOrigin: "0 0" }, 0)
  .set(".verb", { autoAlpha: 0, yPercent: 30 }, 0)
  .set(["#bar-top", "#bar-bot"], { scaleY: 0 }, 0)
  .set("#bar-top", { transformOrigin: "50% 0" }, 0)
  .set("#bar-bot", { transformOrigin: "50% 100%" }, 0)
  .set("#subtitle", { autoAlpha: 0 }, 0);
// 1. L'accroche (46 % H) devient l'en-tête : ×0,56 en 10 im, posée 1 im avant le temps 6
tl.to("#hook", { y: SAFE - 0.459 * S, scale: 0.56, duration: f(10), ease: "power2.inOut" },
      at(6) - f(11));
// 2. Un verbe par temps dans la zone restante, sorties en power2.in
gsap.utils.toArray(".verb").forEach((v, i) => {
  const t = at(6 + i);
  tl.to(v, { autoAlpha: 1, yPercent: 0, duration: f(12), ease: "power2.out" }, t)
    .to(v, { autoAlpha: 0, yPercent: -20, duration: f(6), ease: "power2.in" }, t + at(1) - f(6));
});
// 3. Bandes 2,39:1 (12,8 % chacune) en 6 im sur le 1er temps de la mesure 5
tl.to(["#bar-top", "#bar-bot"], { scaleY: 1, duration: f(6), ease: "power4.out" }, at(16));
// 4. Sous-titre centré à 91 % H, dans la bande : fondu 24 im, tenu, sortie 24 im
tl.to("#subtitle", { autoAlpha: 1, duration: f(24), ease: "none" }, at(16.5))
  .to("#subtitle", { autoAlpha: 0, duration: f(24), ease: "none" }, at(28));
```

**After Effects**

- Composition au format final dès le départ (Composition › Composition Settings (Composition › Paramètres de la composition) : 1080 × 1080, 1080 × 1350 ou 1080 × 1920). Afficher les marges Title/Action Safe (marges de sécurité titre/action) (bouton Choose grid and guide options (options de grille et de repères)), réglées à 6 % dans Preferences › Grids & Guides (Préférences › Grilles et repères).
- Zones fixes : Guides (repères) horizontaux aux limites des zones (par exemple 9, 20, 28, 78 et 87 % en 9:16). Chaque calque texte se cale sur son repère et n'en bouge plus.
- En-tête : Scale (Échelle) 100 → 56 % et Position vers le coin haut gauche en 10 im, Anchor Point (point d'ancrage) au coin haut gauche du texte, influence 60 % des deux côtés dans le Speed Graph (éditeur de graphe de vitesse).
- Cinémascope : deux Solids (solides) noirs de 1920 × 138 px, Scale Y 0 → 100 % en 6 im sur le marqueur du temps fort (Anchor Point au bord extérieur). Sous-titres en calque texte centré à y = 983 px, Opacity (Opacité) en 24 im.
- Contrôle : Composition › Save Frame As (Composition › Enregistrer l'image sous), à chaque changement de scène, et regarder chaque image à taille réelle sur un téléphone.
