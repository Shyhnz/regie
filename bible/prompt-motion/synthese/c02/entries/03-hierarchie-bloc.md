## La hiérarchie du bloc texte : titre, surtitre, pastilles, filigrane (text block hierarchy, stacked lockup, eyebrow pill, ghost word, end card)

Un bloc de texte composé sur 3 ou 4 niveaux nets : surtitre ou pastille, titre géant, sous-titre, micro-légende mono. Il est empilé, en diagonale ou ferré d'un côté, avec parfois un mot géant en filigrane derrière le sujet. Des écarts de taille francs (titre de 15 à 20 % de la hauteur contre 1 à 6 % pour le reste) donnent un seul point d'entrée à l'œil. C'est aussi la grammaire des cartons de fin. Vue dans 31 vidéos, dont 21 notées 4 ou 5.

**Règles de construction**

1. Trois tailles, pas plus : titre de 15 à 22 % H, deuxième niveau de 4 à 6 % H, micro-légende de 1 à 1,5 % H. Le titre fait au moins 2,5 fois le niveau suivant. Le guide Otom (p. 14) fixe le même principe : l'élément principal « au moins deux fois plus grand que le reste et seul dans la couleur d'accent ».
2. Une seule couleur d'accent par bloc, sur un seul mot : IS rouge ([Keyframe motion design reel](https://prompt-motion.com/grace-sunnyy-29bc61)), NO bleu ([ODATANO Cardano hype edit](https://prompt-motion.com/maxalexweber-67688b)). Le reste en blanc, crème ou gris.
3. Apparition dans l'ordre de lecture : pastille en 4-5 im, titre sur le temps, sous-titre au demi-temps, ligne mono écrite en dernier. Pour une série, une pastille par temps ([Studio1 intro showreel](https://prompt-motion.com/astrodevil-3f2054)) ou une toutes les 3 à 5 im.
4. La micro-légende mono à 1 % H est une texture, pas une information : en 1280 × 720 elle devient illisible ([Lead Notifi product ad](https://prompt-motion.com/leadnotifi-e83f94)). Le guide Otom (p. 14) demande 4 % H pour tout texte à lire ; les vidéos notées 5 gardent pourtant leurs lignes mono à 1 % H, comme décor.
5. Filigrane : mot ou chiffre géant de 45 à 85 % H, en ton sur ton (#DD4F08 sur #ED5406 dans [Ondefica app motion reel](https://prompt-motion.com/jesscaroline7-1ff7cb)) ou à 50 % d'opacité. Le sujet passe devant et garde le centre.
6. Pas de nuage : 3 à 5 pastilles sur une ligne ou un cercle, sans chevauchement, complètes au moins 0,5 s avant la sortie. [Fitters Bible app promo](https://prompt-motion.com/adamdesgns-478d6d) fait toucher deux pilules et ne finit que 0,3 s avant le fondu. Un carton tenu plus d'1 s garde une micro-vie (confettis, reflet).

**Verdict** : à reprendre. C'est la base de toute ta typographie : un seul point d'entrée par plan, une seule couleur d'accent. Ce dernier point répond à ton rejet du « même accent répété partout ». Garde la ligne mono pour le décor, jamais pour une information.

**Quand l'utiliser** : en typo cinétique style 1600 pour l'accroche et la chute (manifeste empilé, liste puis mot géant), en showreel éditorial et en promo SaaS pour la signature (carte de fin). On fixe l'échelle à 3 niveaux au système de design, une fois pour toute la vidéo, puis on compose chaque bloc à la construction du plan. À éviter au-dessus d'une interface déjà dense : le bloc entre en concurrence avec elle.

**HyperFrames (GSAP)**

```js
// Carte de fin à 4 niveaux : pastille, titre, italique + filet, ligne mono écrite
const FPS = 60, f = n => n / FPS;
const BEAT = 60 / 128;                       // 128 BPM : 1 temps = 28,125 im
const at = b => b * BEAT;
const T0 = at(28);                           // 1er temps de la mesure 8
tl.set(["#pill", "#sub"], { autoAlpha: 0 }, 0)
  .set("#sub", { y: 20 }, 0)
  .set("#title .char", { yPercent: 110 }, 0)   // lettres sous un masque (overflow: hidden)
  .set("#rule", { scaleX: 0, transformOrigin: "0 50%" }, 0)
  .set("#mono", { clipPath: "inset(0 100% 0 0)" }, 0);
// 1. Pastille (1 % H) en premier, fondu 5 im
tl.to("#pill", { autoAlpha: 1, duration: f(5) }, T0 - f(6));
// 2. Titre (15 % H) : montée masquée 14 im, 1 im par lettre, sur le temps
tl.to("#title .char", { yPercent: 0, duration: f(14), ease: "power1.out", stagger: f(1) }, T0)
  .fromTo("#title", { letterSpacing: "0.12em" }, { letterSpacing: "0em", duration: f(60),
           ease: "power2.out", immediateRender: false }, T0);
// 3. Italique serif (6 % H) au demi-temps, filet tracé en 12 im
tl.to("#sub", { autoAlpha: 1, y: 0, duration: f(12), ease: "power2.out" }, T0 + at(0.5))
  .to("#rule", { scaleX: 1, duration: f(12), ease: "power3.inOut" }, T0 + at(0.5));
// 4. Ligne mono (1 % H) écrite caractère par caractère, finie sur le temps suivant
tl.to("#mono", { clipPath: "inset(0 0% 0 0)", duration: at(1), ease: "steps(48)" }, T0 + at(1));
// 5. Maintien vivant : l'astérisque tourne lentement jusqu'à la fin
tl.to("#star", { rotation: 24, duration: at(4), ease: "none" }, T0);
```

**After Effects**

- Trois styles de texte réglés une fois dans le panneau Character (Caractère) : titre 160 px, sous-titre 64 px, mono 12 px (15, 6 et 1 % de 1080). Un seul mot en couleur d'accent.
- Titre : Animate › Position (Animer › Position) (Y = hauteur de capitale) avec un Range Selector (Sélecteur de plage) (Advanced › Based On: Characters (Avancé › Basé sur : Caractères), Shape: Ramp Up (Forme : rampe vers le haut)). Animer l'Offset (Décalage) de -100 à 100 % pour faire monter les lettres l'une après l'autre en ≈ 20 im. Un calque de forme rectangle sert d'Alpha Matte (cache Alpha).
- Interlettrage : Animate › Tracking (Animer › Interlettrage) de 120 à 0 en 60 im, influence d'arrivée à 80 % dans le Speed Graph (éditeur de graphe de vitesse).
- Filet : calque de forme Path (Tracé) + Trim Paths (Coupe de tracés) (End (Fin) 0 → 100 % en 12 im, Easy Ease (Lissage de vitesse) à 70 % des deux côtés). Ligne mono : Animation Preset (préréglage d'animation) Text › Animate In › Typewriter (Texte › Machine à écrire), étiré sur 1 temps (28 im à 60 i/s).
- Pastilles en série : Animation › Keyframe Assistant › Sequence Layers (Animation › Assistant d'image clé › Séquencer les calques), avec un décalage d'un temps (28 im) ou de 4 im. Vérifier qu'aucune ne se touche.
